ଅଧ୍ୟାୟ ୦୩ – ସମାନ୍ତର ପ୍ରଗତି

(Arithmetic Progression – A.P.)

Class X Mathematics • KGKHS Beldandia

୧. ଅଧ୍ୟାୟ ପରିଚୟ

ସମାନ୍ତର ପ୍ରଗତି (Arithmetic Progression) ହେଉଛି ଏକ ବିଶେଷ ପ୍ରକାରର ସଂଖ୍ୟା ଅନୁକ୍ରମ। ଅନୁକ୍ରମର ପ୍ରତ୍ୟେକ ପଦରୁ ତାହାର ପୂର୍ବପଦକୁ ବିୟୋଗ କଲେ ଯଦି ପ୍ରତ୍ୟେକଥର ସମାନ ସଂଖ୍ୟା ମିଳେ, ତେବେ ସେହି ଅନୁକ୍ରମକୁ ସମାନ୍ତର ପ୍ରଗତି କୁହାଯାଏ। ଏହି ସମାନ ସଂଖ୍ୟାକୁ ସାଧାରଣ ଅନ୍ତର (Common Difference) ଏବଂ ତାହାକୁ d ଦ୍ୱାରା ସୂଚିତ କରାଯାଏ।

ଉଦାହରଣ: 2, 4, 6, 8, 10, ...
ଏଠାରେ ପ୍ରତ୍ୟେକ ପଦରୁ ପୂର୍ବପଦ ବିୟୋଗ କଲେ 2 ମିଳେ। ତେଣୁ ଏହା ଏକ A.P. ଏବଂ ସାଧାରଣ ଅନ୍ତର d = 2।

ଅନୁକ୍ରମର ପଦଗୁଡ଼ିକୁ ସାଧାରଣତଃ t₁, t₂, t₃, ... , tₙ ଭାବେ ଲେଖାଯାଏ।

୨. ସମାନ୍ତର ପ୍ରଗତିର ସାଧାରଣ ରୂପ

ଯଦି A.P. ର ପ୍ରଥମ ପଦ a ଏବଂ ସାଧାରଣ ଅନ୍ତର d, ତେବେ A.P. ର ସାଧାରଣ ରୂପ:

a, a + d, a + 2d, a + 3d, ...

ଏଠାରେ ପ୍ରଥମ ପଦ a, ଦ୍ୱିତୀୟ ପଦ a+d, ତୃତୀୟ ପଦ a+2d ଇତ୍ୟାଦି।

ସାଧାରଣ ଅନ୍ତର:
d = t₂ − t₁ = t₃ − t₂ = t₄ − t₃ = ...
ସାଧାରଣ ଅନ୍ତର ଧନାତ୍ମକ, ଋଣାତ୍ମକ କିମ୍ବା ଶୂନ ହୋଇପାରେ।

୩. A.P. ର n-ତମ ପଦ

A.P. ର ପ୍ରଥମ ପଦ a ଏବଂ ସାଧାରଣ ଅନ୍ତର d ହେଲେ n-ତମ ପଦର ସୂତ୍ର:

tₙ = a + (n − 1)d

ଏହି ସୂତ୍ର ବ୍ୟବହାର କରି A.P. ର ଯେକୌଣସି ନିର୍ଦ୍ଦିଷ୍ଟ ପଦ ନିର୍ଣ୍ଣୟ କରାଯାଇପାରେ।

ଉଦାହରଣ: A.P. = 4, 7, 10, 13, ...
a = 4, d = 3
33-ତମ ପଦ:
t₃₃ = 4 + (33−1)×3 = 100
ଉଦାହରଣ: 2, 4, 6, 8, ... ର 50-ତମ ପଦ:
a = 2, d = 2
t₅₀ = 2 + 49×2 = 100

୪. ପ୍ରଥମ nଟି ପଦର ଯୋଗଫଳ

A.P. ର ପ୍ରଥମ nଟି ପଦର ଯୋଗଫଳକୁ Sₙ ଦ୍ୱାରା ସୂଚିତ କରାଯାଏ। ଯଦି ଶେଷ ପଦ l ହୁଏ, ତେବେ:

Sₙ = n/2 (a + l)

କାରଣ l = a + (n−1)d, ତେଣୁ ଅନ୍ୟ ଏକ ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ ସୂତ୍ର:

Sₙ = n/2 [2a + (n−1)d]
ଉଦାହରଣ: A.P. 4, 7, 10, 13, ... ର ପ୍ରଥମ 40ଟି ପଦର ଯୋଗଫଳ:
a=4, d=3, n=40
S₄₀ = 40/2 [8 + 39×3]
= 20 × 125
= 2500
1 ରୁ n ପର୍ଯ୍ୟନ୍ତ ପ୍ରାକୃତିକ ସଂଖ୍ୟାର ଯୋଗଫଳ: n(n+1)/2

୫. ଓଲଟାଇ ମିଶାଇବା ପଦ୍ଧତି

A.P. କିମ୍ବା କ୍ରମିକ ସଂଖ୍ୟାମାନଙ୍କର ଯୋଗଫଳ ଶୀଘ୍ର ନିର୍ଣ୍ଣୟ ପାଇଁ ପଦଗୁଡ଼ିକୁ ଓଲଟାଇ ଲେଖି ଯୋଗ କରାଯାଇପାରେ।

15 ରୁ 85 ପର୍ଯ୍ୟନ୍ତ ସଂଖ୍ୟାର ଯୋଗଫଳ:
S = 15+16+17+...+84+85
S = 85+84+83+...+16+15
2S = 100+100+100+...+100
ପଦସଂଖ୍ୟା = 85−15+1 = 71
ଅତଏବ S = 100×71/2 = 3550

୬. ଯୋଗଫଳ ସମ୍ପର୍କିତ ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ ଧାରଣା

ପ୍ରଥମ n ପ୍ରାକୃତିକ ସଂଖ୍ୟା: 1+2+...+n = n(n+1)/2
ପ୍ରଥମ n ବିଜୋଡ଼ ସଂଖ୍ୟା: 1+3+5+...+(2n−1) = n²
ପ୍ରଥମ n ଯୁଗ୍ମ ସଂଖ୍ୟା: 2+4+6+...+2n = n(n+1)
ପ୍ରଥମ n ଗଣନ ସଂଖ୍ୟାର ବର୍ଗର ଯୋଗ: 1²+2²+...+n² = n(n+1)(2n+1)/6
ପ୍ରଥମ n ଗଣନ ସଂଖ୍ୟାର ଘନର ଯୋଗ: 1³+2³+...+n³ = [n(n+1)/2]²

ଏହି ଧରଣର ଯୋଗଫଳକୁ A.P. ର ସୂତ୍ର ସହିତ ଯୋଗ କରି ବିଭିନ୍ନ ପ୍ରଶ୍ନ ସମାଧାନ କରାଯାଏ।

୭. A.P. ର ପଦମାନଙ୍କ ସମ୍ପର୍କ

ଏକ A.P. ର ତିନୋଟି ପଦକୁ ସୁବିଧା ପାଇଁ a−d, a, a+d ଭାବେ ନିଆଯାଇପାରେ। ଚାରୋଟି ପଦ ପାଇଁ a−3d, a−d, a+d, a+3d ଭାବେ ନିଆଯାଇପାରେ।

ଯଦି a−d, a, a+d ଏକ A.P. ର ତିନୋଟି ପଦ, ତେବେ ମଧ୍ୟମ ପଦ a ହେବ ଏବଂ ପ୍ରଥମ ଓ ତୃତୀୟ ପଦର ସାଧାରଣ ଅନ୍ତର d ରହିବ।
ତିନୋଟି ସଂଖ୍ୟା A.P. ରେ ଥିଲେ ମଧ୍ୟମ ସଂଖ୍ୟା = ପ୍ରଥମ ଓ ତୃତୀୟ ସଂଖ୍ୟାର ଗାଣିତିକ ମଧ୍ୟକ।
2 × ମଧ୍ୟମ ପଦ = ପ୍ରଥମ ପଦ + ତୃତୀୟ ପଦ

୮. ଦୁଇଟି ସଂଖ୍ୟା ମଧ୍ୟରେ A.M. ସ୍ଥାପନ

ଦୁଇଟି ସଂଖ୍ୟା a ଓ b ମଧ୍ୟରେ ଗୋଟିଏ Arithmetic Mean (A.M.) ସ୍ଥାପନ କରିବାକୁ ସେହି ତିନୋଟି ସଂଖ୍ୟାକୁ A.P. ରେ ନିଆଯାଏ।

A.M. = (a + b)/2
ଉଦାହରଣ: 12 ଓ 36 ମଧ୍ୟରେ ଗୋଟିଏ A.M.
A.M. = (12+36)/2 = 24
ତେଣୁ 12, 24, 36 ଏକ A.P.

ଏକାଧିକ A.M. ସ୍ଥାପନ କରିବାକୁ A.P. ର n-ତମ ପଦର ସୂତ୍ର ଓ ସାଧାରଣ ଅନ୍ତର ବ୍ୟବହାର କରାଯାଏ।

୯. A.P. ରେ ଥିବା ପଦମାନଙ୍କ ଯୋଗଫଳର ବିଶେଷ ରୂପ

ଅଧ୍ୟାୟର ଅଭ୍ୟାସଗୁଡ଼ିକରେ A.P. ର ପଦମାନଙ୍କ ଯୋଗଫଳକୁ ବୀଜଗାଣିତିକ ରୂପରେ ପରିବର୍ତ୍ତନ କରି ସମାଧାନ କରିବାକୁ କୁହାଯାଇଛି। ଯଥା:

  • n-ତମ ପଦ ଦିଆଥିଲେ ପ୍ରଥମ n ପଦର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ।
  • କିଛି ପଦର ଯୋଗଫଳ ଦିଆଥିଲେ ଅଜ୍ଞାତ ପଦସଂଖ୍ୟା ନିର୍ଣ୍ଣୟ।
  • ଦୁଇଟି ନିର୍ଦ୍ଦିଷ୍ଟ ପଦ ଦିଆଥିଲେ a ଓ d ନିର୍ଣ୍ଣୟ।
  • ଏକାଧିକ A.P. ର ଯୋଗଫଳ ମଧ୍ୟରେ ସମ୍ପର୍କ ପ୍ରମାଣ କରିବା।
  • A.P. ରେ ଥିବା ମଧ୍ୟକ ସ୍ଥାପନ କରିବା।
ସମାଧାନ ପାଇଁ ସାଧାରଣ ପଦ୍ଧତି:
(୧) ପ୍ରଥମ ପଦ a ଚିହ୍ନଟ କର → (୨) d ନିର୍ଣ୍ଣୟ କର → (୩) n-ତମ ପଦ ବା Sₙ ସୂତ୍ର ବାଛ → (୪) ଦତ୍ତ ମାନ ବସାଅ → (୫) ଉତ୍ତର ଯାଞ୍ଚ କର।

୧୦. ଅଧ୍ୟାୟର ଅଭ୍ୟାସରେ ଥିବା ପ୍ରଶ୍ନର ପ୍ରକାର

  1. A.P. ଚିହ୍ନଟ କରି a ଓ d ନିର୍ଣ୍ଣୟ।
  2. ନିର୍ଦ୍ଦିଷ୍ଟ n-ତମ ପଦ ନିର୍ଣ୍ଣୟ।
  3. ପ୍ରଥମ n ପଦର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ।
  4. ଯୋଗଫଳ ଦିଆଥିଲେ ପଦସଂଖ୍ୟା ନିର୍ଣ୍ଣୟ।
  5. ଦୁଇଟି ସଂଖ୍ୟା ମଧ୍ୟରେ ଗୋଟିଏ କିମ୍ବା ଅଧିକ A.M. ସ୍ଥାପନ।
  6. A.P. ରେ ଥିବା ପଦମାନଙ୍କୁ ନେଇ ପ୍ରମାଣ କରିବା।
  7. ପ୍ରାକୃତିକ ସଂଖ୍ୟା, ବର୍ଗ ଓ ଘନର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ।
  8. ଦିଆଯାଇଥିବା ଧାରାର nଟି ପଦ ପର୍ଯ୍ୟନ୍ତ ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ।

୧୧. ମନେ ରଖିବା ପାଇଁ ମୁଖ୍ୟ ସୂତ୍ର

ବିଷୟସୂତ୍ର
n-ତମ ପଦtₙ = a + (n−1)d
ପ୍ରଥମ n ପଦର ଯୋଗSₙ = n/2 [2a + (n−1)d]
ଶେଷ ପଦ l ଦିଆଥିଲେSₙ = n/2 (a+l)
ଗୋଟିଏ A.M.(a+b)/2
1 ରୁ n ଯୋଗn(n+1)/2
1² ରୁ n² ଯୋଗn(n+1)(2n+1)/6
1³ ରୁ n³ ଯୋଗ[n(n+1)/2]²

୧୨. ପରୀକ୍ଷା ପାଇଁ ଶେଷ ପୁନରାବୃତ୍ତି

ପ୍ରଥମେ: A.P. କି ନୁହେଁ ଚିହ୍ନଟ କର।
ତାପରେ: a ଓ d ଲେଖ।
n-ତମ ପଦ ଦରକାର: tₙ = a+(n−1)d ବ୍ୟବହାର କର।
ପ୍ରଥମ n ପଦର ଯୋଗ ଦରକାର: Sₙ ର ସୂତ୍ର ବ୍ୟବହାର କର।
A.M. ଦରକାର: ମଧ୍ୟମ ପଦ ଧାରଣା ବ୍ୟବହାର କର।
ଶେଷରେ: ମାନଗୁଡ଼ିକ ବସାଇ ଉତ୍ତର ଯାଞ୍ଚ କର।
