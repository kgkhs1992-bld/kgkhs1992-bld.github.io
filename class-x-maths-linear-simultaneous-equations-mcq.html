🎯 Multiple Choice Questions

Question 1

The pair of equations x + y = 7 and x − y = 1 has the solution:

A. x = 3, y = 4
B. x = 4, y = 3
C. x = 5, y = 2
D. x = 2, y = 5
✅ Show Answer
Correct Answer: B. x = 4, y = 3

Question 2

Which method involves expressing one variable in terms of the other?

A. Substitution Method
B. Graphical Method
C. Cross-Multiplication Method
D. Cramer's Rule
✅ Show Answer
Correct Answer: A. Substitution Method

Question 3

For the equations 2x + 3y = 13 and 4x − 3y = 5, the value of x is:

A. 2
B. 3
C. 4
D. 5
✅ Show Answer
Correct Answer: B. x = 3

Question 4

If two straight lines intersect at exactly one point, the pair of linear equations has:

A. No solution
B. Exactly one solution
C. Infinitely many solutions
D. No variables
✅ Show Answer
Correct Answer: B. Exactly one solution

Question 5

If two equations represent the same straight line, the pair has:

A. No solution
B. One solution
C. Infinitely many solutions
D. Two solutions only
✅ Show Answer
Correct Answer: C. Infinitely many solutions

Question 6

The equations 2x + 4y = 8 and x + 2y = 4 represent:

A. Two parallel lines
B. The same line
C. Two intersecting lines
D. Perpendicular lines
✅ Show Answer
Correct Answer: B. The same line

Question 7

When two straight lines are parallel, the corresponding pair of linear equations has:

A. One solution
B. Two solutions
C. No solution
D. Infinitely many solutions
✅ Show Answer
Correct Answer: C. No solution

Question 8

Which method eliminates one variable by adding or subtracting suitable multiples of the equations?

A. Substitution Method
B. Elimination Method
C. Graphical Method
D. Factorisation Method
✅ Show Answer
Correct Answer: B. Elimination Method

Question 9

The graphical solution of two linear equations is represented by:

A. The point where the two lines intersect
B. The midpoint of the lines
C. The slope only
D. The y-axis only
✅ Show Answer
Correct Answer: A. The point where the two lines intersect

Question 10

For a pair of equations with infinitely many solutions, the two equations represent:

A. Parallel lines
B. The same line
C. Perpendicular lines
D. Two separate curves
✅ Show Answer
Correct Answer: B. The same line

Question 11

For the equations 3x + 2y = 16 and 3x − 2y = 8, the value of x is:

A. 2
B. 3
C. 4
D. 5
✅ Show Answer
Correct Answer: C. x = 4

Question 12

Cramer's Rule is used to solve a pair of:

A. Linear simultaneous equations
B. Quadratic equations only
C. Cubic equations only
D. Trigonometric equations only
✅ Show Answer
Correct Answer: A. Linear simultaneous equations

Question 13

If the two lines of a pair of linear equations do not meet, then the pair has:

A. One solution
B. No solution
C. Infinitely many solutions
D. Three solutions
✅ Show Answer
Correct Answer: B. No solution

Question 14

The equations x + y = 5 and x − y = 1 have the solution:

A. x = 2, y = 3
B. x = 3, y = 2
C. x = 4, y = 1
D. x = 1, y = 4
✅ Show Answer
Correct Answer: B. x = 3, y = 2

Question 15

Which of the following is an important step after obtaining the values of x and y?

A. Ignore the original equations
B. Verify the values in the original equations
C. Change the equations
D. Remove one variable
✅ Show Answer
Correct Answer: B. Verify the values in the original equations
