Arithmetic Progression (A.P.) • Solved Examples

Class X Mathematics • KGKHS Beldandia

📌 ଆବଶ୍ୟକ ସୂତ୍ର

tₙ = a + (n − 1)d
Sₙ = n/2 [2a + (n − 1)d]
Sₙ = n/2 (a + l)

a = ପ୍ରଥମ ପଦ, d = ସାଧାରଣ ଅନ୍ତର, n = ପଦ ସଂଖ୍ୟା, l = ଶେଷ ପଦ।

ଉଦାହରଣ – ୧ : A.P. ଚିହ୍ନଟ ଓ n-ତମ ପଦ

ନିମ୍ନଲିଖିତ ଅନୁକ୍ରମଗୁଡ଼ିକ A.P. କି ନୁହେଁ ଦେଖାଅ ଏବଂ ଆବଶ୍ୟକ ସ୍ଥଳରେ ସାଧାରଣ ପଦ ନିର୍ଣ୍ଣୟ କର।
(i) −18, −16, −14, −12, ...
a = −18
d = −16 − (−18) = 2
ଅତଏବ ଏହା A.P. ଅଟେ।
tₙ = a + (n−1)d = −18 + 2(n−1)
tₙ = 2n − 20
(ii) −11, 0, 11, 22, 33, ...
a = −11
d = 0−(−11) = 11 = 11−0 = 22−11
ତେଣୁ A.P. ଏବଂ tₙ = −11 + 11(n−1)
tₙ = 11n − 22
ଉତ୍ତର: ଉଭୟ ଅନୁକ୍ରମ A.P. ଅଟନ୍ତି।

ଉଦାହରଣ – ୨ : ଓଲଟାଇ ମିଶାଇବା ପଦ୍ଧତି ଓ A.P. ଯୋଗଫଳ

(a) 15 ଠାରୁ 85 ପର୍ଯ୍ୟନ୍ତ ଗଣନ ସଂଖ୍ୟାମାନଙ୍କର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।
S = 15 + 16 + 17 + ... + 84 + 85
S = 85 + 84 + 83 + ... + 16 + 15
2S = 100 + 100 + 100 + ... + 100
ପଦ ସଂଖ୍ୟା = (85−15)+1 = 71
2S = 100 × 71
S = 50 × 71 = 3550
ଉତ୍ତର: 3550
(b) ଗୋଟିଏ A.P. ର ପ୍ରଥମ ପଦ 4 ଓ ସାଧାରଣ ଅନ୍ତର 3। A.P. ଲେଖ, 33ତମ ପଦ ଓ ପ୍ରଥମ 40ଟି ପଦର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।
(i) A.P. = 4, 7, 10, 13, ...
(ii) t₃₃ = 4 + (33−1)×3 = 4+96 = 100
(iii) S₄₀ = 40/2 [2×4 + (40−1)×3]
= 20(8+117) = 20×125 = 2500
ଉତ୍ତର: 33ତମ ପଦ = 100; S₄₀ = 2500

ଉଦାହରଣ – ୩ : ଦୁଇଟି ପଦ ଦିଆଥିଲେ A.P. ନିର୍ଣ୍ଣୟ

ଗୋଟିଏ A.P. ର t₄ = 11, t₁₀ = 16 ହେଲେ t₄₀ ଏବଂ ପ୍ରଥମ 40ଟି ପଦର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।
ମନେକର ପ୍ରଥମ ପଦ = a ଏବଂ ସାଧାରଣ ଅନ୍ତର = d।
t₄ = a+3d = 11 ...(1)
t₁₀ = a+9d = 16 ...(2)
(2)−(1): 6d = 5 ⇒ d = 5/6
a + 3(5/6) = 11 ⇒ a = 17/2
t₄₀ = a + 39d = 17/2 + 39×5/6 = 39
S₄₀ = 40/2 [2a + 39d]
= 20[17 + 195/6] = 20×49.5 = 990
ଉତ୍ତର: t₄₀ = 39 ଏବଂ S₄₀ = 990

ଉଦାହରଣ – ୪ : 2, 4, 6, 8, ... ର S₅₀

2, 4, 6, 8, ... ଅନୁକ୍ରମର S₅₀ ନିର୍ଣ୍ଣୟ କର।
d = 4−2 = 2 = 6−4 = 8−6
ଅତଏବ A.P. ର a = 2, d = 2, n = 50
S₅₀ = 50/2 [2×2 + (50−1)×2]
= 25(4+98) = 25×102 = 2550
ଉତ୍ତର: S₅₀ = 2550

ଉଦାହରଣ – ୫ : ଯୋଗଫଳ 132 ହେବା ପାଇଁ ପଦ ସଂଖ୍ୟା

27 + 24 + 21 + ... ର କେତୋଟି ପଦ ଯୋଗ କଲେ ଯୋଗଫଳ 132 ହେବ? ଦୁଇଟି ଉତ୍ତରର କାରଣ ବୁଝାଅ।
a = 27, d = 24−27 = −3
Sₙ = 132
132 = n/2 [54 + (n−1)(−3)]
132 = n/2 (57−3n)
264 = 57n−3n²
n²−19n+88 = 0
(n−11)(n−8)=0
n = 11 କିମ୍ବା n = 8

ଦୁଇଟି ଉତ୍ତର ସମ୍ଭବ। କାରଣ 9ମ, 10ମ ଓ 11ତମ ପଦ ଯଥାକ୍ରମେ 3, 0, −3; ଏହି ତିନୋଟିର ଯୋଗ 0। ତେଣୁ S₈ = S₁₁ = 132।

ଉତ୍ତର: 8ଟି କିମ୍ବା 11ଟି ପଦ

ଉଦାହରଣ – ୬ : tₙ ଦିଆଥିଲେ Sₙ

ଗୋଟିଏ ଅନୁକ୍ରମର tₙ = 2n + 3 ହେଲେ Sₙ ନିର୍ଣ୍ଣୟ କର।
n=1 ରଖିଲେ t₁ = 2×1+3 = 5 ⇒ a = 5
t₂ = 7 ଏବଂ t₃ = 9
d = 7−5 = 2 = 9−7
ତେଣୁ ଏହା A.P. ଏବଂ a=5, d=2
Sₙ = n/2 [2×5 + (n−1)×2]
= n/2 (10+2n−2)
= n(n+4) = n²+4n
ଉତ୍ତର: Sₙ = n² + 4n

ଉଦାହରଣ – ୭ : Sₙ ଦିଆଥିଲେ t₇

ଗୋଟିଏ ଅନୁକ୍ରମର Sₙ = 3n + 4n² ହେଲେ t₇ କେତେ?
Sₙ₋₁ = 3(n−1) + 4(n−1)²
= 3n−3 + 4n²−8n+4 = 4n²−5n+1
Sₙ = Sₙ₋₁ + tₙ
3n+4n² = 4n²−5n+1+tₙ
tₙ = 8n−1
n=7 ରଖିଲେ t₇ = 8×7−1 = 55
ଉତ୍ତର: t₇ = 55

ଉଦାହରଣ – ୮ : A.P. ରୁ ନୂତନ A.P. ପ୍ରମାଣ

ପ୍ରମାଣ କର ଯେ, ଯଦି a², b², c² ସଂଖ୍ୟାତ୍ରୟ A.P. ରେ ରହନ୍ତି, ତେବେ 1/(b+c), 1/(c+a), 1/(a+b) ମଧ୍ୟ A.P. ରେ ରହିବେ।
ଯେହେତୁ a², b², c² A.P. ରେ ଅଛନ୍ତି, ତେଣୁ ଦୃଷ୍ଟବ୍ୟ 3 ଅନୁସାରେ ପ୍ରତ୍ୟେକ ପଦରେ ab+bc+ca ଯୋଗ କଲେ ନୂତନ ତିନୋଟି ପଦ ମଧ୍ୟ A.P. ରେ ରହିବେ।
a²+ab+bc+ca, b²+ab+bc+ca, c²+ab+bc+ca
= (a+b)(a+c), (a+b)(b+c), (b+c)(c+a)

ଏହି ତିନୋଟି A.P. ରେ ଥିବାରୁ ସମାନ ଅଶୂନ୍ୟ ସଂଖ୍ୟା ଦ୍ୱାରା ଭାଗ କଲେ ମଧ୍ୟ A.P. ରେ ରହିବେ।

ପ୍ରତ୍ୟେକ ପଦକୁ (a+b)(b+c)(c+a) ଦ୍ୱାରା ଭାଗ କଲେ:
1/(b+c), 1/(c+a), 1/(a+b)
ଅତଏବ 1/(b+c), 1/(c+a), 1/(a+b) A.P. ରେ ରହିବେ। ପ୍ରମାଣିତ।

ଉଦାହରଣ – ୯ : A.P. ର ସମମିତ ପଦମାନଙ୍କ ସମ୍ପର୍କ

ଦର୍ଶାଅ ଯେ, ଗୋଟିଏ A.P. ର tₘ₊ₙ + tₘ₋ₙ = 2tₘ।
ମନେକର A.P. ର ପ୍ରଥମ ପଦ a ଏବଂ ସାଧାରଣ ଅନ୍ତର d।
tₘ₊ₙ = a + (m+n−1)d
tₘ₋ₙ = a + (m−n−1)d
tₘ₊ₙ + tₘ₋ₙ = 2a + (2m−2)d
= 2[a+(m−1)d] = 2tₘ
ଅତଏବ tₘ₊ₙ + tₘ₋ₙ = 2tₘ। ପ୍ରମାଣିତ।

📝 ପରୀକ୍ଷାରେ ସମାଧାନ ଲେଖିବାର ନିୟମ

  1. ପ୍ରଥମେ a, d, n ଚିହ୍ନଟ କର।
  2. ପ୍ରଶ୍ନ ଅନୁଯାୟୀ tₙ କିମ୍ବା Sₙ ସୂତ୍ର ବାଛ।
  3. ପ୍ରତ୍ୟେକ ପଦକ୍ଷେପ ସ୍ପଷ୍ଟ ଭାବରେ ଲେଖ।
  4. ଋଣାତ୍ମକ d ଥିଲେ ଚିହ୍ନ ଭୁଲ କରିବା ନାହିଁ।
  5. ଶେଷରେ ଉତ୍ତରକୁ ଅଲଗା ଭାବେ ଲେଖ।
