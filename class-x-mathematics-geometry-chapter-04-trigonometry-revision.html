1. 📐 Trigonometric Ratios — ମୂଳ 6ଟି Ratio

sin θ = Perpendicular / Hypotenuse
cos θ = Base / Hypotenuse
tan θ = Perpendicular / Base
cosec θ = Hypotenuse / Perpendicular = 1/sin θ
sec θ = Hypotenuse / Base = 1/cos θ
cot θ = Base / Perpendicular = 1/tan θ

2. ⭐ Fundamental Relations

tan θ = sin θ / cos θ
cot θ = cos θ / sin θ
sin²θ + cos²θ = 1
1 + tan²θ = sec²θ
1 + cot²θ = cosec²θ
sec²θ − tan²θ = 1
cosec²θ − cot²θ = 1

4. 🔄 Associated Angles

90°−θ
sin(90°−θ)=cosθ
cos(90°−θ)=sinθ
tan(90°−θ)=cotθ
180°−θ
sin(180°−θ)=sinθ
cos(180°−θ)=−cosθ
tan(180°−θ)=−tanθ
Reciprocal relations
sec(90°−θ)=cosecθ
cosec(90°−θ)=secθ
cot(90°−θ)=tanθ

5. 🧭 120°, 135°, 150° — Sign Revision

ଏହି angles second quadrant ରେ ପଡ଼େ। ସେଠାରେ sine positive, କିନ୍ତୁ cosine ଓ tangent negative।

sin120° = sin60° = √3/2
cos120° = −cos60° = −1/2
tan120° = −tan60° = −√3
sin135° = √2/2,   cos135° = −√2/2,   tan135° = −1
sin150° = 1/2,   cos150° = −√3/2,   tan150° = −1/√3

6. ➕➖ Compound Angles — 4ଟି ମୁଖ୍ୟ Formula

sin(A+B)=sinA cosB + cosA sinB
sin(A−B)=sinA cosB − cosA sinB
cos(A+B)=cosA cosB − sinA sinB
cos(A−B)=cosA cosB + sinA sinB

7. 📌 Compound-Angle Tangent Formula

tan(A+B) = (tanA + tanB)/(1 − tanA tanB)
tan(A−B) = (tanA − tanB)/(1 + tanA tanB)
Exam memory: tan(A+B) ର denominator ରେ minus; tan(A−B) ର denominator ରେ plus।

8. 🔁 Useful Derived Identities

sin(A+B)+sin(A−B)=2sinA cosB
sin(A+B)−sin(A−B)=2cosA sinB
cos(A+B)+cos(A−B)=2cosA cosB
cos(A−B)−cos(A+B)=2sinA sinB

9. 🧮 Ratio-Given Question — Fast Method

ଯଦି tan θ = 5/12, then ନିଅନ୍ତୁ:

P : B = 5 : 12

Hypotenuse:

H = √(5²+12²) = √169 = 13
sinθ = 5/13    cosθ = 12/13    secθ = 13/12    cosecθ = 13/5    cotθ = 12/5

10. 🏗️ Height & Distance — Quick Method

  1. ପ୍ରଥମେ right triangle ଆଙ୍କନ୍ତୁ।
  2. Height = vertical/opposite side, distance = horizontal/adjacent side ଚିହ୍ନଟ କରନ୍ତୁ।
  3. Angle of elevation/depression ଚିହ୍ନଟ କରନ୍ତୁ।
  4. ଦିଆଥିବା sides ଅନୁସାରେ sin/cos/tan ବାଛନ୍ତୁ।
  5. ସାଧାରଣତଃ height-distance problem ରେ tanθ = height/distance ବହୁତ useful।
  6. ଶେଷରେ unit ଲେଖନ୍ତୁ।

11. ✍️ Identity Proof — 5-Step Method

Step 1
LHS ରୁ ଆରମ୍ଭ କରନ୍ତୁ।
Step 2
Fraction ରେ sin/cos କରିପାରନ୍ତୁ।
Step 3
Known identity ବ୍ୟବହାର କରନ୍ତୁ।
Step 4

Step 5
RHS ମିଳିଲେ proof complete କରନ୍ତୁ।
