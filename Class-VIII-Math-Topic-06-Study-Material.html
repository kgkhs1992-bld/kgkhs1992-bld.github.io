✖️ ଶ୍ରେଣୀ–VIII ଗଣିତ

ବିଷୟ ୦୬ — ବାଣ୍ଟିଲେ ବଢ଼େ

📘 Study Material

🧠 ପାଠର ମୁଖ୍ୟ ଧାରଣା

ଏହି ଅଧ୍ୟାୟରେ ଗୁଣନର କିଛି ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ ଗୁଣଧର୍ମ, ବିଶେଷକରି ବଣ୍ଟନ ଗୁଣଧର୍ମ (Distributive Property), ରାଶିକୁ ବିଭାଜନ କରି ଗୁଣନକୁ ସହଜ କରିବା ଏବଂ ବୀଜଗାଣିତିକ ରାଶିରେ ଏହି ନିୟମର ବ୍ୟବହାର ଅଧ୍ୟୟନ କରାଯାଏ।

ମୁଖ୍ୟ ଶବ୍ଦ: Multiplication • Distributive Property • Algebraic Expression • Common Factor • Simplification
1️⃣ ବଣ୍ଟନ ଗୁଣଧର୍ମ

ଗୋଟିଏ ସଂଖ୍ୟାକୁ ଅନ୍ୟ ଦୁଇଟି ସଂଖ୍ୟାର ଯୋଗ ସହ ଗୁଣ କଲେ, ସେହି ସଂଖ୍ୟାକୁ ପ୍ରତ୍ୟେକ ପଦ ସହ ଅଲଗା ଅଲଗା ଗୁଣ କରି ଫଳଗୁଡ଼ିକୁ ଯୋଗ କରିହୁଏ।

a(b + c) = ab + ac

ଏହାକୁ ଗୁଣନର ବଣ୍ଟନ ଗୁଣଧର୍ମ କୁହାଯାଏ।

2️⃣ ସଂଖ୍ୟାରେ ବ୍ୟବହାର

ଉଦାହରଣ: 23 × 27 କୁ 23 × (20 + 7) ଭାବରେ ଲେଖିଲେ:

23 × 27 = 23 × (20 + 7) = 23×20 + 23×7 = 460 + 161 = 621

ଏହି ପଦ୍ଧତିରେ ଗୁଣନକୁ ଛୋଟ ଅଂଶରେ ବାଣ୍ଟି ହିସାବ କରିବା ସହଜ ହୁଏ।

3️⃣ ବିୟୋଗ ସହ ବଣ୍ଟନ

ବଣ୍ଟନ ଗୁଣଧର୍ମ ବିୟୋଗରେ ମଧ୍ୟ ପ୍ରୟୋଗ ହୁଏ:

a(b − c) = ab − ac

ଉଦାହରଣ: 23 × 27 = 23 × (30 − 3) = 23×30 − 23×3 = 690 − 69 = 621।

4️⃣ ବୀଜଗାଣିତିକ ରାଶିରେ ବ୍ୟବହାର

ବଣ୍ଟନ ଗୁଣଧର୍ମ ଦ୍ୱାରା ବୀଜଗାଣିତିକ ରାଶିକୁ ବିସ୍ତାର କରିହୁଏ।

a(b + c) = ab + ac
(a + b)(c + d) = ac + ad + bc + bd

ପ୍ରତ୍ୟେକ ପଦକୁ ଅନ୍ୟ ବ୍ରାକେଟର ପ୍ରତ୍ୟେକ ପଦ ସହ ଗୁଣ କରି ସରଳ ରାଶି ପାଇଯାଏ।

5️⃣ ଉଭୟ ପଟେ ବଣ୍ଟନ

ଦୁଇଟି ବ୍ରାକେଟରେ ଥିବା ପଦଗୁଡ଼ିକୁ ଗୁଣ କରିବାବେଳେ ପ୍ରଥମ ବ୍ରାକେଟର ପ୍ରତ୍ୟେକ ପଦକୁ ଦ୍ୱିତୀୟ ବ୍ରାକେଟର ପ୍ରତ୍ୟେକ ପଦ ସହ ଗୁଣ କରିବା ଦରକାର।

(x + y)(m + n) = xm + xn + ym + yn
⭐ ଦ୍ରୁତ ପୁନରାବୃତ୍ତି
a(b+c) = ab+ac
a(b−c) = ab−ac
23×27 = 23×(20+7) = 621
(a+b)(c+d) = ac+ad+bc+bd
