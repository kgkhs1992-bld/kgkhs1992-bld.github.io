Chapter Overview

Project is the final detailed-text unit of the Class IX English book. The textbook explains that project writing is included to meet practical communicative needs. A project should involve a clear topic, purposeful collection of information, organization and presentation.

What a Good Project Contains

  1. Title and topic
  2. Purpose or objectives
  3. Plan and method of collecting information
  4. Relevant information from reliable sources
  5. Proper arrangement under headings
  6. Tables, lists or illustrations where useful
  7. Conclusion or findings
  8. Source/acknowledgement section

Project Writing Skills

Planning: Decide the topic, questions and work schedule.
Research: Collect relevant information through books, observation, interviews or other appropriate sources.
Organization: Arrange information logically rather than copying unrelated facts.
Presentation: Use clear headings, readable writing, tables and suitable illustrations.
Conclusion: State what the project shows or what was learned.

Suggested School Project Format

Cover → Certificate/Acknowledgement → Introduction → Objectives → Method → Main Information → Findings → Conclusion → Sources
