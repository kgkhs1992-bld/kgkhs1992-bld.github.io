CHAPTER 01 — LINEAR SIMULTANEOUS EQUATIONS

🧮 Solved Examples

This page provides step-by-step examples for solving pairs of linear simultaneous equations using different methods.

Methods covered: Substitution, Elimination, Cross-Multiplication, Graphical Method and Cramer's Rule.

✏️ Example 1 — Substitution Method

Question

Solve:

x + y = 7
2x − y = 5

Step 1 — Express one variable

From the first equation:

y = 7 − x

Step 2 — Substitute

Substitute this value of y in the second equation:

2x − (7 − x) = 5
2x − 7 + x = 5
3x = 12
x = 4

Step 3 — Find y

y = 7 − 4 = 3
Answer: x = 4, y = 3

➗ Example 2 — Elimination Method

Question

Solve:

2x + 3y = 13
4x − 3y = 5

Step 1 — Add the equations

(2x + 3y) + (4x − 3y) = 13 + 5
6x = 18
x = 3

Step 2 — Substitute x = 3

2(3) + 3y = 13
6 + 3y = 13
3y = 7
y = 7/3
Answer: x = 3, y = 7/3

🔄 Example 3 — Elimination by Subtraction

Question

Solve:

3x + 2y = 16
3x − 2y = 8

Step 1 — Subtract the second equation from the first

(3x + 2y) − (3x − 2y) = 16 − 8
4y = 8
y = 2

Step 2 — Find x

3x + 2(2) = 16
3x + 4 = 16
3x = 12
x = 4
Answer: x = 4, y = 2

📐 Example 4 — Graphical Interpretation

Question

Consider:

x + y = 5
x − y = 1

Each equation represents a straight line. The common point of the two lines is the solution.

Algebraic verification

2x = 6
x = 3
y = 5 − 3 = 2
The two lines intersect at (3, 2).
Therefore, the solution is x = 3, y = 2.

📊 Example 5 — Identifying No Solution

Question

Examine:

2x + 4y = 8
x + 2y = 5

Write the equations in comparable form:

2x + 4y = 8
2x + 4y = 10

The left-hand sides are identical but the right-hand sides are different. Therefore the two equations cannot be satisfied simultaneously.

There is no solution.

♾️ Example 6 — Infinitely Many Solutions

Question

Consider:

2x + 4y = 8
x + 2y = 4

Multiplying the second equation by 2 gives:

2x + 4y = 8

Both equations represent the same line.

Therefore, the pair has infinitely many solutions.
