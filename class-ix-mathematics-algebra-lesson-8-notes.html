📝 Study Material

1. Probability
Probability ହେଉଛି କୌଣସି event ଘଟିବାର chanceକୁ ମାପିବାର ଏକ ପଦ୍ଧତି।
2. Experiment
ଯେଉଁ ପ୍ରକ୍ରିୟାରେ observation/result ମିଳେ, ତାହାକୁ experiment କୁହାଯାଏ। ଯଥା coin toss କିମ୍ବା dice throw।
3. Observation
Experiment କରି ଯେଉଁ result ମିଳେ, ତାହା observation। Coin tossର result Head (H) କିମ୍ବା Tail (T) ହୋଇପାରେ।
4. Empirical Probability
ପ୍ରୟୋଗରେ event E, n ଥର experimentରେ m ଥର ଘଟିଲେ empirical probability = m/n।
5. Coin
ଏକ balanced coinକୁ ଏକଥର toss କଲେ Head ଓ Tail ଦୁଇଟି equally likely outcomes। ପ୍ରତ୍ୟେକର theoretical probability 1/2।
6. Dice
ଏକ fair dieକୁ ଏକଥର throw କଲେ possible outcomes 1,2,3,4,5,6। ପ୍ରତ୍ୟେକ outcomeର probability 1/6।
7. Event
Experimentର possible outcomes ମଧ୍ୟରୁ ନିର୍ଦ୍ଦିଷ୍ଟ outcome କିମ୍ବା outcomesର setକୁ event କୁହାଯାଏ।
8. Theoretical Probability
ଯଦି ସମସ୍ତ outcomes equally likely, ତେବେ P(E) = favourable outcomes / total equally likely outcomes।
9. Probability Range
କୌଣସି event E ପାଇଁ 0 ≤ P(E) ≤ 1। P(E)=0 ହେଲେ event impossible; P(E)=1 ହେଲେ event certain।
10. Complementary Event
E ଘଟିବା ନୁହେଁ ବୋଲି eventକୁ complementary event ଭାବେ ନିଆଯାଏ। P(E)+P(not E)=1।
11. Example
ଏକ dieରେ even number ଆସିବାର favourable outcomes = 2,4,6, ଅର୍ଥାତ 3ଟି। ତେଣୁ P(even)=3/6=1/2।
12. Experimental Observation
Textbookରେ repeated coin/dice experiments ଦ୍ୱାରା observed frequency ଓ empirical probability ଦେଖାଯାଇଛି। Trial ବଢ଼ିଲେ experimental probability theoretical value ନିକଟକୁ ଯାଇପାରେ।

🔁 Quick Revision

Empirical probability = favourable occurrence / total trials

Theoretical probability = favourable outcomes / total equally likely outcomes

Range: 0 ≤ P(E) ≤ 1

Complement: P(E) + P(not E) = 1
