Question 1 – Solve by substitution method
(i) x + y − 8 = 0,   2x − 3y − 1 = 0
(ii) 3x + 2y − 5 = 0,   x − 3y − 9 = 0
(iii) 2x − 5y + 8 = 0,   x − 4y + 7 = 0
(iv) 11x + 15y + 23 = 0,   7x − 2y − 20 = 0
(v) ax + by − a + b = 0,
bx − ay − a − b = 0
(vi) x + y − a = 0,
ax + by − b² = 0
✅ Answers
(i) x = 5, y = 3
(5, 3)
(ii) x = 3, y = −2
(3, −2)
(iii) x = 1, y = 2
(1, 2)
(iv) x = 2, y = −3
(2, −3)
(v) x = 1, y = −1
(1, −1)
(vi) x = −b, y = a + b
(−b, a + b)
