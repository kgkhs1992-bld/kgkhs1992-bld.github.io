🔑 ଦରକାରୀ ସୂତ୍ର

sin θ = P/H   |   cos θ = B/H   |   tan θ = P/B

cot θ = B/P   |   sec θ = H/B   |   cosec θ = H/P

sin²θ + cos²θ = 1

1 + tan²θ = sec²θ

1 + cot²θ = cosec²θ

sin(90°−θ)=cosθ,   cos(90°−θ)=sinθ

sin(A+B)=sinA cosB + cosA sinB

sin(A−B)=sinA cosB − cosA sinB

cos(A+B)=cosA cosB − sinA sinB

cos(A−B)=cosA cosB + sinA sinB

🧮 Solved Example 01 – ଏକ ratio ରୁ ଅନ୍ୟ ratio

ପ୍ରଶ୍ନ: sin θ = 3/5 ହେଲେ cos θ ନିର୍ଣ୍ଣୟ କରନ୍ତୁ, ଯେଉଁଠାରେ θ ଏକ ତୀକ୍ଷ୍ଣ କୋଣ।

ସମାଧାନ:

sin²θ + cos²θ = 1

9/25 + cos²θ = 1

cos²θ = 16/25

cos θ = 4/5

ଉତ୍ତର: cos θ = 4/5

🧮 Solved Example 02 – tan ରୁ sec

ପ୍ରଶ୍ନ: tan θ = 3/4 ହେଲେ sec θ ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

1 + tan²θ = sec²θ

1 + (3/4)² = sec²θ

1 + 9/16 = 25/16

sec θ = 5/4

ଉତ୍ତର: sec θ = 5/4

🧮 Solved Example 03 – cot ରୁ cosec

ପ୍ରଶ୍ନ: cot θ = 5/12 ହେଲେ cosec θ ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

1 + cot²θ = cosec²θ

1 + 25/144 = cosec²θ

169/144 = cosec²θ

cosec θ = 13/12

ଉତ୍ତର: cosec θ = 13/12

🧮 Solved Example 04 – Standard Values

ପ୍ରଶ୍ନ: sin60° + cos60° ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

sin60° = √3/2 ଏବଂ cos60° = 1/2

∴ sin60° + cos60° = √3/2 + 1/2

= (√3 + 1)/2

🧮 Solved Example 05 – Reciprocal Relations

ପ୍ରଶ୍ନ: sec60° + cosec30° ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

sec60° = 2

cosec30° = 2

∴ 2 + 2 = 4

ଉତ୍ତର: 4

🧮 Solved Example 06 – Complementary Angle

ପ୍ରଶ୍ନ: sin(90°−30°) ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

sin(90°−θ) = cosθ

ତେଣୁ sin(90°−30°) = cos30°

= √3/2

🧮 Solved Example 07 – 180°−θ

ପ୍ରଶ୍ନ: cos150° ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

150° = 180°−30°

cos(180°−θ) = −cosθ

∴ cos150° = −cos30°

= −√3/2

🧮 Solved Example 08 – Quadrant Sign

ପ୍ରଶ୍ନ: tan135° ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

135° = 180°−45°

tan(180°−θ) = −tanθ

∴ tan135° = −tan45° = −1

ଉତ୍ତର: −1

🧮 Solved Example 09 – Identity Verification

ପ୍ରଶ୍ନ: θ=30° ପାଇଁ sin²θ + cos²θ ର ମାନ ଯାଞ୍ଚ କରନ୍ତୁ।

ସମାଧାନ:

sin30°=1/2, cos30°=√3/2

sin²30° + cos²30° = 1/4 + 3/4

= 1

ଅତଏବ identity ସଠିକ୍।

🧮 Solved Example 10 – Identity ଦ୍ୱାରା ମାନ

ପ୍ରଶ୍ନ: tan θ = 5/12 ହେଲେ sec θ ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

1+tan²θ=sec²θ

= 1 + 25/144 = 169/144

secθ = 13/12

ଉତ୍ତର: sec θ = 13/12

🧮 Solved Example 11 – Compound Angle: sin75°

ପ୍ରଶ୍ନ: sin75° ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

75° = 45° + 30°

sin(A+B)=sinAcosB+cosAsinB

sin75° = sin45°cos30° + cos45°sin30°

= (1/√2)(√3/2) + (1/√2)(1/2)

= (√3+1)/(2√2)

🧮 Solved Example 12 – Compound Angle: cos75°

ପ୍ରଶ୍ନ: cos75° ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

75°=45°+30°

cos(A+B)=cosAcosB−sinAsinB

cos75°=(1/√2)(√3/2)−(1/√2)(1/2)

=(√3−1)/(2√2)

🧮 Solved Example 13 – Compound Angle: sin15°

ପ୍ରଶ୍ନ: sin15° ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

15° = 45°−30°

sin(A−B)=sinAcosB−cosAsinB

sin15°=(1/√2)(√3/2)−(1/√2)(1/2)

=(√3−1)/(2√2)

🧮 Solved Example 14 – Compound Angle: cos15°

ପ୍ରଶ୍ନ: cos15° ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

15°=45°−30°

cos(A−B)=cosAcosB+sinAsinB

cos15°=(1/√2)(√3/2)+(1/√2)(1/2)

=(√3+1)/(2√2)

🧮 Solved Example 15 – tan(A+B)

ପ୍ରଶ୍ନ: tan75° ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

75°=45°+30°

tan(A+B)=(tanA+tanB)/(1−tanAtanB)

tan75°=(1+1/√3)/(1−1/√3)

ଉପର ଓ ତଳକୁ √3 ଦ୍ୱାରା ଗୁଣ କଲେ:

=(√3+1)/(√3−1)

rationalise କଲେ:

tan75° = 2+√3

🧮 Solved Example 16 – ଏକାଧିକ ratio ନିର୍ଣ୍ଣୟ

ପ୍ରଶ୍ନ: tanθ=3/4 ହେଲେ sinθ, cosθ, cotθ, secθ ଓ cosecθ ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

tanθ=P/B=3/4. ତେଣୁ P=3k, B=4k.

H=√(P²+B²)=√(9k²+16k²)=5k.

∴ sinθ=P/H=3/5

cosθ=B/H=4/5

cotθ=B/P=4/3

secθ=H/B=5/4

cosecθ=H/P=5/3

ଉତ୍ତର: sinθ=3/5, cosθ=4/5, cotθ=4/3, secθ=5/4, cosecθ=5/3.

🧮 Solved Example 17 – ମିଶ୍ର expression

ପ୍ରଶ୍ନ: sin30°cos60° + cos30°sin60° ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

sin30°cos60°=(1/2)(1/2)=1/4

cos30°sin60°=(√3/2)(√3/2)=3/4

ଯୋଗ = 1/4+3/4

=1

ଏହା sin(30°+60°)=sin90°=1 ସହିତ ମଧ୍ୟ ସମାନ।

🧮 Solved Example 18 – ମିଶ୍ର expression

ପ୍ରଶ୍ନ: cos30°cos60° − sin30°sin60° ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

=(√3/2)(1/2) − (1/2)(√3/2)

= √3/4 − √3/4

=0

ଏହା cos(30°+60°)=cos90°=0 ସହିତ ସମାନ।

🧮 Solved Example 19 – Identity Based Simplification

ପ୍ରଶ୍ନ: (1−sin²θ) କୁ ସରଳ କରନ୍ତୁ।

ସମାଧାନ:

sin²θ+cos²θ=1

ତେଣୁ 1−sin²θ = cos²θ

ଉତ୍ତର: cos²θ

🧮 Solved Example 20 – Identity Based Simplification

ପ୍ରଶ୍ନ: (sec²θ−1) କୁ ସରଳ କରନ୍ତୁ।

ସମାଧାନ:

1+tan²θ=sec²θ

ତେଣୁ sec²θ−1=tan²θ

ଉତ୍ତର: tan²θ

🧮 Solved Example 21 – Identity Based Simplification

ପ୍ରଶ୍ନ: (cosec²θ−1) କୁ ସରଳ କରନ୍ତୁ।

ସମାଧାନ:

1+cot²θ=cosec²θ

ତେଣୁ cosec²θ−1=cot²θ

ଉତ୍ତର: cot²θ

🧮 Solved Example 22 – 90°+θ

🧮 Solved Example 24 – Exam Style 5-Mark Problem

ପ୍ରଶ୍ନ: tanθ=5/12 ହେଲେ sinθ, cosθ, secθ ଓ cosecθ ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ସମାଧାନ:

tanθ=P/B=5/12. ତେଣୁ P=5k, B=12k.

H=√(25k²+144k²)=√169k²=13k.

sinθ=5/13

cosθ=12/13

secθ=13/12

cosecθ=13/5

ଉତ୍ତର: sinθ=5/13, cosθ=12/13, secθ=13/12, cosecθ=13/5.

🧮 Solved Example 25 – Exam Style 5-Mark Problem

ପ୍ରଶ୍ନ: sinθ=8/17 ହେଲେ cosθ, tanθ ଓ secθ ନିର୍ଣ୍ଣୟ କରନ୍ତୁ, θ ତୀକ୍ଷ୍ଣ କୋଣ।

ସମାଧାନ:

sinθ=P/H=8/17. ତେଣୁ P=8k, H=17k.

B=√(H²−P²)=√(289−64)k=15k.

cosθ=B/H=15/17

tanθ=P/B=8/15

secθ=H/B=17/15

ଉତ୍ତର: cosθ=15/17, tanθ=8/15, secθ=17/15.

🧠 5-Mark Answer Writing Pattern

  1. ପ୍ରଶ୍ନରେ ଦିଆଯାଇଥିବା value ପ୍ରଥମେ ଲେଖନ୍ତୁ।
  2. ଉପଯୁକ୍ତ identity/formula ଲେଖନ୍ତୁ।
  3. Value substitute କରନ୍ତୁ।
  4. ପ୍ରତ୍ୟେକ algebraic step ଦେଖାନ୍ତୁ।
  5. ଶେଷରେ ଘେରା/ସ୍ପଷ୍ଟ ଭାବରେ final answer ଲେଖନ୍ତୁ।
ମନେ ରଖନ୍ତୁ: କେବଳ final answer ଲେଖିଲେ step-mark ହରାଇପାରେ। ବିଶେଷକରି 5-mark ପ୍ରଶ୍ନରେ formula → substitution → calculation → answer ରଖନ୍ତୁ।
