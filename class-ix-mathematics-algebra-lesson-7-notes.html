📝 Study Material

1. Statistics
Statisticsରେ data ସଂଗ୍ରହ, ବ୍ୟବସ୍ଥିତ କରିବା ଓ ପ୍ରଦର୍ଶନ କରିବାର ପ୍ରକ୍ରିୟା ଅଧ୍ୟୟନ କରାଯାଏ।
2. Data
ଯେକୌଣସି ବିଷୟ ସମ୍ପର୍କିତ ସଂଗୃହୀତ facts/valuesକୁ data କୁହାଯାଏ। Numerical data ସଂଖ୍ୟା ଆକାରରେ ଥାଏ।
3. Primary ଓ Secondary Data
ନିଜେ ପ୍ରଥମେ ସଂଗ୍ରହ କରାଯାଇଥିବା dataକୁ Primary data ଏବଂ ଅନ୍ୟ ଉତ୍ସରୁ ପାଇଥିବା dataକୁ Secondary data କୁହାଯାଏ।
4. Raw Data ଓ Array
ଅବ୍ୟବସ୍ଥିତ ଭାବରେ ଥିବା dataକୁ raw data କୁହାଯାଏ। Dataକୁ ascending କିମ୍ବା descending orderରେ ଲେଖିଲେ array ମିଳେ।
5. Frequency
କୌଣସି score/value କେତେଥର ଆସିଛି, ସେହି ସଂଖ୍ୟା ହେଉଛି frequency। Tally marks ଦ୍ୱାରା frequency ଗଣାଯାଇପାରେ।
6. Frequency Distribution Table
Score/value ଏବଂ ତାହାର frequencyକୁ ସାରଣୀରେ ଦେଖାଇଲେ frequency distribution table ମିଳେ।
7. Cumulative Frequency
ପ୍ରତ୍ୟେକ score ପର୍ଯ୍ୟନ୍ତ frequencyଗୁଡ଼ିକୁ କ୍ରମେ ଯୋଗ କଲେ cumulative frequency ମିଳେ। ଉଦାହରଣ: 30, 32, 36 ⇒ cumulative frequency 30, 62, 98।
8. Grouped Frequency Distribution
ବହୁ dataକୁ class/groupରେ ବିଭକ୍ତ କରି frequency ଦେଖାଇଲେ grouped frequency distribution ମିଳେ।
9. Class Interval
10–20, 20–30 ପରି intervalକୁ class କୁହାଯାଏ। Lower limit ହେଉଛି classର ଆରମ୍ଭ ମୂଲ୍ୟ ଏବଂ upper limit ଶେଷ ମୂଲ୍ୟ।
10. Mid-point
Classର mid-point = (Lower limit + Upper limit) / 2. ଉଦାହରଣ 10–20 ପାଇଁ mid-point = 15।
11. Class Size
Exclusive classificationରେ class size = upper limit − lower limit. Inclusive classificationରେ textbook ଅନୁସାରେ class size = (upper limit − lower limit) + 1.
12. Exclusive ଓ Inclusive Classification
Exclusive: 10–20, 20–30…; Inclusive: 10–19, 20–29…।

🔁 Quick Revision

Frequency = ଏକ value କେତେଥର ଆସିଛି

Cumulative frequency = କ୍ରମିକ frequencyର ଯୋଗ

Mid-point = (Lower + Upper)/2

Grouped data = class intervalsରେ ବିଭକ୍ତ data
