⚠️ Common Mistakes

1. Mean ରେ n ଭୁଲିବା

Mean=Σxᵢ/n

2. Median ପୂର୍ବରୁ order ନକରିବା

Data କୁ ascending କିମ୍ବା descending order କର।

3. Even observations ର Median

ଦୁଇ ମଧ୍ୟସ୍ଥ observation ର average ନିଅ।

4. Mode ଭୁଲ ଚିହ୍ନଟ

ସର୍ବାଧିକ frequency ଥିବା value ହେଉଛି Mode।

5. Mean property

Σ(xᵢ−M)=0
