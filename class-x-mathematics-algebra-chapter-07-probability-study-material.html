ଏହି Study Material ଶ୍ରେଣୀ–X ବୀଜଗଣିତ ପାଠ୍ୟପୁସ୍ତକର Chapter 07 ସମ୍ଭାବ୍ୟତା (Probability) ଅଂଶକୁ ଆଧାର କରି ପ୍ରସ୍ତୁତ। ପାଠ୍ୟପୁସ୍ତକରେ ଏହି ଅଧ୍ୟାୟଟି ମୁଖ୍ୟତଃ ଘଟଣା, ନମୁନା ସ୍ଥାନ (Sample Space), empirical/theoretical probability ଏବଂ ବିଭିନ୍ନ ଉଦାହରଣ ମାଧ୍ୟମରେ ବିଷୟଟି ବୁଝାଏ।

1️⃣ ଭୂମିକା — Introduction

ଦୈନନ୍ଦିନ ଜୀବନରେ କେତେକ ଘଟଣା ନିଶ୍ଚିତ ଭାବେ ଘଟେ, କେତେକ ଘଟଣା ଘଟିବ ନାହିଁ, ଆଉ କେତେକ ଘଟଣା ଘଟିପାରେ କିମ୍ବା ଘଟିନପାରେ। ଏପରି ଘଟଣାର ଘଟିବାର ସମ୍ଭାବନାକୁ ଗଣିତୀୟ ଭାବରେ ଅଧ୍ୟୟନ କରିବାକୁ ସମ୍ଭାବ୍ୟତା କୁହାଯାଏ।

  • ନିଶ୍ଚିତ ଘଟଣା → probability = 1
  • ଅସମ୍ଭବ ଘଟଣା → probability = 0
  • ଅନିଶ୍ଚିତ ଘଟଣା → probability 0 ଓ 1 ମଧ୍ୟରେ

2️⃣ ପରୀକ୍ଷଣ, ଫଳାଫଳ ଓ ଘଟଣା

Random Experiment: ଏପରି ଏକ ପରୀକ୍ଷଣ ଯାହାର ଫଳାଫଳ ପୂର୍ବରୁ ନିଶ୍ଚିତ ଭାବେ କୁହିହେବ ନାହିଁ, କିନ୍ତୁ ସମ୍ଭବ ଫଳାଫଳଗୁଡ଼ିକୁ ଜଣାଯାଇପାରେ।

Outcome: Random experiment ର ଗୋଟିଏ ସମ୍ଭବ ଫଳାଫଳ।

Event: ଗୋଟିଏ କିମ୍ବା ଅଧିକ outcome ର ସମୁହକୁ event କୁହାଯାଏ।

ଉଦାହରଣ: ଗୋଟିଏ ଛଅମୁହାଁ ଛକା ଥରେ ଗଡ଼ାଗଲା। ସମ୍ଭବ ଫଳାଫଳ: 1, 2, 3, 4, 5, 6। “ଯୁଗ୍ମ ସଂଖ୍ୟା ଆସିବା” ଏକ event ଏବଂ ଏହାର outcomes ହେଉଛି 2, 4, 6।

3️⃣ Sample Space — ନମୁନା ସ୍ଥାନ

Random experiment ର ସମସ୍ତ ସମ୍ଭବ outcome ର ସମୁହକୁ Sample Space କୁହାଯାଏ ଏବଂ ସାଧାରଣତଃ S ଦ୍ୱାରା ଦର୍ଶାଯାଏ।

ଛକା ଥରେ ଗଡ଼ାଇଲେ: S = {1, 2, 3, 4, 5, 6}
Event E: ଯୁଗ୍ମ ସଂଖ୍ୟା ଆସିବା ⇒ E = {2, 4, 6}

ଏଠାରେ E, S ର ଏକ subset।

4️⃣ Empirical Probability — ପରୀକ୍ଷଣାଧାରିତ ସମ୍ଭାବ୍ୟତା

କୌଣସି ପରୀକ୍ଷଣକୁ ଅନେକଥର କରି ଗୋଟିଏ event ଯେତେଥର ଘଟିଛି ତାହାର ଅନୁପାତରୁ empirical probability ନିର୍ଣ୍ଣୟ କରାଯାଏ।

P(E) = Event E ଘଟିଥିବା ଥର ସଂଖ୍ୟା ÷ ପରୀକ୍ଷଣର ସମୁଦାୟ ଥର ସଂଖ୍ୟା
ଉଦାହରଣ: ଗୋଟିଏ ଛକାକୁ 50 ଥର ଗଡ଼ାଗଲା ଏବଂ 6 ସଂଖ୍ୟା 9 ଥର ଆସିଲା।
P(6) = 9/50.

5️⃣ Theoretical Probability — ତାତ୍ତ୍ୱିକ ସମ୍ଭାବ୍ୟତା

ଯେତେବେଳେ experiment ର ସମସ୍ତ ସମ୍ଭବ outcome ସମାନ ଭାବରେ ସମ୍ଭବ (equally likely), ତେବେ event ର theoretical probability ବ୍ୟବହାର କରାଯାଏ।

P(E) = n(E) / n(S)

ଯେଉଁଠାରେ n(E) = event E ର favourable outcomes ସଂଖ୍ୟା ଏବଂ n(S) = sample space ର ସମୁଦାୟ outcomes ସଂଖ୍ୟା।

6️⃣ ଛକାର ଉଦାହରଣ

ପ୍ରଶ୍ନ: ଗୋଟିଏ fair die ଥରେ ଗଡ଼ାଗଲା। ଯୁଗ୍ମ ସଂଖ୍ୟା ଆସିବାର probability ନିର୍ଣ୍ଣୟ କର।

ସମାଧାନ:
S = {1,2,3,4,5,6}, ତେଣୁ n(S)=6।
E = {2,4,6}, ତେଣୁ n(E)=3।
P(E)=3/6=1/2.

7️⃣ ଦୁଇଟି ଛକା — Sample Space ର ଧାରଣା

ଦୁଇଟି ଛକା ଏକାସାଙ୍ଗରେ ଗଡ଼ାଇଲେ outcome ଗୁଡ଼ିକ ordered pair ଭାବରେ ଲେଖାଯାଇପାରେ:

S = {(1,1),(1,2),...,(1,6),(2,1),...,(6,6)}

ଏଠାରେ ମୋଟ outcome ସଂଖ୍ୟା = 6 × 6 = 36।

ଉଦାହରଣ: ଦୁଇ ଛକାର ଯୋଗ 7 ହେବାର favourable outcomes ହେଉଛି
(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)।
ତେଣୁ favourable outcomes = 6 ଏବଂ probability = 6/36 = 1/6।

8️⃣ Mutually Exclusive Events

ଦୁଇଟି event ଏକାସାଙ୍ଗରେ ଘଟିପାରେ ନାହିଁ ଯଦି, ସେମାନଙ୍କୁ mutually exclusive events କୁହାଯାଏ।

A ∩ B = ∅
ଉଦାହରଣ: ଗୋଟିଏ die ଗଡ଼ାଇବାରେ “1 ଆସିବା” ଓ “6 ଆସିବା” ଏକାସାଙ୍ଗରେ ଘଟିପାରେ ନାହିଁ।

9️⃣ Complementary Event

Event E ନଘଟିବାର event କୁ E ର complement କୁହାଯାଏ। ଏହାକୁ ସାଧାରଣତଃ E′ କିମ୍ବା E̅ ଭାବେ ଲେଖାଯାଏ।

P(E′) = 1 − P(E)
ଉଦାହରଣ: ଗୋଟିଏ die ରେ even number ଆସିବାର probability 1/2। ତେଣୁ odd number ଆସିବାର probability = 1 − 1/2 = 1/2।

🔟 Probability ର ମୁଖ୍ୟ ନିୟମ

ଘଟଣାସମ୍ଭାବ୍ୟତା
Impossible eventP(E)=0
Certain eventP(E)=1
Any event0 ≤ P(E) ≤ 1
ComplementP(E′)=1−P(E)
Equally likely outcomesP(E)=n(E)/n(S)

1️⃣1️⃣ ମୁଖ୍ୟ Formula Sheet

P(E) = n(E) / n(S)
P(E′) = 1 − P(E)
P(S) = 1
P(∅) = 0
0 ≤ P(E) ≤ 1

1️⃣2️⃣ ପରୀକ୍ଷା ପାଇଁ ପଦକ୍ରମ

  1. ପ୍ରଥମେ experiment ଓ sample space ଚିହ୍ନଟ କର।
  2. ସମସ୍ତ possible outcomes ଲେଖ।
  3. ପ୍ରଶ୍ନରେ ଦିଆଯାଇଥିବା event E ଲେଖ।
  4. favourable outcomes ଗଣି n(E) ନିର୍ଣ୍ଣୟ କର।
  5. ସମୁଦାୟ outcomes n(S) ନିର୍ଣ୍ଣୟ କର।
  6. P(E)=n(E)/n(S) ବ୍ୟବହାର କର।
  7. ଉତ୍ତରକୁ ସରଳ ଭାଗରେ ଲେଖ।

1️⃣3️⃣ Worked Examples — ଦ୍ରୁତ ଅଭ୍ୟାସ

Example 1: Coin toss: S={H,T}. P(H)=1/2.
Example 2: Die ରେ 5 ଠାରୁ ବଡ଼ ସଂଖ୍ୟା: E={6}. P(E)=1/6.
Example 3: Die ରେ prime number: E={2,3,5}. P(E)=3/6=1/2.
Example 4: Die ରେ number less than 4: E={1,2,3}. P(E)=3/6=1/2.
Example 5: Die ରେ odd number: E={1,3,5}. P(E)=3/6=1/2.
Example 6: Two dice sum 7: favourable outcomes 6, total 36. P=1/6.
Example 7: If P(E)=3/5, then P(E′)=1−3/5=2/5.
Example 8: If an event occurs 18 times in 60 trials, empirical P=18/60=3/10.

1️⃣4️⃣ ଧ୍ୟାନରେ ରଖନ୍ତୁ

  • Probability କେବେ 1 ଠାରୁ ଅଧିକ ହୁଏ ନାହିଁ।
  • Favourable outcomes ମାନେ ଆମ ଚାହୁଁଥିବା event କୁ satisfy କରୁଥିବା outcomes।
  • ଦୁଇଟି dice ରେ 6+6 ପରି ordered pair ଗୁଡ଼ିକୁ ଭିନ୍ନ outcome ଭାବେ ଗଣିବାକୁ ପଡ଼େ।
  • Empirical probability ଓ theoretical probability ର ଅର୍ଥ ଏକ ନୁହେଁ; ପ୍ରଥମଟି observed trials ଉପରେ ଏବଂ ଦ୍ୱିତୀୟଟି equally likely outcomes ଉପରେ ଆଧାରିତ।
