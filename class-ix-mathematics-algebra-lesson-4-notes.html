📝 Study Material

1. Algebraic Equation
ଯେଉଁ algebraic statementରେ equality sign (=) ଥାଏ ଏବଂ variableର ମୂଲ୍ୟ ଖୋଜିବାକୁ ପଡ଼େ, ତାହା algebraic equation।
2. Linear Equation in One Variable
ax + b = 0, ଯେଉଁଠାରେ a ≠ 0, ଏକ linear equation in one variable। ଏହାର solution/root ହେଉଛି x = −b/a.
3. Root / Solution
ଯେଉଁ x ମୂଲ୍ୟ equationକୁ ସତ୍ୟ କରେ, ସେହି ମୂଲ୍ୟକୁ root କିମ୍ବା solution କୁହାଯାଏ।
4. Consistent / In-consistent
ଯେଉଁ equationର solution ଥାଏ ତାହା consistent; solution ନଥିଲେ in-consistent।
5. Equivalent Equations
ଯେଉଁ equationsର solution set ସମାନ, ସେଗୁଡ଼ିକ equivalent equations।
6. Identity
ଯେଉଁ equation variableର ପ୍ରତ୍ୟେକ admissible value ପାଇଁ ସତ୍ୟ, ତାହା identity।
7. Quadratic Equation
ax² + bx + c = 0, a ≠ 0 ଆକାରର equationକୁ quadratic equation in one variable କୁହାଯାଏ।
8. Quadratic Equation by Factorisation
ଉଦାହରଣ: x²−5x+4=0
⇒ x²−4x−x+4=0
⇒ (x−4)(x−1)=0
⇒ x=4 କିମ୍ବା x=1.
9. Difference of Squares
a²−b²=(a+b)(a−b). ଉଦାହରଣ: 3x²−12=0 ⇒ 3(x²−4)=0 ⇒ (x+2)(x−2)=0 ⇒ x=−2, 2.
10. Cross Multiplication
ଯଦି A/B = C/D, ତେବେ AD = BC. ଏହି ପଦ୍ଧତିକୁ linear equationsର କିଛି fractional formରେ ବ୍ୟବହାର କରାଯାଏ।
11. Applications
Chapterର application examplesରେ ସଂଖ୍ୟା, ଆୟତ/କ୍ଷେତ୍ରଫଳ, ବୟସ ଓ ସମ୍ବନ୍ଧିତ quantityକୁ variable ଧରି equation ଗଠନ କରି solution ଖୋଜାଯାଏ।

🔁 Quick Revision

Linear: ax+b=0, a≠0

Linear solution: x=−b/a

Quadratic: ax²+bx+c=0, a≠0

Key identity: a²−b²=(a+b)(a−b)

Cross multiplication: A/B=C/D ⇒ AD=BC
