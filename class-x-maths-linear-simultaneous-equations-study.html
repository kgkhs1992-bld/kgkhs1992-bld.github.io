CHAPTER 01 — LINEAR SIMULTANEOUS EQUATIONS

Linear Simultaneous Equations

A pair of linear equations in two variables can be solved together to find their common solution. This chapter deals with graphical representation, conditions for solvability and different algebraic methods of solving simultaneous equations.

The main methods studied are graphical method, substitution method, elimination method, cross-multiplication method and Cramer's Rule.

📖 1. Basic Concept

Linear Equation in Two Variables

A linear equation in two variables can be written in the form:

ax + by + c = 0

where a and b are not both zero.

Pair of Linear Simultaneous Equations

a₁x + b₁y + c₁ = 0

a₂x + b₂y + c₂ = 0

The values of x and y satisfying both equations simultaneously form the solution of the pair.

📊 2. Geometrical Representation

Each linear equation in two variables represents a straight line on the coordinate plane.

Intersecting Lines

If the two lines intersect at one point, the pair has a unique solution.

Parallel Lines

If the two lines are distinct and parallel, they have no common point. Therefore the pair has no solution.

Coincident Lines

If the two equations represent the same line, there are infinitely many common points and hence infinitely many solutions.

📐 3. Conditions for Solvability

For

a₁x + b₁y + c₁ = 0
a₂x + b₂y + c₂ = 0
a₁/a₂ ≠ b₁/b₂
Unique solution
a₁/a₂ = b₁/b₂ ≠ c₁/c₂
No solution
a₁/a₂ = b₁/b₂ = c₁/c₂
Infinitely many solutions

✏️ 4. Substitution Method

In the substitution method, one variable is expressed in terms of the other variable and then substituted into the second equation.

Example

Solve:

x + y = 7
2x − y = 5

From the first equation:

y = 7 − x

Substitute in the second equation:

2x − (7 − x) = 5
3x = 12
x = 4

Therefore:

y = 7 − 4 = 3

Answer: x = 4, y = 3

➗ 5. Elimination Method

In the elimination method, the equations are multiplied by suitable numbers so that one variable can be eliminated.

Example

Solve:

2x + 3y = 13
4x − 3y = 5

Add the two equations:

6x = 18
x = 3

Substitute x = 3 into the first equation:

6 + 3y = 13
3y = 7
y = 7/3

🔄 6. Cross-Multiplication Method

For equations written in a suitable standard form, the cross-multiplication method can be used to obtain the values of the variables directly.

x/(b₁c₂ − b₂c₁) = y/(c₁a₂ − c₂a₁) = 1/(a₁b₂ − a₂b₁)

Care must be taken with the order of the terms and their signs.

🔢 7. Homogeneous Equations

A homogeneous pair of linear equations has zero constant terms.

a₁x + b₁y = 0
a₂x + b₂y = 0

The equations can be studied using the same principles of simultaneous linear equations and their coefficient relationships.

🧮 8. Cramer's Rule

Cramer's Rule uses determinants to solve a pair of simultaneous linear equations.

D = | a₁ b₁ |
    | a₂ b₂ |

When the main determinant is non-zero, the pair has a unique solution.

Remember:
  • Define the determinant carefully.
  • Maintain the correct order of terms.
  • Check the final answer in the original equations.

📝 9. Applications

Simultaneous equations can be used to solve practical problems involving two unknown quantities.

  • Problems involving two numbers
  • Age problems
  • Price and quantity problems
  • Distance and time problems
  • Other situations involving two unknown quantities

General Procedure

  1. Let the unknown quantities be x and y.
  2. Translate the given information into two equations.
  3. Solve the simultaneous equations.
  4. Interpret the values in the context of the problem.
  5. Verify the answer.

⚠️ Common Mistakes to Avoid

Always check the signs while transposing terms.
When multiplying an equation, multiply every term by the required number.
Do not confuse parallel lines with coincident lines.
Always verify the final values of x and y in the original equations.
In word problems, define the variables clearly before forming equations.
