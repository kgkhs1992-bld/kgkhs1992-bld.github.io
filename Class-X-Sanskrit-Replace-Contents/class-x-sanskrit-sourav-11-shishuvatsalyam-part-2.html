📚 Box 2 — Complete Explanation + Word Meanings

‘शिशुवात्सल्यम्’ पाठः कालिदासस्य ‘अभिज्ञानशाकुन्तलम्’ नाटकस्य सप्तमाङ्कस्य दृश्याधारितः अस्ति। अस्मिन् दृश्ये राजा दुष्यन्तः आश्रमप्रदेशे एकं निर्भीकं बालं पश्यति। बालः सिंहशावकेन सह क्रीडति तथा तस्य दन्तान् गणयितुम् इच्छति। तपस्विन्यः तं निवारयन्ति। बालस्य नाम सर्वदमनः इति ज्ञायते।

राजा बालस्य गोत्रपरिचयं पृच्छति। पुरुवंशसम्बन्धः ज्ञायते। बालस्य जननी शकुन्तला इति संकेतः प्राप्तः। मृत्तिकामयूरः, रक्षाकरण्डकः तथा अपराजिता-औषधिः अस्मिन् दृश्ये महत्त्वपूर्णानि भवन्ति। अन्ते बालस्य परिचयेन राज्ञः वात्सल्यभावः प्रकटते।

✍️ Box 3 — 6 Long Q/A × 5 Marks

1. ‘शिशुवात्सल्यम्’ पाठस्य मुख्यविषयः कः?
ଉଚ୍ଚାରଣ: ‘ଶିଶୁବାତ୍ସଲ୍ୟମ୍’ ପାଠସ୍ୟ ମୁଖ୍ୟବିଷୟଃ କଃ?
ଉତ୍ତର:
ଏହି ପାଠର ମୁଖ୍ୟ ବିଷୟ ହେଉଛି ଶିଶୁପ୍ରତି ଥିବା ଅପାର ସ୍ନେହ ଓ ମମତା। ରାଜା ଦୁଷ୍ୟନ୍ତ ଆଶ୍ରମରେ ଏକ ନିର୍ଭୀକ ଶିଶୁଙ୍କୁ ଦେଖନ୍ତି। ଶିଶୁର ସାହସ ଓ ସରଳତା ରାଜାଙ୍କୁ ଆକର୍ଷିତ କରେ। ପରେ ଶିଶୁଟି ତାଙ୍କ ନିଜ ପୁତ୍ର ବୋଲି ପରିଚିତ ହୁଏ। ଏହି ମିଳନରେ ପିତୃସ୍ନେହ ଓ ପାରିବାରିକ ମମତାର ସୁନ୍ଦର ପ୍ରକାଶ ମିଳେ।
2. सर्वदमनस्य स्वभावः कीदृशः आसीत्?
ଉଚ୍ଚାରଣ: ସର୍ବଦମନସ୍ୟ ସ୍ୱଭାବଃ କୀଦୃଶଃ ଆସୀତ୍?
ଉତ୍ତର:
ସର୍ବଦମନ ଜଣେ ନିର୍ଭୀକ ଓ ଚଞ୍ଚଳ ଶିଶୁ ଥିଲା। ସେ ସିଂହଶାବକ ସହିତ ମଧ୍ୟ ଭୟ ନକରି ଖେଳୁଥିଲା। ତାହାର ଦୁଷ୍ଟାମି ଦେଖି ତପସ୍ୱିନୀମାନେ ତାକୁ ନିୟନ୍ତ୍ରଣ କରୁଥିଲେ। ତାହାର ସାହସ ଓ ଶକ୍ତି ସମସ୍ତଙ୍କୁ ଆଶ୍ଚର୍ଯ୍ୟ କରୁଥିଲା। ତଥାପି ତାହାର ଶିଶୁସୁଲଭ ସରଳତା ଅତ୍ୟନ୍ତ ଆକର୍ଷଣୀୟ ଥିଲା।
3. राजा दुष्यन्तः बालं कथं दृष्टवान्?
ଉଚ୍ଚାରଣ: ରାଜା ଦୁଷ୍ୟନ୍ତଃ ବାଲଂ କଥଂ ଦୃଷ୍ଟବାନ୍?
ଉତ୍ତର:
ରାଜା ଦୁଷ୍ୟନ୍ତ ଆଶ୍ରମ ଅଞ୍ଚଳରେ ଶିଶୁ ସର୍ବଦମନଙ୍କୁ ଦେଖିଥିଲେ। ଶିଶୁଟି ସିଂହଶାବକ ସହିତ ଖେଳୁଥିବା ଦେଖି ରାଜା ଆଶ୍ଚର୍ଯ୍ୟ ହୋଇଥିଲେ। ଶିଶୁର ଆଚରଣରେ ରାଜା ଏକ ପରିଚିତ ସାଦୃଶ୍ୟ ଅନୁଭବ କରିଥିଲେ। ତାହାର ମାତା ଓ ବଂଶ ସମ୍ପର୍କରେ ପଚାରିବା ପରେ ରହସ୍ୟ ଖୋଲିଥିଲା। ଶେଷରେ ରାଜା ବୁଝିଥିଲେ ଯେ ଶିଶୁଟି ତାଙ୍କ ନିଜ ପୁତ୍ର।
4. शकुन्तलायाः विषये तापसी किं सूचितवती?
ଉଚ୍ଚାରଣ: ଶକୁନ୍ତଲାୟାଃ ବିଷୟେ ତାପସୀ କିଂ ସୂଚିତବତୀ?
ଉତ୍ତର:
ତାପସୀ ରାଜାଙ୍କୁ ଶକୁନ୍ତଳା ସମ୍ବନ୍ଧରେ ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ ସୂଚନା ଦେଇଥିଲେ। ସେ କହିଥିଲେ ଯେ ଶିଶୁର ଜନନୀ ଶକୁନ୍ତଳା। ଏହି କଥା ରାଜାଙ୍କ ମନରେ ପୁରୁଣା ସ୍ମୃତିକୁ ଜାଗ୍ରତ କରିଥିଲା। ଶିଶୁର ପରିଚୟ ସହିତ ଶକୁନ୍ତଳାଙ୍କ ସମ୍ପର୍କ ସ୍ପଷ୍ଟ ହୋଇଥିଲା। ଏହା ରାଜା ଓ ତାଙ୍କ ପରିବାରର ପୁନର୍ମିଳନର ପଥକୁ ଖୋଲିଦେଇଥିଲା।
5. रक्षाकरण्डकस्य महत्त्वं किम्?
ଉଚ୍ଚାରଣ: ରକ୍ଷାକରଣ୍ଡକସ୍ୟ ମହତ୍ତ୍ୱଂ କିମ୍?
ଉତ୍ତର:
ରକ୍ଷାକରଣ୍ଡକ ଶିଶୁ ସର୍ବଦମନଙ୍କ ସହିତ ଜଡିତ ଏକ ବିଶେଷ ଚିହ୍ନ ଥିଲା। ଏହା ଶିଶୁର ରକ୍ଷା ସହିତ ସମ୍ପର୍କିତ ଥିଲା। ତାହାରେ ଅପରାଜିତା ନାମକ ଔଷଧିର ଉଲ୍ଲେଖ ମିଳେ। ଏହି ରକ୍ଷାକରଣ୍ଡକ ଦେଖି ଶିଶୁର ପରିଚୟ ସମ୍ପର୍କରେ ରାଜାଙ୍କ ସନ୍ଦେହ ଦୂର ହୋଇଥିଲା। ତେଣୁ ଏହା ପାଠରେ ପରିଚୟ ଉଦ୍ଘାଟନର ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ ମାଧ୍ୟମ।
6. ‘शिशुवात्सल्यम्’ पाठात् का शिक्षा प्राप्यते?
ଉଚ୍ଚାରଣ: ‘ଶିଶୁବାତ୍ସଲ୍ୟମ୍’ ପାଠାତ୍ କା ଶିକ୍ଷା ପ୍ରାପ୍ୟତେ?
ଉତ୍ତର:
ଏହି ପାଠରୁ ଶିଶୁମାନଙ୍କ ପ୍ରତି ସ୍ନେହ ଓ ଯତ୍ନର ମହତ୍ତ୍ୱ ଜଣାପଡେ। ଶିଶୁର ସରଳତା ଓ ନିର୍ଭୀକତାକୁ ସମ୍ମାନ କରିବା ଦରକାର। ପରିବାରରେ ପିତାମାତାଙ୍କ ମମତା ଶିଶୁର ବିକାଶରେ ମହତ୍ତ୍ୱପୂର୍ଣ୍ଣ। ସତ୍ୟ ପରିଚୟ ଓ ପାରିବାରିକ ସମ୍ପର୍କ ମଣିଷର ହୃଦୟକୁ ସ୍ପର୍ଶ କରେ। ତେଣୁ ଏହି ପାଠ ମାନବୀୟ ସ୍ନେହ, ପରିବାର ଓ ମମତାର ମୂଲ୍ୟ ଶିଖାଏ।

📘 Box 5 — Textbook-based Grammar Practice

सन्धिः

  • यदि + एतस्याः → यद्येतस्याः
  • अनेन + एव → अनेनैव
  • माम् + अयम् → मामयम्
  • कः + अत्र → कोऽत्र
  • देवगुरोः + तपोवने → देवगुरोस्तपोवने

सन्धिविच्छेदः

  • भीतोऽस्मि → भीतः + अस्मि
  • इत्यधर्म → इति + अधर्म
  • वाङ्मात्रेण → वाक् + मात्रेण
  • मोचयानेन → मोचय + अनेन
  • काऽस्य → का + अस्य
  • मातुराख्या → मातुः + आख्या

समासः

  • अविनीतः — नास्ति विनीतः यस्य
  • सर्वदमनः — सर्वं दमयति इति
  • राजर्षिः — राजा च ऋषिश्च
  • वाङ्मात्रेण — वाचा मात्रेण
  • तपोवने — तपसः वनम्
  • मनोरथः — मनसः रथः

प्रत्यय-अभ्यासः

  • भीतः = भी + क्त
  • विलोक्य = वि + लोक् + ल्यप्
  • स्थानम् = स्था + ल्युट्
  • प्राप्तव्यम् = प्र + आप् + तव्य
  • गृहीतम् = ग्रह् + क्त
  • भूत्वा = भू + क्त्वा
  • सम्पूर्णम् = सम् + पूर् + क्त

स्त्रीप्रत्यय-अभ्यासः

बालः → बालिका, सिंहः → सिंही, प्रथमः → प्रथमा, मयूरः → मयूरी, तपस्वी → तपस्विनी, राजा → राज्ञी.
