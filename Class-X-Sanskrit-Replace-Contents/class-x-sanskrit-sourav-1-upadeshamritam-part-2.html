Sanskrit 01

उपदेशामृतम्

📚 Box 2 — Complete Explanation + Word Meanings

ପାଠ ପରିଚୟ: ‘ଉପଦେଶାମୃତମ୍’ ପାଠରେ ପ୍ରାଚୀନ ଗୁରୁକୁଳ ପରମ୍ପରାର ନୀତିମୂଳକ ଓ ଜୀବନମୁଖୀ ଉପଦେଶଗୁଡ଼ିକ ସଂକଳିତ ହୋଇଛି। ସତ୍ୟ, ଧର୍ମ, ଶିକ୍ଷା, ମିତ୍ରତା, ଦେଶପ୍ରତି ସଚେତନତା, ଶୁଭ ସଙ୍କଳ୍ପ ଓ ଉତ୍ତମ ଆଚରଣ ଏହାର ମୁଖ୍ୟ ଭାବ।

୧. ସତ୍ୟର ଅନ୍ୱେଷଣ

‘एकं सद् विप्रा बहुधा वदन्ति’ ଭାବରେ ସତ୍ୟ ଏକ, କିନ୍ତୁ ଜ୍ଞାନୀମାନେ ତାହାକୁ ବିଭିନ୍ନ ଭାବେ କହନ୍ତି—ଏହି ଚିନ୍ତା ଦିଆଯାଇଛି। ‘ऋतस्य पथा प्रेत’ ଦ୍ୱାରା ସତ୍ୟ ଓ ନୀତିର ପଥରେ ଚାଲିବାର ଆହ୍ୱାନ ରହିଛି। ଶ୍ରଦ୍ଧା ସହିତ ସତ୍ୟକୁ ଅନୁସରଣ କରିବା ଜୀବନକୁ ସଠିକ ଦିଗ ଦେଇଥାଏ।

୨. ମାତୃଭୂମି ଓ ଦେଶପ୍ରେମ

‘माता भूमिः पुत्रोऽहं पृथिव्याः’ ବାକ୍ୟରେ ପୃଥିବୀକୁ ମାତା ଏବଂ ନିଜକୁ ତାଙ୍କ ପୁତ୍ର ଭାବେ ଦେଖାଯାଇଛି। ‘वयं राष्ट्रे जागृयाम’ ଦ୍ୱାରା ଦେଶ ପ୍ରତି ସଚେତନ ରହିବାର ଶିକ୍ଷା ମିଳେ। ତେଣୁ ଦେଶ, ସମାଜ ଓ ପରିବେଶ ପ୍ରତି ଦାୟିତ୍ୱବୋଧ ପାଠର ଏକ ମୁଖ୍ୟ ଦିଗ।

୩. ମିତ୍ରତା ଓ ଉତ୍ତମ ଆଚରଣ

‘मित्रस्य चक्षुषा समीक्षामहे’ ଦ୍ୱାରା ସମସ୍ତଙ୍କୁ ମିତ୍ରତାର ଦୃଷ୍ଟିରେ ଦେଖିବାର ଆଦର୍ଶ ଦିଆଯାଇଛି। ଯେଉଁ ବ୍ୟକ୍ତି ମିତ୍ରକୁ ସାହାଯ୍ୟ କରେନାହିଁ, ସେ ପ୍ରକୃତ ମିତ୍ର ନୁହେଁ। ତେଣୁ ସ୍ନେହ, ସହଯୋଗ ଓ ବିଶ୍ୱାସ ଉତ୍ତମ ମାନବୀୟ ସମ୍ପର୍କର ଆଧାର।

୪. ଶୁଭ ସଙ୍କଳ୍ପ ଓ କର୍ମ

‘तन्मे मनः शिवसंकल्पमस्तु’ ଦ୍ୱାରା ମନ ଶୁଭ ଓ କଲ୍ୟାଣମୟ ସଙ୍କଳ୍ପରେ ପୂର୍ଣ୍ଣ ହେଉ—ଏହି ପ୍ରାର୍ଥନା ରହିଛି। ‘चरैवेति चरैवेति’ ଦ୍ୱାରା ନିରନ୍ତର ପ୍ରୟାସ ଓ ଗତିଶୀଳତାର ମହତ୍ତ୍ୱ ବୁଝାଯାଏ। ପରିଶ୍ରମ ଓ କର୍ମନିଷ୍ଠା ଜୀବନର ଉନ୍ନତିର ମାର୍ଗ।

୫. ଶିକ୍ଷା ଓ ଅମୃତତ୍ୱ

‘विद्ययामृतमश्नुते’ ଭାବରେ ବିଦ୍ୟା ମାଧ୍ୟମରେ ଅମୃତତ୍ୱ ବା ଉଚ୍ଚତର ଜୀବନମୂଲ୍ୟ ପ୍ରାପ୍ତିର କଥା କୁହାଯାଇଛି। ଶିକ୍ଷା କେବଳ ପରୀକ୍ଷାରେ ସଫଳତା ପାଇଁ ନୁହେଁ; ଏହା ଚରିତ୍ର, ବିବେକ ଓ ଦାୟିତ୍ୱବୋଧ ବିକାଶ କରିବା ଉଚିତ।

୬. ସତ୍ୟ, ଧର୍ମ ଓ କର୍ତ୍ତବ୍ୟ

‘सत्यं वद, धर्मं चर’—ସତ୍ୟ କହ ଓ ଧର୍ମପଥରେ ଚାଲ—ଏହି ସରଳ ଉପଦେଶ ପାଠର ମୂଳ ନୀତିମାନଙ୍କ ମଧ୍ୟରୁ ଗୋଟିଏ। ସ୍ୱାଧ୍ୟାୟରେ ଅବହେଳା ନ କରିବା, ଉତ୍ତମ କାର୍ଯ୍ୟକୁ ଅନୁସରଣ କରିବା ଏବଂ ମାତା, ପିତା, ଆଚାର୍ଯ୍ୟ ଓ ଅତିଥିଙ୍କୁ ସମ୍ମାନ କରିବାର ଶିକ୍ଷା ମଧ୍ୟ ଦିଆଯାଇଛି।

ମୁଖ୍ୟ ଶବ୍ଦାର୍ଥ

  • उपदेश — ଉପଦେଶ / ନୀତିମୂଳକ ଶିକ୍ଷା
  • अमृत — ଅମୃତ / ଅମରତ୍ୱଦାୟକ ସାର
  • गुरुकुल — ଗୁରୁଙ୍କ ଆଶ୍ରମରେ ଶିକ୍ଷାସ୍ଥଳ
  • आचार्य — ଶିକ୍ଷକ / ଗୁରୁ
  • सूक्ति — ଉତ୍ତମ ଓ ଅର୍ଥପୂର୍ଣ୍ଣ ବାକ୍ୟ
  • सत्य — ସତ୍ୟ
  • ऋत — ସତ୍ୟ ଓ ନୀତିର ପଥ
  • श्रद्धा — ଗଭୀର ବିଶ୍ୱାସ
  • पृथिवी — ପୃଥିବୀ / ଧରିତ୍ରୀ
  • राष्ट्र — ଦେଶ
  • जागृ — ସଚେତନ ହେବା
  • मित्र — ବନ୍ଧୁ
  • शिवसंकल्प — ଶୁଭ ଓ କଲ୍ୟାଣମୟ ସଙ୍କଳ୍ପ
  • चरैवेति — ଚାଲି ଚାଲ / ଆଗକୁ ବଢ଼
  • विद्या — ଜ୍ଞାନ / ଶିକ୍ଷା
  • स्वाध्याय — ନିଜେ ଅଧ୍ୟୟନ
  • प्रमाद — ଅବହେଳା / ଅସାବଧାନତା
  • अनवद्यानि — ନିନ୍ଦନୀୟ ନୁହେଁ ଏମିତି
  • सुक्रित — ଉତ୍ତମ ଆଚରଣ / ସତ୍କର୍ମ
  • अतिथि — ଅତିଥି

✍️ Box 3 — 6 Long Questions × 5 Marks

ପ୍ରତ୍ୟେକ ୫-ମାର୍କ ଉତ୍ତରରେ ଅତି କମରେ ୫ଟି ଅର୍ଥପୂର୍ଣ୍ଣ ଧାଡ଼ି ରହିଛି।
1. उपदेशामृतस्य मुख्यः उद्देश्यः कः?
ଉଚ୍ଚାରଣ: ଉପଦେଶାମୃତସ୍ୟ ମୁଖ୍ୟଃ ଉଦ୍ଦେଶ୍ୟଃ କଃ?
ଉତ୍ତର:
  1. ଏହି ପାଠର ମୁଖ୍ୟ ଉଦ୍ଦେଶ୍ୟ ହେଉଛି ଛାତ୍ରଛାତ୍ରୀଙ୍କୁ ଉତ୍ତମ ଜୀବନର ନୀତିମୂଳକ ଶିକ୍ଷା ଦେବା।
  2. ପାଠରେ ସତ୍ୟ, ଧର୍ମ, କର୍ତ୍ତବ୍ୟ ଓ ଉତ୍ତମ ଆଚରଣର ମହତ୍ତ୍ୱ ବୁଝାଯାଇଛି।
  3. ଗୁରୁ, ମାତା, ପିତା ଓ ଅତିଥିଙ୍କ ପ୍ରତି ସମ୍ମାନ ରଖିବାକୁ ଉପଦେଶ ଦିଆଯାଇଛି।
  4. ଶିକ୍ଷାକୁ କେବଳ ପୁସ୍ତକୀୟ ଜ୍ଞାନ ନୁହେଁ, ଚରିତ୍ରଗଠନର ମାଧ୍ୟମ ଭାବେ ଦେଖାଯାଇଛି।
  5. ଦେଶ ଓ ପୃଥିବୀ ପ୍ରତି ଦାୟିତ୍ୱବୋଧ ରଖିବାର ଶିକ୍ଷା ମଧ୍ୟ ଏଥିରେ ରହିଛି।
  6. ଏହିପରି ପାଠଟି ଛାତ୍ରଙ୍କୁ ସତ୍ୟନିଷ୍ଠ, ଶୃଙ୍ଖଳିତ ଓ ଦାୟିତ୍ୱଶୀଳ ମଣିଷ ହେବାକୁ ପ୍ରେରଣା ଦିଏ।
2. ‘एकं सद् विप्रा बहुधा वदन्ति’ इति वाक्यस्य भावः कः?
ଉଚ୍ଚାରଣ: ‘ଏକଂ ସଦ୍ ବିପ୍ରା ବହୁଧା ବଦନ୍ତି’ ଇତି ବାକ୍ୟସ୍ୟ ଭାବଃ କଃ?
ଉତ୍ତର:
  1. ଏହି ବାକ୍ୟର ଅର୍ଥ ହେଉଛି ସତ୍ୟ ଏକ, କିନ୍ତୁ ଜ୍ଞାନୀମାନେ ତାହାକୁ ବିଭିନ୍ନ ଭାବରେ କହନ୍ତି।
  2. ଏହା ମଣିଷକୁ ସତ୍ୟ ପ୍ରତି ଉଦାର ଓ ବିବେକପୂର୍ଣ୍ଣ ଦୃଷ୍ଟି ରଖିବାକୁ ଶିଖାଏ।
  3. ବିଭିନ୍ନ ମତ ଥିଲେ ମଧ୍ୟ ସତ୍ୟର ମୂଳ ସ୍ୱରୂପ ଏକ ବୋଲି ଏଠାରେ ବୁଝାଯାଇଛି।
  4. ଏହା ଅନ୍ୟମତକୁ ଅସମ୍ମାନ କରିବା ପରିବର୍ତ୍ତେ ବୁଝିବାର ମନୋଭାବ ଦିଏ।
  5. ‘ऋतस्य पथा प्रेत’ ସହ ଏହାକୁ ଦେଖିଲେ ସତ୍ୟ ଓ ନୀତିର ପଥରେ ଚାଲିବାର ଶିକ୍ଷା ସ୍ପଷ୍ଟ ହୁଏ।
  6. ତେଣୁ ଏହି ଉପଦେଶ ମାନବ ସମାଜରେ ସହିଷ୍ଣୁତା ଓ ସତ୍ୟନିଷ୍ଠା ବଢ଼ାଇଥାଏ।
3. ‘माता भूमिः पुत्रोऽहं पृथिव्याः’ इति कथनेन का शिक्षा दीयते?
ଉଚ୍ଚାରଣ: ‘ମାତା ଭୂମିଃ ପୁତ୍ରୋऽହଂ ପୃଥିବ୍ୟାଃ’ ଇତି କଥନେନ କା ଶିକ୍ଷା ଦୀୟତେ?
ଉତ୍ତର:
  1. ଏହି କଥନରେ ପୃଥିବୀକୁ ମାତା ଓ ମଣିଷକୁ ତାଙ୍କ ପୁତ୍ର ଭାବେ ଗ୍ରହଣ କରାଯାଇଛି।
  2. ଏଥିରୁ ପୃଥିବୀ ପ୍ରତି ମଣିଷର ଗଭୀର ଦାୟିତ୍ୱବୋଧ ପ୍ରକାଶ ପାଏ।
  3. ମାତାଙ୍କ ପ୍ରତି ଯେପରି ସ୍ନେହ ଓ ସମ୍ମାନ ରହେ, ସେହିପରି ଧରିତ୍ରୀ ପ୍ରତି ମଧ୍ୟ ଆଦର ରଖିବା ଉଚିତ।
  4. ପରିବେଶର ସୁରକ୍ଷା ଓ ପୃଥିବୀର ସମ୍ପଦର ସଠିକ ବ୍ୟବହାର ଏହି ଭାବନା ସହ ଜଡ଼ିତ।
  5. ‘वयं राष्ट्रे जागृयाम’ ଦ୍ୱାରା ଦେଶ ଓ ସମାଜ ପ୍ରତି ସଚେତନ ହେବାର ଶିକ୍ଷା ମିଳେ।
  6. ତେଣୁ ଏହି ଉପଦେଶ ପ୍ରକୃତିପ୍ରେମ, ଦେଶପ୍ରେମ ଓ ଦାୟିତ୍ୱବୋଧକୁ ଦୃଢ଼ କରେ।
4. ‘तन्मे मनः शिवसंकल्पमस्तु’ तथा ‘चरैवेति चरैवेति’ इत्यनयोः महत्त्वं वर्णयत।
ଉଚ୍ଚାରଣ: ‘ତନ୍ମେ ମନଃ ଶିବସଙ୍କଳ୍ପମସ୍ତୁ’ ତଥା ‘ଚରୈବେତି ଚରୈବେତି’ ଇତ୍ୟନୟୋଃ ମହତ୍ତ୍ୱଂ ବର୍ଣ୍ଣୟତ।
ଉତ୍ତର:
  1. ପ୍ରଥମ ଉପଦେଶରେ ମନ ଶୁଭ ଓ କଲ୍ୟାଣମୟ ସଙ୍କଳ୍ପରେ ପୂର୍ଣ୍ଣ ହେଉ ବୋଲି ପ୍ରାର୍ଥନା କରାଯାଇଛି।
  2. ଶୁଭ ଚିନ୍ତା ମଣିଷକୁ ଭଲ କାମ କରିବାରେ ପ୍ରେରଣା ଦିଏ।
  3. ‘चरैवेति चरैवेति’ ନିରନ୍ତର ଆଗକୁ ବଢ଼ିବା ଓ ପ୍ରୟାସ ଜାରି ରଖିବାକୁ କହେ।
  4. ଜୀବନରେ ବାଧା ଆସିଲେ ମଧ୍ୟ ହତାଶ ନ ହୋଇ ପରିଶ୍ରମ କରିବା ଏହାର ମୂଳ ଭାବ।
  5. ଶୁଭ ଚିନ୍ତା ଓ ନିରନ୍ତର କର୍ମ—ଏହି ଦୁଇଟି ମିଶି ସଫଳ ଜୀବନର ଭିତ୍ତି ଗଢ଼େ।

  5. ଏହି ନୀତିଗୁଡ଼ିକ ମଣିଷକୁ ଦାୟିତ୍ୱଶୀଳ, ଶୃଙ୍ଖଳିତ ଓ ସମ୍ମାନଶୀଳ କରେ।
  6. ତେଣୁ ଏହି ଉପଦେଶଗୁଡ଼ିକ ଛାତ୍ରଜୀବନ ସହିତ ସମଗ୍ର ଜୀବନରେ ପ୍ରୟୋଗଯୋଗ୍ୟ।
