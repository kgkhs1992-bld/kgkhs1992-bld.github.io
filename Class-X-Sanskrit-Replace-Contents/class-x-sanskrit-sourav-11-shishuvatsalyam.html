📖 Box 1 — Complete Explanation + Word Meanings

ପାଠର ସମ୍ପୂର୍ଣ୍ଣ ବ୍ୟାଖ୍ୟା

‘शिशुवात्सल्यम्’ ପାଠରେ ଶିଶୁ ପ୍ରତି ଥିବା ଗଭୀର ସ୍ନେହ, ମମତା ଓ ବାତ୍ସଲ୍ୟର ଚିତ୍ର ପ୍ରକାଶ ପାଇଛି।

ଏହି ପାଠରେ ରାଜା ଦୁଷ୍ୟନ୍ତ ଏକ ଆଶ୍ରମରେ ନିର୍ଭୀକ ଶିଶୁକୁ ଦେଖନ୍ତି। ଶିଶୁର ସରଳତା, ସାହସ ଓ ନିଷ୍କପଟ ଆଚରଣ ତାଙ୍କୁ ଆକର୍ଷିତ କରେ।

ଶିଶୁଟି ସିଂହଶାବକ ସହିତ ମଧ୍ୟ ନିର୍ଭୟରେ ଖେଳୁଥିବାରୁ ତାହାର ସାହସ ପ୍ରକାଶ ପାଏ।

📚 Word Meanings

  • शिशुः — ଶିଶୁ / ପିଲା
  • वात्सल्यम् — ଶିଶୁ ପ୍ରତି ସ୍ନେହ
  • सर्वदमनः — ଶିଶୁ ଭରତଙ୍କ ନାମ
  • सिंहशावकः — ସିଂହର ଛୁଆ
  • तपोवनम् — ତପୋବନ / ଆଶ୍ରମ
  • केशरिणी — ସିଂହୀ
  • उपहारः — ଉପହାର
  • आत्मगतम् — ମନରେ କୁହାଯାଇଥିବା କଥା
