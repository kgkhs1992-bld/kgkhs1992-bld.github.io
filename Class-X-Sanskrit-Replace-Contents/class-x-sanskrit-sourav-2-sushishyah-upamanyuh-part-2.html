सुषिष्यः उपमन्युः

📚 Box 2 — Complete Explanation + Word Meanings

୧. ପାଠର ପରିଚୟ ଓ ଉପମନ୍ୟୁଙ୍କ ଚରିତ୍ର

‘सुशिष्यः उपमन्युः’ ପାଠଟି ମହାଭାରତରେ ବର୍ଣ୍ଣିତ ଋଷି ଧୌମ୍ୟଙ୍କ ଶିଷ୍ୟ ଉପମନ୍ୟୁଙ୍କ ଗୁରୁଭକ୍ତିର କଥା। ଉପମନ୍ୟୁ ଗୁରୁଙ୍କ ଆଜ୍ଞାକୁ ନିଷ୍ଠାର ସହ ପାଳନ କରୁଥିଲେ। ଗାଈ ଜଗିବା, ଭିକ୍ଷା ଆଣି ଗୁରୁଙ୍କୁ ଦେବା ଓ କଷ୍ଟ ସହିବା ମାଧ୍ୟମରେ ତାଙ୍କ ଶିଷ୍ୟତ୍ୱ ପ୍ରକାଶ ପାଏ।

୨. ଗୁରୁଙ୍କ ଆଜ୍ଞା ଓ ଗୋରକ୍ଷା

ଉପାଧ୍ୟାୟ ଧୌମ୍ୟ ଉପମନ୍ୟୁଙ୍କୁ ଗାଈମାନଙ୍କୁ ଜଗିବା ପାଇଁ ବନକୁ ପଠାଉଥିଲେ। ଉପମନ୍ୟୁ ଦିନସାରା ଗାଈ ଜଗି ସନ୍ଧ୍ୟାରେ ଗୁରୁଙ୍କ ସମ୍ମୁଖରେ ଆସି ନମସ୍କାର କରୁଥିଲେ। ତାଙ୍କର ଏହି ନିୟମିତ ସେବା ଗୁରୁଭକ୍ତିର ପ୍ରମାଣ।

୩. ଭିକ୍ଷାଜୀବନ ଓ ଗୁରୁଙ୍କ ଶିକ୍ଷା

ଉପମନ୍ୟୁ ଭିକ୍ଷାରେ ମିଳୁଥିବା ଦ୍ରବ୍ୟରେ ଜୀବିକା ଚଳାଉଥିଲେ ଏବଂ ସେସବୁ ଗୁରୁଙ୍କୁ ଅର୍ପଣ କରୁଥିଲେ। ଗୁରୁ ତାଙ୍କୁ ନିଜେ ଭୋଜନ କରିବାର ପଦ୍ଧତି ଓ ଅନ୍ୟ ଭିକ୍ଷାଜୀବୀଙ୍କ ଜୀବିକାରେ ବାଧା ନଦେବାର ଶିକ୍ଷା ଦେଲେ। ଉପମନ୍ୟୁ ପ୍ରତ୍ୟେକ ନିର୍ଦ୍ଦେଶକୁ ପାଳନ କଲେ।

୪. କ୍ଷୁଧା, ଅରଖପତ୍ର ଓ କୂପରେ ପତନ

ସମସ୍ତ ଉପାୟ ବନ୍ଦ ହୋଇଯିବାରୁ ଉପମନ୍ୟୁ ଅତ୍ୟନ୍ତ କ୍ଷୁଧାର୍ତ୍ତ ହେଲେ। ବନରେ ଘୁରୁଥିବା ସମୟରେ ସେ ଅରଖପତ୍ର ଖାଇଲେ। ତାହାର ପ୍ରଭାବରେ ତାଙ୍କ ଦୃଷ୍ଟିଶକ୍ତି ହ୍ରାସ ପାଇଲା ଏବଂ ସେ ଚାଲିବାବେଳେ ଗୋଟିଏ କୂପରେ ପଡ଼ିଗଲେ।

୫. ଅଶ୍ୱିନୀକୁମାରଙ୍କ ସ୍ତୁତି

ଉପମନ୍ୟୁଙ୍କ ଅବସ୍ଥା ଜାଣି ଗୁରୁ ଧୌମ୍ୟ ତାଙ୍କୁ ଦେବବୈଦ୍ୟ ଅଶ୍ୱିନୀକୁମାର ଦୁଇଜଣଙ୍କୁ ସ୍ତୁତି କରିବାକୁ ପରାମର୍ଶ ଦେଲେ। ଉପମନ୍ୟୁ ଗୁରୁଙ୍କ ଆଜ୍ଞା ଅନୁସାରେ ସେମାନଙ୍କୁ ପ୍ରାର୍ଥନା କଲେ। ତାଙ୍କ ଗୁରୁଭକ୍ତି ଓ ସ୍ତୁତିରେ ପ୍ରସନ୍ନ ହୋଇ ଅଶ୍ୱିନୀକୁମାର ତାଙ୍କୁ ପିଠା ଦେଲେ।

୬. ଦୃଷ୍ଟିଶକ୍ତି ପ୍ରାପ୍ତି ଓ ଗୁରୁଙ୍କ ଆଶୀର୍ବାଦ

ଅଶ୍ୱିନୀକୁମାରଙ୍କ ଦିଆ ପିଠା ଖାଇବା ପରେ ଉପମନ୍ୟୁ ତାଙ୍କ ଦୃଷ୍ଟିଶକ୍ତି ଫେରିପାଇଲେ। ତାଙ୍କ ଗୁରୁଭକ୍ତିରେ ଧୌମ୍ୟ ପ୍ରସନ୍ନ ହେଲେ। ଗୁରୁ ତାଙ୍କୁ ଆଶୀର୍ବାଦ କରି କହିଲେ ଯେ ସେ ବେଦ, ଧର୍ମଶାସ୍ତ୍ର ଓ ଅନ୍ୟ ଶାସ୍ତ୍ରରେ ପାରଙ୍ଗମ ହେବେ। ଏହିପରି ଉପମନ୍ୟୁ ଜଣେ ଯଶସ୍ୱୀ ଶାସ୍ତ୍ରଜ୍ଞ ଭାବେ ପ୍ରସିଦ୍ଧ ହେଲେ।

ମୁଖ୍ୟ ଶବ୍ଦାର୍ଥ

  • उपमन्युः — ଋଷି ଧୌମ୍ୟଙ୍କ ଶିଷ୍ୟ
  • उपाध्यायः — ଗୁରୁ / ଶିକ୍ଷକ

  • भैक्ष्यम् — ଭିକ୍ଷାରେ ପ୍ରାପ୍ତ ଦ୍ରବ୍ୟ
  • वृत्तिः — ଜୀବିକା / ଉପାର୍ଜନ ପଦ୍ଧତି
  • वृत्त्युपरोधः — ଜୀବିକାରେ ବାଧା
  • क्षुधार्त्तः — ଭୋକରେ କଷ୍ଟପ୍ରାପ୍ତ
  • अरण्यम् — ବନ
  • अर्कपत्रम् — ଅରଖ ଗଛର ପତ୍ର
  • अन्धः — ଦୃଷ୍ଟିହୀନ
  • कूपः — କୂଅ
  • अन्वेषणम् — ଖୋଜାଖୋଜି
  • देवभिषजौ — ଦୁଇଜଣ ଦେବବୈଦ୍ୟ
  • अश्विनीकुमारौ — ଅଶ୍ୱିନୀକୁମାର ଦୁଇଜଣ
  • चक्षुष्मान् — ଦୃଷ୍ଟିଶକ୍ତିସମ୍ପନ୍ନ
  • श्रेयः — ମଙ୍ଗଳ / କଲ୍ୟାଣ
  • सर्वज्ञः — ସମସ୍ତ ଶାସ୍ତ୍ରରେ ଜ୍ଞାନୀ
  • गुरुभक्तिः — ଗୁରୁଙ୍କ ପ୍ରତି ଭକ୍ତି
  • नमस्कारः — ପ୍ରଣାମ

✍️ Box 3 — 6 Long Questions × 5 Marks

ପ୍ରତ୍ୟେକ ଉତ୍ତରରେ ଅତି କମରେ ୫ଟି ଅର୍ଥପୂର୍ଣ୍ଣ ଧାଡ଼ି ରହିଛି। ପ୍ରଶ୍ନ Devanagariରେ, ତଳେ Odia-script ଉଚ୍ଚାରଣ ଏବଂ ଉତ୍ତର Odiaରେ।
1. उपमन्योः गुरुभक्तिः कथं प्रकाशिता?
ଉଚ୍ଚାରଣ: ଉପମନ୍ୟୋଃ ଗୁରୁଭକ୍ତିଃ କଥଂ ପ୍ରକାଶିତା?
ଉତ୍ତର:
  1. ଉପମନ୍ୟୁ ଋଷି ଧୌମ୍ୟଙ୍କର ଜଣେ ନିଷ୍ଠାବାନ ଶିଷ୍ୟ ଥିଲେ।
  2. ଗୁରୁଙ୍କ ଆଜ୍ଞା ଅନୁସାରେ ସେ ଗାଈମାନଙ୍କୁ ଜଗିବା ପାଇଁ ବନକୁ ଯାଉଥିଲେ।
  3. ଭିକ୍ଷାରେ ମିଳୁଥିବା ସମସ୍ତ ଦ୍ରବ୍ୟ ସେ ଗୁରୁଙ୍କୁ ଅର୍ପଣ କରୁଥିଲେ।
  4. ଗୁରୁ ତାଙ୍କୁ ଏକାଧିକ ଉପାୟରୁ ବାରଣ କଲେ ମଧ୍ୟ ସେ ଆଜ୍ଞା ଅମାନ୍ୟ କରିନଥିଲେ।
  5. କ୍ଷୁଧାର୍ତ୍ତ ହୋଇ ଅରଖପତ୍ର ଖାଇ ଦୃଷ୍ଟି ହରାଇଥିଲେ ମଧ୍ୟ ଗୁରୁଙ୍କ ଆଜ୍ଞା ପ୍ରତି ତାଙ୍କର ନିଷ୍ଠା ଅଟଳ ରହିଲା।
  6. ଏହି କାରଣରୁ ଉପମନ୍ୟୁଙ୍କ ଚରିତ୍ର ଗୁରୁଭକ୍ତି ଓ କର୍ତ୍ତବ୍ୟନିଷ୍ଠାର ଉତ୍ତମ ଉଦାହରଣ ହୋଇଛି।
2. उपमन्युः भैक्ष्येण कथं वृत्तिं करोति स्म?
ଉଚ୍ଚାରଣ: ଉପମନ୍ୟୁଃ ଭୈକ୍ଷ୍ୟେଣ କଥଂ ବୃତ୍ତିଂ କରୋତି ସ୍ମ?
ଉତ୍ତର:
  1. ଉପମନ୍ୟୁ ନିଜ ଜୀବିକା ପାଇଁ ଭିକ୍ଷାବୃତ୍ତି ଗ୍ରହଣ କରିଥିଲେ।
  2. ସେ ଭିକ୍ଷାରେ ଯାହା ପାଉଥିଲେ, ତାହା ଗୁରୁଙ୍କ ସମ୍ମୁଖରେ ନେଇ ଅର୍ପଣ କରୁଥିଲେ।
  3. ଗୁରୁ ତାଙ୍କର ଏହି ଆଚରଣକୁ ଦେଖି ଭିକ୍ଷାର ନିୟମ ସମ୍ପର୍କରେ ଶିକ୍ଷା ଦେଲେ।
  4. ଦ୍ୱିତୀୟଥର ଭିକ୍ଷା କଲେ ଅନ୍ୟ ଭିକ୍ଷାଜୀବୀଙ୍କ ଜୀବିକାରେ ବାଧା ହେବ ବୋଲି ଗୁରୁ ବୁଝାଇଲେ।
  5. ଉପମନ୍ୟୁ ଗୁରୁଙ୍କ ଏହି ଶିକ୍ଷାକୁ ମଧ୍ୟ ଗ୍ରହଣ କଲେ।
  6. ଏହାରୁ ତାଙ୍କର ନମ୍ରତା, ଆଜ୍ଞାପାଳନ ଓ ଗୁରୁପ୍ରତି ସମ୍ମାନ ପ୍ରକାଶ ପାଏ।
3. क्षुधार्त्तस्य उपमन्योः किं अभवत्?
ଉଚ୍ଚାରଣ: କ୍ଷୁଧାର୍ତ୍ତସ୍ୟ ଉପମନ୍ୟୋଃ କିଂ ଅଭବତ୍?
ଉତ୍ତର:
  1. ଗୁରୁଙ୍କ ନିର୍ଦ୍ଦେଶ ପାଳନ କରି ଉପମନ୍ୟୁ ଖାଦ୍ୟ ପାଇବାର ସମସ୍ତ ସହଜ ଉପାୟ ହରାଇଥିଲେ।
  2. ଏହାର ଫଳରେ ସେ ଅତ୍ୟନ୍ତ କ୍ଷୁଧାର୍ତ୍ତ ହୋଇପଡ଼ିଲେ।
  3. ବନରେ ଘୁରୁଥିବା ସମୟରେ ସେ ଅରଖପତ୍ର ଖାଇଲେ।
  4. ଅରଖପତ୍ର ଖାଇବା ପରେ ତାଙ୍କ ଦୃଷ୍ଟିଶକ୍ତି ନଷ୍ଟ ହୋଇଗଲା।
  5. ଦୃଷ୍ଟିହୀନ ଅବସ୍ଥାରେ ଯାଉଥିବାବେଳେ ସେ ଗୋଟିଏ କୂପ ମଧ୍ୟରେ ପଡ଼ିଗଲେ।
  6. ଏହି ଘଟଣା ତାଙ୍କର ଗୁରୁଭକ୍ତି ସହିତ ଧୈର୍ଯ୍ୟ ଓ କଷ୍ଟସହିଷ୍ଣୁତାକୁ ମଧ୍ୟ ପ୍ରକାଶ କରେ।
4. उपमन्युः कथं चक्षुषी पुनः प्राप्तवान्?
ଉଚ୍ଚାରଣ: ଉପମନ୍ୟୁଃ କଥଂ ଚକ୍ଷୁଷୀ ପୁନଃ ପ୍ରାପ୍ତବାନ୍?
ଉତ୍ତର:
  1. ଉପମନ୍ୟୁଙ୍କ ଅବସ୍ଥା ଜାଣି ଗୁରୁ ଧୌମ୍ୟ ତାଙ୍କୁ ଅଶ୍ୱିନୀକୁମାର ଦୁଇଜଣଙ୍କ ସ୍ତୁତି କରିବାକୁ କହିଲେ।
  2. ଅଶ୍ୱିନୀକୁମାର ଦୁଇଜଣଙ୍କୁ ଦେବବୈଦ୍ୟ ବୋଲି କୁହାଯାଏ।
  3. ଉପମନ୍ୟୁ ଗୁରୁଙ୍କ ଆଜ୍ଞା ଅନୁସାରେ ସେମାନଙ୍କୁ ଭକ୍ତିପୂର୍ବକ ସ୍ତୁତି କଲେ।
  4. ତାଙ୍କର ଭକ୍ତି ଓ ସ୍ତୁତିରେ ଅଶ୍ୱିନୀକୁମାର ପ୍ରସନ୍ନ ହେଲେ।
  5. ସେମାନେ ଉପମନ୍ୟୁଙ୍କୁ ଗୋଟିଏ ପିଠା ଦେଲେ ଏବଂ ତାହା ଖାଇବା ପରେ ତାଙ୍କ ଦୃଷ୍ଟିଶକ୍ତି ଫେରିଆସିଲା।
