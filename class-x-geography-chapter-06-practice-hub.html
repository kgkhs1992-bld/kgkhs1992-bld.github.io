Class X Geography — Chapter 06: କୃଷି

✍️ 2-Mark / Short Answer

1. କୃଷିର ଚାରିଟି ପ୍ରମୁଖ ପ୍ରକାର ଲେଖ।

ଉତ୍ତର: ଜୀବିକା ନିର୍ଭର/ଆତ୍ମନିର୍ଭର, ଗହନ, ବ୍ୟାପକ ଓ ବାଣିଜ୍ୟିକ କୃଷି।

2. ଖରିଫ ଋତୁ କେବେ ଆରମ୍ଭ ହୁଏ?

ଉତ୍ତର: ଜୁନ୍/ଜୁଲାଇରେ ଆରମ୍ଭ ହୋଇ ଅକ୍ଟୋବର-ନଭେମ୍ବର ପର୍ଯ୍ୟନ୍ତ ଚାଲେ।

3. ରବି ଋତୁର ଦୁଇଟି ଫସଲ ଲେଖ।

ଉତ୍ତର: ଗହମ୍ ଓ ବାର୍ଲି।

4. ଜାଇଦ୍ ଋତୁର ଦୁଇଟି ଫସଲ ଲେଖ।

ଉତ୍ତର: ତରଭୁଜ ଓ ଖରଭୁଜ।

5. ଧାନ ଚାଷ ପାଇଁ କେଉଁ ପ୍ରକାର ଜଳବାୟୁ ଉପଯୁକ୍ତ?

ଉତ୍ତର: ଅଧିକ ଆର୍ଦ୍ରତା, ଉଷ୍ଣ ତାପମାତ୍ରା ଓ ପର୍ଯ୍ୟାପ୍ତ ବର୍ଷା।

6. ଦୁଇଟି ଡାଲିଜାତୀୟ ଫସଲ ଲେଖ।

ଉତ୍ତର: ମୁଗ ଓ ବିରି।

7. ଆଖୁରୁ କେଉଁ ପଦାର୍ଥ ମିଳେ?

ଉତ୍ତର: ଗୁଡ଼, ଖଣ୍ଡସାରି ଓ ଚିନି।

8. ‘Golden Fibre’ କାହାକୁ କୁହାଯାଏ?

ଉତ୍ତର: ଝୋଟକୁ।

9. Sericulture କ'ଣ?

ଉତ୍ତର: ରେଶମ କୀଟ ପାଳନ ଓ ରେଶମ ଉତ୍ପାଦନ ସମ୍ବନ୍ଧୀୟ କୃଷି।

10. ସବୁଜ ବିପ୍ଳବ କେଉଁ ଉତ୍ପାଦନ ସହିତ ସମ୍ବନ୍ଧିତ?

ଉତ୍ତର: ଖାଦ୍ୟଶସ୍ୟ ଉତ୍ପାଦନ।

📝 3-Mark / Long Answer

1. ଭାରତର ତିନିଟି କୃଷି ଋତୁ ବିଷୟରେ ଲେଖ।

ଖରିଫ, ରବି ଓ ଜାଇଦ୍ର ସମୟ ଏବଂ ପ୍ରମୁଖ ଫସଲ ସହିତ ଲେଖ।

2. ଗହନ କୃଷି ଓ ବ୍ୟାପକ କୃଷିର ପାର୍ଥକ୍ୟ ଦର୍ଶାଅ।

ଜନସଂଖ୍ୟା, ଜମିର ଉପଲବ୍ଧତା, ଶ୍ରମ ଓ ଯାନ୍ତ୍ରିକ ଉପକରଣ ଆଧାରରେ ତୁଳନା କର।

3. ଧାନ ଚାଷର ଭୌଗୋଳିକ ପରିସ୍ଥିତି ଓ ପ୍ରମୁଖ ଅଞ୍ଚଳ ଲେଖ।

ତାପମାତ୍ରା, ଆର୍ଦ୍ରତା, ବର୍ଷା, ମାଟି ଓ ଭାରତର ପ୍ରମୁଖ ଅଞ୍ଚଳ ଲେଖ।

4. ଭାରତର ତନ୍ତୁଜାତୀୟ ଫସଲଗୁଡ଼ିକ ବିଷୟରେ ଲେଖ।

କପା, ଝୋଟ, ରବର ଓ ରେଶମର ଗୁରୁତ୍ୱ ଓ ଅଞ୍ଚଳ ଦିଅ।

5. କୃଷି ଉପରେ ବିଶ୍ୱାୟନର ପ୍ରଭାବ ଆଲୋଚନା କର।

ବଜାର, ରପ୍ତାନି, ଫସଲ ଚୟନ ଓ ଛୋଟ ଚାଷୀଙ୍କ ସମସ୍ୟା ସହିତ ଉତ୍ତର ଲେଖ।

🎯 Learning Activities

  • ଭାରତର ମାନଚିତ୍ରରେ ଧାନ, ଗହମ୍, କପା, ଝୋଟ, ଚା ଓ କଫିର ପ୍ରମୁଖ ଅଞ୍ଚଳ ଚିହ୍ନଟ କର।
  • ଖରିଫ-ରବି-ଜାଇଦ୍ ଫସଲର ଏକ ଚାର୍ଟ ତିଆରି କର।
  • ‘କୃଷି ବିପ୍ଳବ’ ଉପରେ ରଙ୍ଗିନ ଟେବୁଲ୍ ତିଆରି କର।
  • ତୁମ ଅଞ୍ଚଳର 5ଟି ମୁଖ୍ୟ ଫସଲ ଲେଖି ସେଗୁଡ଼ିକର ଋତୁ ଚିହ୍ନଟ କର।
