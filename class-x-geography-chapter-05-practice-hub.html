Class X Geography — Chapter 05: ଶକ୍ତି ସମ୍ବଳ

✍️ 2-Mark / Short Answer Practice

1. ଶକ୍ତି ସମ୍ବଳ କ'ଣ?

ଉତ୍ତର: ମଣିଷର ବିଭିନ୍ନ କାର୍ଯ୍ୟ ପାଇଁ ଆବଶ୍ୟକ ଶକ୍ତି ଯେଉଁ ଉତ୍ସରୁ ମିଳେ, ସେଗୁଡ଼ିକ ଶକ୍ତି ସମ୍ବଳ।

2. ପାରମ୍ପରିକ ଶକ୍ତିର ଦୁଇଟି ଉଦାହରଣ ଦିଅ।

ଉତ୍ତର: କୋଇଲା ଓ ପେଟ୍ରୋଲିୟମ୍।

3. ଅପାରମ୍ପରିକ ଶକ୍ତିର ଦୁଇଟି ଉଦାହରଣ ଦିଅ।

ଉତ୍ତର: ସୌର ଶକ୍ତି ଓ ପବନ ଶକ୍ତି।

4. କୋଇଲାର ଚାରି ପ୍ରକାର ଲେଖ।

ଉତ୍ତର: ଆନ୍ଥ୍ରାସାଇଟ୍, ବିଟୁମିନସ୍, ଲିଗ୍ନାଇଟ୍ ଓ ପିଟ୍।

5. ତାଳଚେର କାହିଁକି ପରିଚିତ?

ଉତ୍ତର: କୋଇଲା ଅଞ୍ଚଳ ଏବଂ ତାପଜ ବିଦ୍ୟୁତ୍ ସମ୍ବନ୍ଧୀୟ ଗୁରୁତ୍ୱ ପାଇଁ।

6. ପେଟ୍ରୋଲିୟମ୍ର ଦୁଇଟି ବ୍ୟବହାର ଲେଖ।

ଉତ୍ତର: ଯାନବାହନ ଚଳାଚଳ ଓ ଶିଳ୍ପ/ତାପଜ ବିଦ୍ୟୁତ୍ରେ ବ୍ୟବହାର।

7. ଜଳ ବିଦ୍ୟୁତ୍ କିପରି ଉତ୍ପନ୍ନ ହୁଏ?

ଉତ୍ତର: ଜଳର ଗତି/ପତନ ଶକ୍ତିରେ ଟର୍ବାଇନ୍ ଚଳାଇ ବିଦ୍ୟୁତ୍ ଉତ୍ପାଦନ କରାଯାଏ।

8. ତାପଜ ବିଦ୍ୟୁତ୍ କିପରି ଉତ୍ପନ୍ନ ହୁଏ?

ଉତ୍ତର: ଇନ୍ଧନ ଜାଳି ପାଣିକୁ ବାଷ୍ପ କରି, ବାଷ୍ପରେ ଟର୍ବାଇନ୍ ଚଳାଇ ବିଦ୍ୟୁତ୍ ଉତ୍ପାଦନ।

9. ଜୈବ ବାଷ୍ପର ଗୋଟିଏ ଲାଭ ଲେଖ।

ଉତ୍ତର: ଏହା ତୁଳନାମୂଳକ ଧୂଆଁମୁକ୍ତ ଏବଂ ଅବଶିଷ୍ଟାଂଶ ଖତ ଭାବେ ବ୍ୟବହାର ହୁଏ।

10. ଶକ୍ତି ସଂରକ୍ଷଣ କାହିଁକି ଆବଶ୍ୟକ?

ଉତ୍ତର: ଶକ୍ତିର ବଢ଼ୁଥିବା ଚାହିଦା, ସୀମିତ ଇନ୍ଧନ ଓ ନିରନ୍ତର ବିକାଶ ପାଇଁ।

📝 3-Mark / Long Answer Practice

1. ପାରମ୍ପରିକ ଓ ଅପାରମ୍ପରିକ ଶକ୍ତି ଉତ୍ସର ପାର୍ଥକ୍ୟ ଦର୍ଶାଅ।

ଉତ୍ସର ସ୍ୱଭାବ, ବ୍ୟବହାର, ପୁନର୍ନବୀକରଣ ସମ୍ଭାବନା ଓ ପରିବେଶୀୟ ପ୍ରଭାବ ଆଧାରରେ ତୁଳନା କର।

2. କୋଇଲାର ପ୍ରକାର ଓ ଭାରତର ବଣ୍ଟନ ବିଷୟରେ ଲେଖ।

ଚାରି ପ୍ରକାର କୋଇଲା, ଗଣ୍ଡୱାନା/ଟର୍ସିଆରୀ ଭେଦ ଏବଂ ପ୍ରମୁଖ ଅଞ୍ଚଳ ଲେଖ।

3. ଜଳ ବିଦ୍ୟୁତ୍ ଓ ତାପଜ ବିଦ୍ୟୁତ୍ର ଉତ୍ପାଦନ ପ୍ରକ୍ରିୟା ବୁଝାଅ।

ଦୁଇଟିରେ ଶକ୍ତି ଉତ୍ସ ଓ ଟର୍ବାଇନ୍ ବ୍ୟବହାରର ପାର୍ଥକ୍ୟ ଦର୍ଶାଅ।

4. ଅପାରମ୍ପରିକ ଶକ୍ତି ଉତ୍ସଗୁଡ଼ିକ ବିଷୟରେ ଟିପ୍ପଣୀ ଲେଖ।

ସୌର, ପବନ, ଜୈବ ବାଷ୍ପ, ଜୁଆର, ଭୂ-ତାପଜ ଓ ପାରମାଣବିକ ଶକ୍ତିର ମୁଖ୍ୟ ବିଶେଷତା ଲେଖ।

5. ଶକ୍ତି ସଂରକ୍ଷଣର ପାଞ୍ଚଟି ଉପାୟ ଲେଖ।

ଘର, ଯାନବାହନ, ଶିଳ୍ପ ଓ ବିକଳ୍ପ ଶକ୍ତି ବ୍ୟବହାର ସମ୍ବନ୍ଧୀୟ ଉଦାହରଣ ଦିଅ।

🎯 Learning Activities

  • ଘର/ସ୍କୁଲରେ ଗୋଟିଏ ଦିନର ଶକ୍ତି ବ୍ୟବହାର ତାଲିକା କର।
  • କୋଇଲା, ପେଟ୍ରୋଲିୟମ୍ ଓ ସୌର ଶକ୍ତିର ତୁଳନାତ୍ମକ ଚାର୍ଟ ତିଆରି କର।
  • ଓଡ଼ିଶାର ଶକ୍ତି ସମ୍ବଳ ସମ୍ବନ୍ଧୀୟ ସ୍ଥାନଗୁଡ଼ିକ ମାନଚିତ୍ରରେ ଚିହ୍ନଟ କର।
