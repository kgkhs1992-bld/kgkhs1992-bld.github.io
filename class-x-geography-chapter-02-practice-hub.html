GEOGRAPHY — CHAPTER 02

ଭୂ-ସମ୍ବଳ

🧠 MY PRACTICE HUB

2-Mark + 3-Mark Questions • Self Learning • Exam Practice

📝 PART A — 2 MARK PRACTICE

1. ଭୂ-ସମ୍ବଳର ବିନିଯୋଗ କିପରି କରାଯାଏ?
ଉତ୍ତର: ଭୂମିକୁ ପ୍ରାକୃତିକ ଓ ମାନବୀୟ ପରିସ୍ଥିତି ଅନୁସାରେ କୃଷି, ବନ, ଜନବସତି, ଶିଳ୍ପ, ପରିବହନ ଓ ଅନ୍ୟାନ୍ୟ କାର୍ଯ୍ୟରେ ବ୍ୟବହାର କରାଯାଏ।
2. ଭାରତରେ ଭୂ-ସମ୍ବଳ କିପରି ବ୍ୟବହୃତ ହୁଏ?
ଉତ୍ତର: କୃଷି, ବନୀକରଣ, ପଶୁପାଳନ, ଜନବସତି, ରାସ୍ତାଘାଟ, ଶିଳ୍ପ, ଖଣିଜ ଉତ୍ତୋଳନ ଓ ବାଣିଜ୍ୟିକ କାର୍ଯ୍ୟରେ ଭୂମି ବ୍ୟବହୃତ ହୁଏ।
3. ଅନାବାଦୀ ଭୂମି କ’ଣ?
ଉତ୍ତର: ଯେଉଁ ଭୂମି କୃଷିକାର୍ଯ୍ୟ ପାଇଁ ବ୍ୟବହୃତ ହୁଏ ନାହିଁ, ତାହାକୁ ଅନାବାଦୀ ଭୂମି କୁହାଯାଏ।
4. କ୍ଷୟିତ ଭୂମି କ’ଣ?
ଉତ୍ତର: ଯେଉଁ ଭୂମିର ଗୁଣ ଓ ଉତ୍ପାଦନ କ୍ଷମତା ହ୍ରାସ ପାଇଛି, ତାହାକୁ କ୍ଷୟିତ ଭୂମି କୁହାଯାଏ।
5. ପତିତ ଭୂମିର ଦୁଇଟି ପ୍ରକାର ଲେଖ।
ଉତ୍ତର: (୧) ଚଳନ୍ତି ପତିତ ଭୂମି, (୨) ପୁରୁଣା ପତିତ ଭୂମି।

✍️ PART B — 3 MARK PRACTICE

1. ଭୂମିର ବିଭିନ୍ନ ବ୍ୟବହାର ବର୍ଣ୍ଣନା କର।
ଭୂମି କୃଷି, ବନ, ପଶୁଚାରଣ, ଜନବସତି, ଶିଳ୍ପ, ରାସ୍ତାଘାଟ, ରେଳପଥ, ଶିକ୍ଷା ଓ ସ୍ୱାସ୍ଥ୍ୟ ପ୍ରତିଷ୍ଠାନ, ଖଣିଜ ଉତ୍ତୋଳନ ଆଦି କାର୍ଯ୍ୟରେ ବ୍ୟବହୃତ ହୁଏ।
2. ବନଭୂମି ହ୍ରାସର କାରଣଗୁଡ଼ିକ ଲେଖ।
ଜନସଂଖ୍ୟା ବୃଦ୍ଧି, ନଗରୀକରଣ, କୃଷିଭୂମି ବୃଦ୍ଧି, ସ୍ଥାନାନ୍ତରିତ କୃଷି, ଶିଳ୍ପ, ଖଣିଜ ଉତ୍ତୋଳନ ଓ ରାସ୍ତାଘାଟ ନିର୍ମାଣ ବନଭୂମି ହ୍ରାସର ପ୍ରମୁଖ କାରଣ।
3. ଭୂ-ଅବକ୍ଷୟର ପ୍ରମୁଖ କାରଣଗୁଡ଼ିକ ବୁଝାଅ।
ଅତ୍ୟଧିକ ପଶୁଚାରଣ, ଖଣିଜ ଉତ୍ତୋଳନ, ବନ ନଷ୍ଟ, ଅନୁଚିତ କୃଷି, ଶିଳ୍ପ ବର୍ଜ୍ୟ ଓ ଜଳ/ବାୟୁ ଦ୍ୱାରା ଭୂମିକ୍ଷୟ ଭୂ-ଅବକ୍ଷୟର କାରଣ।
4. ଭୂ-ସମସ୍ୟାର ସମାଧାନ ପାଇଁ କେଉଁ ପଦକ୍ଷେପ ନିଆଯାଇପାରେ?
ପୁନଃବନୀକରଣ, ନିୟନ୍ତ୍ରିତ ପଶୁଚାରଣ, କୃଷି ଓ ବନଭୂମି ସଂରକ୍ଷଣ, ଶିଳ୍ପ ବର୍ଜ୍ୟର ସୁପରିଚାଳନା ଓ ସୁଚିନ୍ତିତ ଭୂ-ବ୍ୟବହାର ଯୋଜନା ଗ୍ରହଣ କରାଯାଇପାରେ।

🎯 PART C — THINK & LEARN

  1. ତୁମ ଗାଁ/ସହରରେ ଭୂମି କେଉଁ କେଉଁ କାମରେ ବ୍ୟବହୃତ ହେଉଛି?
  2. ତୁମ ଅଞ୍ଚଳରେ ବନଭୂମି କମିବାର କୌଣସି କାରଣ ଅଛି କି?
  3. ଏକ କୃଷିଭୂମିକୁ ଅନ୍ୟ କାମରେ ବ୍ୟବହାର କଲେ କେଉଁ ପରିବର୍ତ୍ତନ ହୋଇପାରେ?
  4. ଭୂମି ସୁରକ୍ଷା ପାଇଁ ଛାତ୍ରଛାତ୍ରୀ କ’ଣ କରିପାରିବେ?

📚 PART D — EXAM WRITING PRACTICE

ନିମ୍ନ ପ୍ରଶ୍ନଗୁଡ଼ିକର ଉତ୍ତର ନିଜେ ଲେଖି ଅଭ୍ୟାସ କର:

  1. ଭାରତରେ ଭୂ-ସମ୍ବଳର ବିଭିନ୍ନ ବ୍ୟବହାର ଆଲୋଚନା କର।
  2. ବନଭୂମିର ଗୁରୁତ୍ୱ ଓ ବନକ୍ଷୟର କାରଣ ବର୍ଣ୍ଣନା କର।
  3. ଭୂମି ଅବକ୍ଷୟର କାରଣ ଓ ପ୍ରତିକାର ଲେଖ।
  4. ପତିତ ଭୂମି ଓ ଅନାବାଦୀ ଭୂମି ମଧ୍ୟରେ ପାର୍ଥକ୍ୟ ଲେଖ।
Exam Tip: 3-mark ଉତ୍ତରରେ ପ୍ରଥମେ ଛୋଟ ପରିଚୟ, ପରେ 3–4ଟି ସ୍ପଷ୍ଟ ପଏଣ୍ଟ ଏବଂ ଶେଷରେ ଛୋଟ ନିଷ୍କର୍ଷ ଲେଖ।

🔄 QUICK REVISION

  • ଭୂମି = ମୌଳିକ ପ୍ରାକୃତିକ ସମ୍ବଳ
  • ମୁଖ୍ୟ ବ୍ୟବହାର = କୃଷି, ବନ, ଜନବସତି, ଶିଳ୍ପ, ପରିବହନ
  • ପତିତ ଭୂମି = କିଛି ସମୟ ଧରି ଚାଷ ହୋଇନଥିବା ଭୂମି
  • ଭୂ-ଅବକ୍ଷୟ = ଭୂମିର ଗୁଣ ଓ ଉତ୍ପାଦନ କ୍ଷମତାର ହ୍ରାସ
  • ସଂରକ୍ଷଣ = ପୁନଃବନୀକରଣ + ନିୟନ୍ତ୍ରିତ ପଶୁଚାରଣ + ଯୋଜନାବଦ୍ଧ ଭୂ-ବ୍ୟବହାର
