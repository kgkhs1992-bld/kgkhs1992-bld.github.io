📘 Chapter Introduction

A quadratic equation is an equation in which the highest power of the variable is 2. This chapter explains the standard form of a quadratic equation, methods of solving quadratic equations, the discriminant, nature of roots, relations between roots and coefficients, formation of equations and applications.

1️⃣ What is a Quadratic Equation?

A quadratic equation in one variable is an equation of the form:

ax² + bx + c = 0

where a, b and c are real numbers and a ≠ 0.

📌 The highest power of the variable is 2.

📌 The coefficient of x² must not be zero.

📌 The equation is called quadratic because its degree is two.
Examples of quadratic equations:

x² + 5x + 6 = 0
2x² − 7x + 3 = 0
3x² + 4x − 8 = 0

2️⃣ Standard Form

The standard form of a quadratic equation is:

ax² + bx + c = 0

Before applying any method, it is important to bring the equation into standard form.

Identify:

a = coefficient of x²

b = coefficient of x

c = constant term
Example:

For:
2x² − 5x + 3 = 0

a = 2
b = −5
c = 3

3️⃣ Solving by Factorisation

A quadratic equation can often be solved by factorisation.

General Method

  1. Write the equation in standard form.
  2. Factorise the quadratic expression.
  3. Use the zero-product property.
  4. Find the values of x.
Example:

x² − 5x + 6 = 0

Factorising:
(x − 2)(x − 3) = 0

Therefore:
x − 2 = 0
or
x − 3 = 0

Hence:
x = 2 or x = 3
📌 Always check the factors carefully before writing the roots.

4️⃣ Completing the Square

Another method of solving a quadratic equation is to convert it into a perfect square form.

Basic idea:

x² + 2px + p² = (x + p)²

and
x² − 2px + p² = (x − p)²

General Steps

  1. Write the equation in standard form.
  2. Move the constant term to the other side.
  3. Add the required quantity to make a perfect square.
  4. Write the expression as a square.
  5. Take square roots.
  6. Find the values of x.
⚠️ When adding a quantity to one side of an equation, the same quantity must be added to the other side.

5️⃣ Quadratic Formula

For a quadratic equation

ax² + bx + c = 0

the roots can be obtained using the quadratic formula:

x = (−b ± √(b² − 4ac)) / 2a

Steps for Using the Formula

  1. Write the equation in standard form.
  2. Identify a, b and c.
  3. Calculate b² − 4ac.
  4. Substitute the values in the formula.
  5. Simplify carefully.
  6. Write both possible roots.
Example:

For:
x² − 5x + 6 = 0

a = 1, b = −5, c = 6

Using:
x = (−b ± √(b² − 4ac)) / 2a
⚠️ Pay special attention to the sign of b when substituting into −b.

6️⃣ Discriminant

The expression

D = b² − 4ac

is called the discriminant of a quadratic equation.

Nature of Roots

If D > 0:
The equation has two distinct real roots.

If D = 0:
The equation has two equal real roots.

If D < 0:
The equation has no real roots.
📌 The discriminant helps us determine the nature of the roots without finding the roots completely.

7️⃣ Relation Between Roots and Coefficients

Suppose α and β are the roots of:

ax² + bx + c = 0

Then:

α + β = −b/a

αβ = c/a
Example:

For:
2x² − 7x + 3 = 0

a = 2
b = −7
c = 3

Therefore:
α + β = 7/2

αβ = 3/2
📌 Sum of roots = −b/a

📌 Product of roots = c/a

8️⃣ Formation of a Quadratic Equation

If α and β are the roots, the corresponding quadratic equation can be formed using:

x² − (α + β)x + αβ = 0
Example:

If:
α = 2,    β = 5

Then:
α + β = 7
αβ = 10

Therefore:
x² − 7x + 10 = 0

9️⃣ Equations Reducible to Quadratic Form

Some equations can be transformed into a quadratic equation by using a suitable substitution.

General Approach

1. Identify the repeated expression.

2. Replace it by a new variable.

3. Form a quadratic equation in the new variable.

4. Solve the quadratic equation.

5. Substitute back to obtain the required value of the original variable.
💡 Always substitute the obtained value back into the original expression when required.

🔟 Applications of Quadratic Equations

Quadratic equations are used to solve problems where the relationship between quantities leads to a second-degree equation.

General Steps

  1. Read the problem carefully.
  2. Let the unknown quantity be x.
  3. Express the other quantities in terms of x.
  4. Form the equation from the given condition.
  5. Convert it into quadratic form.
  6. Solve the quadratic equation.
  7. Check the obtained roots.
  8. Reject any root that does not satisfy the conditions of the problem.
  9. Write the final answer clearly.

1️⃣1️⃣ Checking a Solution

A value is a root of a quadratic equation only when substitution makes the original equation equal to zero.

Example:

For:
2x² − 5x + 2 = 0

substitute the proposed value of x into the original equation.
✅ If the result is 0, the value satisfies the equation.

❌ If the result is not 0, the value is not a root.

1️⃣3️⃣ Exam Preparation Points

  • ✔️ Write the equation clearly.
  • ✔️ Convert the equation to standard form.
  • ✔️ Identify a, b and c correctly.
  • ✔️ Be careful with positive and negative signs.
  • ✔️ Choose a suitable method.
  • ✔️ Show the important working steps.
  • ✔️ Write both roots clearly.
  • ✔️ Check the roots when required.
  • ✔️ In application problems, check whether the root satisfies the original condition.
