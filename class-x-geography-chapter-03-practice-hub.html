GEOGRAPHY — CHAPTER 03

ଜଳ ସମ୍ବଳ

🧠 MY PRACTICE HUB

📝 2-Mark Questions

1. ଜଳ କିପରି ଏକ ଅସରନ୍ତି ସମ୍ବଳ?
ଜଳଚକ୍ର ମାଧ୍ୟମରେ ଜଳ ନିରନ୍ତର ନବୀକରଣ ଓ ଭରଣା ହୁଏ।
2. ଜଳାଭାବ କ’ଣ?
ଆବଶ୍ୟକତା ପୂରଣ ପାଇଁ ପର୍ଯ୍ୟାପ୍ତ ଜଳ ଉପଲବ୍ଧ ନହେବାକୁ ଜଳାଭାବ କୁହାଯାଏ।
3. ଟନକା କ’ଣ?
ରାଜସ୍ଥାନରେ ବୃଷ୍ଟିଜଳ ସଂଗ୍ରହ ପାଇଁ ବ୍ୟବହୃତ ଭୂଗର୍ଭ ଜଳାଶୟ।
4. ପଲାରପାନି କ’ଣ?
ରାଜସ୍ଥାନରେ ସଂଗୃହୀତ ବୃଷ୍ଟିଜଳକୁ ପଲାରପାନି କୁହାଯାଏ।
5. ଜଳାଭାବର ଦୁଇଟି କାରଣ ଲେଖ।
ଜଳର ଅତ୍ୟଧିକ ଶୋଷଣ ଓ ଜଳ ପ୍ରଦୂଷଣ।

✍️ 3/5-Mark Questions

  1. ଜଳାଭାବର ପ୍ରମୁଖ କାରଣଗୁଡ଼ିକ ବୁଝାଅ।
  2. ବହୁମୁଖୀ ନଦୀବନ୍ଧ ଯୋଜନାର ଉଦ୍ଦେଶ୍ୟ ଲେଖ।
  3. ରାଜସ୍ଥାନର ଅର୍ଦ୍ଧଶୁଷ୍କ ଅଞ୍ଚଳରେ ବୃଷ୍ଟିଜଳ ଅମଳ ପଦ୍ଧତି ବର୍ଣ୍ଣନା କର।
  4. ପାରମ୍ପରିକ ବୃଷ୍ଟିଜଳ ଅମଳ ପଦ୍ଧତିର ଆଧୁନିକୀକରଣର ଉପଯୋଗିତା ବୁଝାଅ।
  5. ଜଳ ସଂରକ୍ଷଣ ପାଇଁ ପାଞ୍ଚଟି ପଦକ୍ଷେପ ଲେଖ।

🧠 Think & Learn

  1. ଅଧିକ ବୃଷ୍ଟି ହେଉଥିବା ଅଞ୍ଚଳରେ ମଧ୍ୟ ଜଳାଭାବ କାହିଁକି ହୋଇପାରେ?
  2. ଘରର ଛାତକୁ ବୃଷ୍ଟିଜଳ ଅମଳ ପାଇଁ କିପରି ବ୍ୟବହାର କରିବ?
  3. ବନ୍ଧ ନଦୀର ପ୍ରାକୃତିକ ପ୍ରବାହକୁ କିପରି ପ୍ରଭାବିତ କରିପାରେ?
  4. ତୁମ ବିଦ୍ୟାଳୟରେ ଜଳ ସଂରକ୍ଷଣ ପାଇଁ ଏକ ଯୋଜନା ଲେଖ।
