1️⃣ 7.1 — ସଡକରେ ପ୍ରଗତି / Arithmetic Sequence ର ପ୍ରୟୋଗ

ଅଧ୍ୟାୟର ପ୍ରଥମ ଅଂଶରେ ସଡକ ଓ ଟ୍ରାଫିକ ସମ୍ବନ୍ଧୀୟ ପରିସ୍ଥିତିକୁ Arithmetic Progression (A.P.) ସହିତ ବ୍ୟାଖ୍ୟା କରାଯାଇଛି। ଯେତେବେଳେ କ୍ରମିକ ମାପଗୁଡ଼ିକରେ ସମାନ ଅନ୍ତର ରହେ, A.P. ବ୍ୟବହାର କରାଯାଏ।

a, a+d, a+2d, a+3d, ...
tₙ = a + (n−1)d
Sₙ = n/2 [2a + (n−1)d]

ଯେଉଁଠାରେ a = ପ୍ରଥମ ପଦ, d = common difference, tₙ = n-ତମ ପଦ।

2️⃣ A.P. ର 10ମ ପଦ — ଅଧ୍ୟାୟର ଉଦାହରଣ

ଦିଆଯାଇଛି: a = 3, d = 2। 10ମ ପଦ ନିର୍ଣ୍ଣୟ କର।

tₙ = a+(n−1)d

t₁₀ = 3+(10−1)×2

= 3+18 = 21

ଉତ୍ତର: 10ମ ପଦ = 21

3️⃣ ଅଧ୍ୟାୟର A.P. ଉଦାହରଣ — 3ୟ ଓ 8ମ ପଦ

ପ୍ରଶ୍ନ: କୌଣସି A.P. ର 3ୟ ପଦ 1500 ଏବଂ 8ମ ପଦ 3000। 15ମ ପଦ ନିର୍ଣ୍ଣୟ କର।

t₃ = a+2d = 1500 … (i)

t₈ = a+7d = 3000 … (ii)

(ii) ରୁ (i) ବିୟୋଗ କଲେ:

5d = 1500 ⇒ d = 300

(i) ରେ d=300 ବସାଇଲେ:

a+2×300=1500 ⇒ a=900

ଏବେ,

t₁₅ = a+14d = 900+14×300 = 5100

4️⃣ 7.2 — ପରିସଂଖ୍ୟାନର ପ୍ରୟୋଗ

ଏହି ଅଂଶରେ ସଡକ ଦୁର୍ଘଟଣା, ଯାନବାହନ ଓ ପ୍ରଦୂଷଣ ନିୟନ୍ତ୍ରଣ ସମ୍ବନ୍ଧୀୟ ତଥ୍ୟକୁ table, bar graph, line graph ଓ pie chart ଦ୍ୱାରା ବୁଝାଯାଇଛି।

  • ତଥ୍ୟକୁ ସଂଗଠିତ କରିବା
  • ଗ୍ରାଫ୍ ପଢ଼ିବା
  • ପ୍ରତିଶତ ନିର୍ଣ୍ଣୟ
  • Pie chart ର କୋଣ ଠାରୁ ମୋଟ ମୂଲ୍ୟ ନିର୍ଣ୍ଣୟ

5️⃣ Percentage ନିର୍ଣ୍ଣୟ

ପ୍ରଶ୍ନର ପ୍ରକାର: ଦୁଇ ବର୍ଷର ତଥ୍ୟ ଦିଆଯାଇଥିଲେ ବୃଦ୍ଧି/ହ୍ରାସର ପ୍ରତିଶତ ନିର୍ଣ୍ଣୟ କର।
Percentage change = (Change / Original value) × 100

ଉଦାହରଣ: 300 ଠାରୁ 350 ହେଲେ change = 50।

Percentage = 50/300 ×100 = 16⅔%।

6️⃣ Pie Chart — ମୂଳ ଧାରଣା

ଗୋଟିଏ ସମ୍ପୂର୍ଣ୍ଣ pie chart ର କେନ୍ଦ୍ରୀୟ କୋଣର ଯୋଗ:

360°

ତେଣୁ କୌଣସି category ର ମୂଲ୍ୟ ନିର୍ଣ୍ଣୟ ପାଇଁ:

Category value = (Category angle / 360°) × Total value
ଯଦି total = 10800 ଏବଂ କୋଣ = 120°, ତେବେ value = 10800/360 ×120 = 3600।
ଯଦି କୋଣ = 90°, value = 10800/360 ×90 = 2700।

7️⃣ 7.3 — ତ୍ରିକୋଣମିତିର ପ୍ରୟୋଗ

ସଡକ ସୁରକ୍ଷାରେ CCTV camera, ଯାନର ଉଚ୍ଚତା, ଦୂରତା ଓ line of sight ପରି ସମସ୍ୟା ସମାଧାନ ପାଇଁ right triangle ଓ trigonometric ratio ବ୍ୟବହାର କରାଯାଇଛି।

tan θ = Opposite / Adjacent
sin θ = Opposite / Hypotenuse
cos θ = Adjacent / Hypotenuse

8️⃣ CCTV — Height ନିର୍ଣ୍ଣୟ

ଉଦାହରଣ: CCTV ଠାରୁ ରାସ୍ତାର ଏକ ବିନ୍ଦୁର horizontal distance 10 m ଏବଂ angle of elevation 45°। CCTV ର ଉଚ୍ଚତା h ନିର୍ଣ୍ଣୟ କର।

tan45° = h/10

1 = h/10

h = 10 m

9️⃣ CCTV — 12 m ଉଚ୍ଚତା ଓ 13 m line of sight

ଅଧ୍ୟାୟର ଉଦାହରଣ: ଚିତ୍ରରେ OA=12 m ଏବଂ AB=13 m। ପୃଥିବୀ ଉପରେ CCTV ର vertical projection ଠାରୁ B ପର୍ଯ୍ୟନ୍ତ ଦୂରତା ନିର୍ଣ୍ଣୟ କର।

Right triangle AOB ରେ:

OB = √(AB² − OA²)

= √(13²−12²) = √(169−144) = 5 m

ପାଠ୍ୟପୁସ୍ତକର ଚିତ୍ରରେ green belt ଏହି OB ଚାରିପାଖରେ ବୃତ୍ତାକାର ଭାବେ ଦର୍ଶାଯାଇଛି।

Area = π(OB)² = π×25 = 25π m²

🔟 CCTV — Pythagoras ର ପ୍ରୟୋଗ

ଉଦାହରଣ: AB=8 m ଏବଂ AC=17 m ହେଲେ BC ନିର୍ଣ୍ଣୟ କର।

AC² = AB² + BC²

17² = 8² + BC²

BC² = 289−64 =225

BC=15 m

ଯଦି BC କୁ ବୃତ୍ତର radius ଭାବେ ନିଆଯାଏ, area = π(15)² = 225π ≈ 706.5 m² (π≈3.14) ପାଠ୍ୟପୁସ୍ତକ ଉଦାହରଣ ଅନୁସାରେ।

1️⃣1️⃣ 7.4 — ଦୁଇ ଚକା ଯାନର ବିଶିଷ୍ଟ ସମସ୍ୟା

ଏହି ଅଂଶରେ ସଡକରେ ଯାନ ଥମାଇବା ପାଇଁ ଆବଶ୍ୟକ ଦୂରତା ଏବଂ reaction/braking distance ବିଷୟରେ ଆଲୋଚନା ହୋଇଛି।

Reaction distance + Braking distance = Stopping distance

ମୂଳ ପାଠ୍ୟପୁସ୍ତକରେ ଏହା ପରେ reaction time ଓ chasing distance ସମ୍ବନ୍ଧୀୟ ଏକ ସମ୍ପର୍କ ମଧ୍ୟ ଦିଆଯାଇଛି।

1️⃣2️⃣ Chasing Distance

ସଡକରେ ଆଗରେ ଚାଲୁଥିବା ଯାନକୁ ପଛରୁ ଆସୁଥିବା ଯାନ ଧାଉଥିବା ସମୟରେ ଯାନମାନଙ୍କ ମଧ୍ୟରେ ନିରାପଦ ଦୂରତା ରଖିବା ଆବଶ୍ୟକ। ପାଠ୍ୟପୁସ୍ତକରେ 19, 20, 21 ପରି ସଂଖ୍ୟା ଦେଖାଉଥିବା road illustration ଦ୍ୱାରା ଏହି ଧାରଣାକୁ ବୁଝାଯାଇଛି।

ମୁଖ୍ୟ ଶିକ୍ଷା: ଯାନ ଚଳାଇବା ସମୟରେ ଆଗର ଯାନ ସହ ଯଥେଷ୍ଟ ଦୂରତା ରଖିବା road safety ର ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ ଅଂଶ।

1️⃣3️⃣ ଏହି ଅଧ୍ୟାୟରେ ମନେ ରଖିବା Formula

tₙ = a+(n−1)d
Sₙ = n/2[2a+(n−1)d]
Percentage = (Change/Original)×100
Pie-chart value = (Angle/360°)×Total
tanθ = Opposite/Adjacent
sinθ = Opposite/Hypotenuse
cosθ = Adjacent/Hypotenuse
AC² = AB²+BC² (Right triangle)
Reaction distance + Braking distance = Stopping distance

1️⃣4️⃣ ପରୀକ୍ଷାରେ ପ୍ରଶ୍ନ କିପରି ଆସିପାରେ?

  • A.P. ର n-ତମ ପଦ ନିର୍ଣ୍ଣୟ।
  • ଦୁଇଟି ପଦ ଦିଆଯାଇ a ଓ d ନିର୍ଣ୍ଣୟ।
  • Bar/line graph ଠାରୁ ତଥ୍ୟ ପଢ଼ିବା।
  • ଦୁଇ ବର୍ଷର data ର percentage change।
  • Pie chart ର angle ଠାରୁ actual number।
  • CCTV problem ରେ height/distance ନିର୍ଣ୍ଣୟ।
  • Right triangle ରେ Pythagoras theorem ବ୍ୟବହାର।
  • Stopping distance, reaction distance ଓ braking distance ବିଷୟକ ପ୍ରଶ୍ନ।
