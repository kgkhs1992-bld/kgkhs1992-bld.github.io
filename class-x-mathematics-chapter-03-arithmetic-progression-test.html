Chapter 03 – Arithmetic Progression

🎯 Chapter Test

📝 10 Questions × 5 Marks = 50 Marks
Important Formulae:
n-th term: tₙ = a + (n − 1)d
Sum of n terms: Sₙ = n/2 [2a + (n − 1)d]
Also, Sₙ = n/2(a + l)

Q1. (5 Marks)

ଏକ Arithmetic Progression (A.P.) ର ପ୍ରଥମ ପଦ 5 ଏବଂ ସାଧାରଣ ଅନ୍ତର 3 । ଏହାର 20ତମ ପଦ ନିର୍ଣ୍ଣୟ କର।

ଉତ୍ତର:
a = 5, d = 3, n = 20
t₂₀ = a + (n−1)d = 5 + 19×3 = 62।

Q2. (5 Marks)

A.P. 7, 11, 15, 19, ... ର 25ତମ ପଦ ନିର୍ଣ୍ଣୟ କର।

ଉତ୍ତର:
a = 7, d = 4, n = 25
t₂₅ = 7 + 24×4 = 103।

Q3. (5 Marks)

A.P. 3, 8, 13, 18, ... ର ପ୍ରଥମ 20ଟି ପଦର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।

ଉତ୍ତର:
a = 3, d = 5, n = 20
S₂₀ = 20/2 [2(3) + 19(5)]
= 10(6 + 95) = 1010।

Q4. (5 Marks)

A.P. 12, 17, 22, 27, ... ର 15ତମ ପଦ ଏବଂ ପ୍ରଥମ 15ଟି ପଦର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।

ଉତ୍ତର:
a = 12, d = 5, n = 15
t₁₅ = 12 + 14×5 = 82
S₁₅ = 15/2(12 + 82) = 15/2×94 = 705।

Q5. (5 Marks)

ଏକ A.P. ର 5ତମ ପଦ 18 ଏବଂ 10ତମ ପଦ 33 । ଏହାର ପ୍ରଥମ ପଦ ଓ ସାଧାରଣ ଅନ୍ତର ନିର୍ଣ୍ଣୟ କର।

ଉତ୍ତର:
a + 4d = 18 ...(1)
a + 9d = 33 ...(2)
(2)−(1): 5d = 15 ⇒ d = 3
a + 12 = 18 ⇒ a = 6।

Q6. (5 Marks)

A.P. 20, 17, 14, 11, ... ର 10ତମ ପଦ ନିର୍ଣ୍ଣୟ କର ଏବଂ ଏହି ପଦ ଧନାତ୍ମକ କି ନୁହେଁ ଲେଖ।

ଉତ୍ତର:
a = 20, d = −3, n = 10
t₁₀ = 20 + 9(−3) = 20 − 27 = −7।
ତେଣୁ 10ତମ ପଦ ଧନାତ୍ମକ ନୁହେଁ; ଏହା ଋଣାତ୍ମକ।

Q7. (5 Marks)

A.P. 5, 9, 13, 17, ... ର କେଉଁ ପଦ 81 ହେବ? ଗଣନା କର।

ଉତ୍ତର:
tₙ = a + (n−1)d
81 = 5 + (n−1)4
76 = 4(n−1)
n−1 = 19 ⇒ n = 20।
ତେଣୁ 20ତମ ପଦ = 81।

Q8. (5 Marks)

ପ୍ରଥମ 25ଟି ସ୍ୱାଭାବିକ ସଂଖ୍ୟାର ଯୋଗଫଳ A.P. ସୂତ୍ର ବ୍ୟବହାର କରି ନିର୍ଣ୍ଣୟ କର।

ଉତ୍ତର:
a = 1, d = 1, n = 25, l = 25
S₂₅ = 25/2(1 + 25)
= 25/2 × 26 = 325।

Q9. (5 Marks)

ଏକ A.P. ର ପ୍ରଥମ ପଦ 4, ଶେଷ ପଦ 40 ଏବଂ ପଦ ସଂଖ୍ୟା 10 । ଏହାର ସାଧାରଣ ଅନ୍ତର ଏବଂ ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।

ଉତ୍ତର:
l = a + (n−1)d
40 = 4 + 9d ⇒ 36 = 9d ⇒ d = 4
S₁₀ = 10/2(4 + 40) = 5×44 = 220।

Q10. (5 Marks)

A.P. 2, 6, 10, 14, ... ର ପ୍ରଥମ 30ଟି ପଦର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର। ଏହାପରେ 30ତମ ପଦ ମଧ୍ୟ ନିର୍ଣ୍ଣୟ କର।

ଉତ୍ତର:
a = 2, d = 4, n = 30
t₃₀ = 2 + 29×4 = 118
S₃₀ = 30/2 [2(2) + 29(4)]
= 15(4 + 116) = 15×120 = 1800।
