Chapter 03 – Arithmetic Progression

🔄 Quick Revision

📌 1. A.P. କ'ଣ?

ଏପରି ସଂଖ୍ୟାମାଳା ଯେଉଁଥିରେ ପରପର ଦୁଇଟି ପଦର ପାର୍ଥକ୍ୟ ସମାନ ଥାଏ, ତାହାକୁ Arithmetic Progression (A.P.) କୁହାଯାଏ।

ଉଦାହରଣ: 3, 7, 11, 15, ... — ଏଠାରେ d = 4

📌 2. ମୁଖ୍ୟ ପରିଚୟ

  • ପ୍ରଥମ ପଦ = a
  • ସାଧାରଣ ଅନ୍ତର = d
  • ପଦ ସଂଖ୍ୟା = n
  • n-ତମ ପଦ = tₙ
  • ପ୍ରଥମ n ପଦର ଯୋଗ = Sₙ
  • ଶେଷ ପଦ = l

🧮 3. ମୁଖ୍ୟ ସୂତ୍ର

n-ତମ ପଦ:
tₙ = a + (n − 1)d

ପ୍ରଥମ n ପଦର ଯୋଗ:
Sₙ = n/2 [2a + (n − 1)d]

ଶେଷ ପଦ l ଦିଆଥିଲେ:
Sₙ = n/2(a + l)

📌 4. Common Difference

d = ଦ୍ୱିତୀୟ ପଦ − ପ୍ରଥମ ପଦ

ଉଦାହରଣ: 8, 13, 18, 23, ...
d = 13 − 8 = 5

📌 5. n-ତମ ପଦ କିପରି ପାଇବ?

ପ୍ରଥମେ a, d, n ଚିହ୍ନଟ କର।

ତାପରେ:

tₙ = a + (n − 1)d

ଉଦାହରଣ: a=5, d=3, n=10

t₁₀ = 5 + 9×3 = 32

📌 6. Sum କିପରି ପାଇବ?

a, d ଏବଂ n ଦିଆଥିଲେ:

Sₙ = n/2 [2a + (n−1)d]

a, l ଏବଂ n ଦିଆଥିଲେ:

Sₙ = n/2(a+l)

📌 7. ମନେ ରଖ

  • n−1 ଭୁଲିବ ନାହିଁ।
  • d ର positive/negative sign ଯାଞ୍ଚ କର।
  • Sum ପାଇଁ n/2 ନିଶ୍ଚିତ ରଖ।
  • ପ୍ରଥମ ପଦ a ଠିକ୍ ଚିହ୍ନଟ କର।
  • ଶେଷ ପଦ ଦିଆଥିଲେ Sₙ = n/2(a+l) ବ୍ୟବହାର କରିପାରିବ।

⚡ 8. Quick Examples

A.P.: 2, 5, 8, 11, ...

a = 2, d = 3

t₁₀ = 2 + 9×3 = 29

S₁₀ = 10/2(2+29) = 155

🎯 9. Exam Checklist

  • Question ଭଲଭାବେ ପଢ଼।
  • a, d, n, l ଚିହ୍ନଟ କର।
  • ଠିକ୍ formula ଲେଖ।
  • ମୂଲ୍ୟ substitute କର।
  • Calculation ଯାଞ୍ଚ କର।
  • ଶେଷରେ ଉତ୍ତର ସ୍ପଷ୍ଟ ଭାବେ ଲେଖ।
