Chapter 1: Set Operations and Application of Set

Set (ସମୁଚ୍ଚୟ)

ନିର୍ଦ୍ଦିଷ୍ଟ ଭାବରେ ଚିହ୍ନଟ କରିହେବା ଉପାଦାନମାନଙ୍କର ଏକ ସୁସ୍ପଷ୍ଟ ସଂଗ୍ରହକୁ Set କୁହାଯାଏ। ଉଦାହରଣ: A = {1,2,3,4}.

Set ଓ Elements

Set ର ଭିତରେ ଥିବା ବସ୍ତୁ/ସଂଖ୍ୟାକୁ element କୁହାଯାଏ। x ∈ A ଅର୍ଥ x, A ର ଏକ element; x ∉ A ଅର୍ଥ x, A ରେ ନାହିଁ।

Roster / Tabular Method

ସମସ୍ତ element କୁ { } ମଧ୍ୟରେ ଲେଖି Set ପ୍ରକାଶ କରାଯାଏ। ଯଥା S={1,2,3,4,5}.

Set-builder Method

Set ର element ଗୁଡ଼ିକର ସାଧାରଣ ଗୁଣ/ଶର୍ତ୍ତ ଦେଇ Set ପ୍ରକାଶ କରାଯାଏ। ଯଥା S={x | x∈N, 1≤x≤5}.

Finite ଓ Infinite Set

ଯେଉଁ Set ର element ସଂଖ୍ୟା ସୀମିତ, ସେହିଟି finite set; element ସଂଖ୍ୟା ଅସୀମ ହେଲେ infinite set।

Empty / Null Set

ଯେଉଁ Set ରେ କୌଣସି element ନାହିଁ, ତାହା empty set ବା null set। ଏହାକୁ ∅ ବା { } ଦ୍ୱାରା ଲେଖାଯାଏ।

Subset

A ର ପ୍ରତ୍ୟେକ element ଯଦି B ରେ ଥାଏ, ତେବେ A, B ର subset; A ⊆ B. ପ୍ରତ୍ୟେକ set ନିଜର subset।

Equality of Sets

A ଓ B ରେ ଠିକ୍ ସମାନ elements ଥିଲେ A=B. Element ର କ୍ରମ ବଦଳିଲେ Set বদলায় ନାହିଁ ଏବଂ repeated element ଏକଥର ହିଁ ଗଣାଯାଏ।

Universal Set

ଆଲୋଚନା କରାଯାଉଥିବା ସମସ୍ତ relevant elements ଥିବା ବଡ଼ Set କୁ universal set କୁହାଯାଏ। ସାଧାରଣତଃ U ବା E ଦ୍ୱାରା ପ୍ରକାଶ କରାଯାଏ।

Union

A ଓ B ର ସମସ୍ତ elements କୁ ଏକତ୍ର କରିଥିବା Set ହେଉଛି union: A∪B={x | x∈A କିମ୍ବା x∈B}.

Intersection

A ଓ B ର common elements ମାନଙ୍କର Set ହେଉଛି intersection: A∩B={x | x∈A ଏବଂ x∈B}.

Difference

A-B ରେ A ରେ ଥିବା କିନ୍ତୁ B ରେ ନଥିବା elements ରହେ: A-B={x | x∈A ଏବଂ x∉B}. ସେହିପରି B-A ମଧ୍ୟ ଭିନ୍ନ ହୋଇପାରେ।

Important Laws

Union ଓ intersection ର commutative ଏବଂ associative laws ରହେ। Distributive laws: A∪(B∩C)=(A∪B)∩(A∪C) ଏବଂ A∩(B∪C)=(A∩B)∪(A∩C).

Complement

Universal set E ମଧ୍ୟରେ A ରେ ନଥିବା elements ର Set କୁ A ର complement କୁହାଯାଏ: A′=E-A.
