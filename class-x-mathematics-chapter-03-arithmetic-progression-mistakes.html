Chapter 03 – Arithmetic Progression

⚠️ Common Mistakes

ମୁଖ୍ୟ ସୂତ୍ର:
n-ତମ ପଦ: tₙ = a + (n − 1)d
ପ୍ରଥମ n ପଦର ଯୋଗ: Sₙ = n/2 [2a + (n − 1)d]
ଶେଷ ପଦ l ଦିଆଥିଲେ: Sₙ = n/2(a + l)

1. (n − 1) ଭୁଲିଯିବା

❌ ଭୁଲ: tₙ = a + nd
✅ ଠିକ୍: tₙ = a + (n − 1)d

ଉଦାହରଣ: a = 5, d = 3 ହେଲେ t₂₀ = 5 + 19×3 = 62।

2. ସାଧାରଣ ଅନ୍ତର d ର ଚିହ୍ନ ଭୁଲ କରିବା

❌ 20, 17, 14, 11, ... ରେ d = 3 ଲେଖିବା।
✅ d = 17 − 20 = −3

ପଦଗୁଡ଼ିକ କମୁଥିଲେ d ସାଧାରଣତଃ ଋଣାତ୍ମକ ହୁଏ।

3. a ଏବଂ d ର ସ୍ଥାନ ଅଦଳବଦଳ କରିବା

❌ 7, 11, 15, 19, ... ପାଇଁ a = 4, d = 7।
✅ a = 7, d = 4

a ହେଉଛି ପ୍ରଥମ ପଦ ଏବଂ d ହେଉଛି ପରପର ପଦର ପାର୍ଥକ୍ୟ।

4. Sum ରେ n/2 ଭୁଲିଯିବା

❌ Sₙ = n[2a + (n−1)d]
✅ Sₙ = n/2[2a + (n−1)d]

ଯୋଗ କରିବା ପୂର୍ବରୁ n/2 ଅଂଶଟି ନିଶ୍ଚିତ ଯାଞ୍ଚ କର।

5. ପଦ ସଂଖ୍ୟା n ନିର୍ଣ୍ଣୟରେ ଭୁଲ

A.P. ର ଏକ ପଦ x ଦିଆଥିଲେ:

x = a + (n−1)d

ପ୍ରଥମେ ସୂତ୍ରରେ ମୂଲ୍ୟ ବସାଇ, ପରେ n ନିର୍ଣ୍ଣୟ କର।

6. ଶେଷ ପଦ l କୁ n-ତମ ପଦ ସହ ଗୋଳମାଳ କରିବା

ଯଦି ଏକ A.P. ରେ nଟି ପଦ ଅଛି, ତେବେ ଶେଷ ପଦକୁ l କିମ୍ବା tₙ ଭାବେ ଲେଖିପାରିବ।

Sₙ = n/2(a + l)

କିନ୍ତୁ l ର ମୂଲ୍ୟ ନିଶ୍ଚିତ ଭାବରେ ଶେଷ ପଦ ହେବା ଦରକାର।

7. ଋଣାତ୍ମକ d ରେ ଚିହ୍ନ ଭୁଲ କରିବା

ଯଦି d = −3, ତେବେ:

a + (n−1)d = a − 3(n−1)

−3 କୁ +3 କରିଦେଲେ ସମଗ୍ର ଉତ୍ତର ବଦଳିଯିବ।

8. ପ୍ରଥମ ପଦକୁ 0 ଧରିବା

A.P. 2, 6, 10, 14, ... ରେ ପ୍ରଥମ ପଦ a = 2। ତାହାକୁ 0 ଧରିବା ଠିକ୍ ନୁହେଁ।

9. Calculation ଶେଷରେ ଯାଞ୍ଚ ନକରିବା

ଉତ୍ତର ପାଇବା ପରେ ଏହା A.P. ର ପଦ ସହ ସମଞ୍ଜସ କି ନୁହେଁ ଯାଞ୍ଚ କର। ବିଶେଷକରି d ଋଣାତ୍ମକ ହେଲେ ଏହା ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ।

10. Question ଅନୁଯାୟୀ ସୂତ୍ର ଚୟନ ନକରିବା

n-ତମ ପଦ ପାଇଁ tₙ ସୂତ୍ର ଏବଂ ଯୋଗଫଳ ପାଇଁ Sₙ ସୂତ୍ର ବ୍ୟବହାର କର।
