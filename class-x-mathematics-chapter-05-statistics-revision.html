🔄 Quick Revision

ସୂତ୍ର

Mean = Σxᵢ/n

Σ(xᵢ−M)=0

Even Median = ଦୁଇ ମଧ୍ୟସ୍ଥ observation ର average

3ଟି ମୁଖ୍ୟ ମାପ

  • Mean → arithmetic average
  • Median → ordered data ର middle value
  • Mode → ସର୍ବାଧିକ ଥର ଘଟୁଥିବା value

Exam Steps

  1. Data ଠିକ୍ ଭାବେ ଲେଖ।
  2. Median ପାଇଁ order କର।
  3. Mean ପାଇଁ sum ଓ n ନିଅ।
  4. Mode ପାଇଁ frequency ଦେଖ।
