Step-by-step examples covering the important methods and results of quadratic equations.

1️⃣ Solving a Quadratic Equation by Factorisation

Solve:

x² − 5x + 6 = 0
Solution:

Factorise the quadratic expression:

x² − 5x + 6
= (x − 2)(x − 3)

Therefore,
(x − 2)(x − 3) = 0

Hence,
x − 2 = 0    or    x − 3 = 0

Therefore,
x = 2    or    x = 3
✅ Answer: x = 2, 3

2️⃣ Solving by the Quadratic Formula

Solve:

6x² + 11x + 3 = 0
For ax² + bx + c = 0,

x = (−b ± √(b² − 4ac)) / 2a
Here,

a = 6,   b = 11,   c = 3

First calculate the discriminant:

D = b² − 4ac
= 11² − 4 × 6 × 3
= 121 − 72
= 49

Therefore,
x = (−11 ± √49) / 12
= (−11 ± 7) / 12
First root:

x = (−11 + 7) / 12
= −4 / 12
= −1/3

Second root:

x = (−11 − 7) / 12
= −18 / 12
= −3/2
✅ Answer:

x = −1/3   or   x = −3/2

3️⃣ Solving by Completing the Square

Solve:

x² + 2x − 63 = 0
Rearrange:

x² + 2x = 63

Complete the square:

x² + 2x + 1 = 64

Therefore,
(x + 1)² = 64

Taking square roots:
x + 1 = ±8
Therefore,

x + 1 = 8
x = 7

or

x + 1 = −8
x = −9
✅ Answer: x = 7, −9

4️⃣ Finding the Nature of Roots

Determine the nature of the roots of:

x² − 2x − 8 = 0
Here,

a = 1,   b = −2,   c = −8

Discriminant:

D = b² − 4ac
= (−2)² − 4(1)(−8)
= 4 + 32
= 36

Since,
D > 0

the equation has two distinct real roots.
✅ Answer: Two distinct real roots.

5️⃣ Relation Between Roots and Coefficients

If α and β are the roots of:

25x² + 30x + 7 = 0,
find α + β and αβ.
For ax² + bx + c = 0:

α + β = −b/a

αβ = c/a
Here,

a = 25,   b = 30,   c = 7

Therefore,

α + β = −30/25
= −6/5

and

αβ = 7/25
✅ Answer:

α + β = −6/5
αβ = 7/25

6️⃣ Finding the Equation When Roots Are Known

Form the quadratic equation whose roots are α and β, where:

α = 2,   β = 5
For a quadratic equation with roots α and β:

x² − (α + β)x + αβ = 0

Here,
α + β = 2 + 5 = 7

and
αβ = 2 × 5 = 10

Therefore,
x² − 7x + 10 = 0
✅ Answer:

x² − 7x + 10 = 0

7️⃣ Forming a Quadratic Equation from Given Sum and Product of Roots

The sum of the roots is 5 and their product is 6. Form the quadratic equation.
We know:

α + β = 5
αβ = 6

The required equation is:

x² − (α + β)x + αβ = 0

Therefore,
x² − 5x + 6 = 0
✅ Answer:

x² − 5x + 6 = 0

8️⃣ Equation Reducible to Quadratic Form

Solve:

4(x − 1/x)² + 8(x + 1/x) − 29 = 0
Let

y = x + 1/x

We know:
(x − 1/x)² = (x + 1/x)² − 4

Therefore,
4(y² − 4) + 8y − 29 = 0
4y² + 8y − 45 = 0
Using the quadratic formula:

y = [−8 ± √(64 + 720)] / 8
= [−8 ± √784] / 8
= [−8 ± 28] / 8

Therefore,
y = 5/2   or   y = −9/2
💡 First convert the equation into a quadratic equation in y.

9️⃣ Application – Two Consecutive Integers

The product of two consecutive positive integers is 90. Find the integers.
Let the smaller integer be x.

The next integer is x + 1.

Therefore,
x(x + 1) = 90

x² + x − 90 = 0

Factorising:
(x + 10)(x − 9) = 0

Therefore,
x = −10   or   x = 9

Since the integers are positive:
x = 9

The next integer is 10.
✅ Answer: 9 and 10

🔟 Application of Quadratic Equation

A word problem gives rise to a quadratic equation. Explain the steps used to solve the problem.
Step 1: Let the unknown quantity be x.

Step 2: Express the other quantity in terms of x.

Step 3: Form the required equation.

Step 4: Bring it to the standard form:

ax² + bx + c = 0

Step 5: Solve the quadratic equation.

Step 6: Check which root satisfies the conditions of the problem.
💡 In application problems, a root must satisfy the original conditions before it is accepted.

1️⃣1️⃣ Checking Whether a Number is a Root

Check whether x = 3 is a root of:

2x² − 5x + 2 = 0
Substitute x = 3:

2(3)² − 5(3) + 2
= 18 − 15 + 2
= 5

Since the result is not zero,
x = 3 is not a root.
❌ Answer: x = 3 is not a root.

1️⃣2️⃣ Nature of Roots Using the Discriminant

For a quadratic equation

ax² + bx + c = 0

determine the nature of roots using D.
D = b² − 4ac

D > 0 → Two distinct real roots
D = 0 → Two equal real roots
D < 0 → No real roots
🎯 Remember:

D > 0 → distinct roots
D = 0 → equal roots
D < 0 → no real roots

🎯 How to Write a Quadratic Equation Solution

Step 1: Write the equation in standard form.

Step 2: Identify a, b and c.

Step 3: Choose a suitable method.

Step 4: Show the calculation clearly.

Step 5: Write both roots.

Step 6: Check the answer when necessary.

Step 7: For word problems, interpret the answer.
