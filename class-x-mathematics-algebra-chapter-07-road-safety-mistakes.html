⚠️ Common Mistakes

🔙 Back to Class X Mathematics

📘 How to Use This Page

This page highlights common calculation and presentation mistakes that students may make while solving the mathematical problems in Chapter 07 – Road Safety. Always compare your working with the exact data and wording given in the textbook question.

1️⃣ AP: Wrong Common Difference

❌ Mistake: In 5, 8, 11, 14, ... writing d = 2.
✅ Correct: d = 8 − 5 = 3. Check the difference between consecutive terms.

2️⃣ AP: Wrong nth-Term Formula

❌ Mistake: Using an = a + nd.
✅ Correct: an = a + (n − 1)d.
an = a + (n − 1)d

3️⃣ AP: Forgetting n − 1

❌ Mistake: For the 10th term, using 10d instead of 9d.
✅ Correct: The first term is already a, so the 10th term contains 9 common differences.

4️⃣ AP: Sum Formula Error

❌ Mistake: Writing Sn = n[2a + (n−1)d].
✅ Correct: Do not forget the factor 1/2.
Sn = n/2 [2a + (n − 1)d]

5️⃣ Percentage: Wrong Base

❌ Mistake: Dividing the change by the new value.
✅ Correct: For percentage increase or decrease, divide the change by the original value.
Percentage change = (Change ÷ Original value) × 100

6️⃣ Percentage: Confusing Increase and Decrease

❌ Mistake: If a value changes from 500 to 400, calling it a 100% decrease.
✅ Correct: Decrease = 100; percentage decrease = (100/500)×100 = 20%.

7️⃣ Bar Graph: Reading the Wrong Scale

❌ Mistake: Reading a bar as 40 when the graph scale actually represents 20 units per division.
✅ Correct: Read the scale on the vertical axis first, then read each bar.

8️⃣ Pie Chart: Forgetting 360°

❌ Mistake: Calculating a sector value using θ/180 instead of θ/360.
✅ Correct: A complete circle contains 360°.
Value = (θ/360°) × Total

9️⃣ Pie Chart: Wrong Sector Angle

❌ Mistake: Using the angle of another category.
✅ Correct: Match the category name with its exact sector before calculating.

🔟 Trigonometry: Mixing Up tan

❌ Mistake: Writing tan θ = base/perpendicular.
✅ Correct: tan θ = perpendicular/base.
tan θ = Perpendicular ÷ Base

1️⃣1️⃣ Trigonometry: Wrong Angle

❌ Mistake: Using the angle at the wrong point of the triangle.
✅ Correct: Mark the angle given in the question and identify the opposite and adjacent sides relative to that angle.

1️⃣2️⃣ Pythagoras: Wrong Side

❌ Mistake: Treating the shortest side as the hypotenuse.
✅ Correct: The hypotenuse is always the side opposite the right angle and is the longest side.
Hypotenuse² = Perpendicular² + Base²

1️⃣3️⃣ CCTV: Confusing Height and Horizontal Distance

❌ Mistake: Putting the horizontal distance in the numerator when using tan.
✅ Correct: Relative to the selected angle, identify the perpendicular and base first.

1️⃣4️⃣ CCTV: Ignoring Units

❌ Mistake: Giving a distance without m, cm or km.
✅ Correct: Always write the unit with the final answer.

1️⃣5️⃣ Line of Sight: Using It as the Base

❌ Mistake: Treating a sloping line of sight as the horizontal distance.
✅ Correct: In a right triangle, the line of sight is generally the hypotenuse in the CCTV setup.

1️⃣6️⃣ Reaction Distance vs Braking Distance

❌ Mistake: Treating reaction distance as the distance travelled after brakes are applied.
✅ Correct: Reaction distance is travelled while the driver reacts; braking distance is travelled after braking begins until the vehicle stops.

1️⃣7️⃣ Stopping Distance

❌ Mistake: Subtracting reaction distance from braking distance.
✅ Correct: Add them.
Stopping distance = Reaction distance + Braking distance

1️⃣8️⃣ Speed Conversion

❌ Mistake: Treating km/h and m/s as the same unit.
✅ Correct: To convert km/h to m/s, multiply by 5/18.
50 km/h = 50 × 5/18 ≈ 13.89 m/s

1️⃣9️⃣ Equation of Motion

❌ Mistake: Forgetting that acceleration can be negative during deceleration.
✅ Correct: If the vehicle is slowing down in the chosen positive direction, use the appropriate negative acceleration.
v = u + at

2️⃣0️⃣ Final Answer Without Working

❌ Mistake: Writing only the final number.
✅ Correct: Show the formula, substitution, calculation and final answer with unit. This makes the solution clear and easy to verify.

  • ☑ Did I identify the correct formula?
  • ☑ Did I use n−1 in the AP nth-term formula?
  • ☑ Did I use 360° for a complete pie chart?
  • ☑ Did I identify the correct sides for tan?
  • ☑ Did I identify the hypotenuse correctly?
  • ☑ Did I distinguish reaction distance from braking distance?
  • ☑ Did I use the correct units?
  • ☑ Did I show all important calculation steps?
