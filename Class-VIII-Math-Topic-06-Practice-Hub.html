✍️ ୫ ମାର୍କ — ୩ଟି ଦୀର୍ଘ ପ୍ରଶ୍ନୋତ୍ତର

ପ୍ରଶ୍ନ–୧. ଗୁଣନର ବଣ୍ଟନ ଗୁଣଧର୍ମ ବୁଝାଇ ଉଦାହରଣ ସହ ଲେଖ।

ଉତ୍ତର: ଗୋଟିଏ ସଂଖ୍ୟାକୁ ଦୁଇଟି ସଂଖ୍ୟାର ଯୋଗ ସହ ଗୁଣ କଲେ, ସେହି ସଂଖ୍ୟାକୁ ଉଭୟ ପଦ ସହ ଅଲଗା ଅଲଗା ଗୁଣ କରି ଫଳକୁ ଯୋଗ କରିହୁଏ। ଏହାର ନିୟମ a(b+c)=ab+ac। ଉଦାହରଣ, 23×27 = 23×(20+7) = 23×20 + 23×7 = 460+161 = 621। ତେଣୁ ବଣ୍ଟନ ଗୁଣଧର୍ମ ଗୁଣନକୁ ଛୋଟ ଅଂଶରେ ବାଣ୍ଟି ସହଜ କରେ।

ପ୍ରଶ୍ନ–୨. 23 × 27 କୁ ଯୋଗ ଓ ବିୟୋଗ ଉଭୟ ପଦ୍ଧତିରେ ବଣ୍ଟନ ଗୁଣଧର୍ମ ବ୍ୟବହାର କରି ହିସାବ କର।

ଉତ୍ତର: ଯୋଗ ପଦ୍ଧତି: 23×27 = 23×(20+7) = 23×20+23×7 = 460+161 = 621। ବିୟୋଗ ପଦ୍ଧତି: 23×27 = 23×(30−3) = 23×30−23×3 = 690−69 = 621। ଦୁଇ ପଦ୍ଧତିରେ ସମାନ ଫଳ ମିଳେ।

ପ୍ରଶ୍ନ–୩. (a+b)(c+d) ର ବିସ୍ତାର କରି ବଣ୍ଟନ ଗୁଣଧର୍ମ ବୁଝାଅ।

ଉତ୍ତର: ପ୍ରଥମ ବ୍ରାକେଟର ପ୍ରତ୍ୟେକ ପଦକୁ ଦ୍ୱିତୀୟ ବ୍ରାକେଟର ପ୍ରତ୍ୟେକ ପଦ ସହ ଗୁଣ କରିବା। ତେଣୁ (a+b)(c+d) = a(c+d)+b(c+d) = ac+ad+bc+bd। ଅର୍ଥାତ୍ ଚାରିଟି ଗୁଣନ ପଦ ମିଳେ—ac, ad, bc ଓ bd। ଏହି ନିୟମ ବୀଜଗାଣିତିକ ରାଶି ବିସ୍ତାର କରିବାରେ ବହୁତ ଉପଯୋଗୀ।
