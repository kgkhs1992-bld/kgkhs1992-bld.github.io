Geography — Chapter 01: ସମ୍ବଳ

2-Mark + 3-Mark + Learning Practice

✍️ 2-Mark / Short Answer Practice

1. ସମ୍ବଳ କ’ଣ?
Answer: ମଣିଷ ପାଇଁ ଉପଯୋଗୀ, ଆର୍ଥିକ ଦୃଷ୍ଟିରୁ ସମ୍ଭବ ଓ ସାଂସ୍କୃତିକ ଦୃଷ୍ଟିରୁ ଗ୍ରହଣଯୋଗ୍ୟ ପରିବେଶୀୟ ପଦାର୍ଥ ବା ଶକ୍ତିକୁ ସମ୍ବଳ କୁହାଯାଏ।
2. ସମ୍ବଳର ଚାରିଟି ବିଶେଷତା ଲେଖ।
Answer: ଉପଯୋଗିତା, କାର୍ଯ୍ୟଦକ୍ଷତା, ସୁଲଭତା ଓ ପରିବର୍ତ୍ତନଶୀଳତା।
3. ପ୍ରାକୃତିକ ସମ୍ବଳ କ’ଣ? ଉଦାହରଣ ଦିଅ।
Answer: ପ୍ରକୃତିରେ ଥିବା ଏବଂ ମଣିଷ ପ୍ରତ୍ୟକ୍ଷ ବା ପରୋକ୍ଷ ଭାବେ ବ୍ୟବହାର କରୁଥିବା ପଦାର୍ଥ/ଶକ୍ତି ପ୍ରାକୃତିକ ସମ୍ବଳ। ଯଥା—ଭୂମି, ମୃତ୍ତିକା, ଜଳ, ବାୟୁ, ଅରଣ୍ୟ, ଖଣିଜ।
4. ସାଂସ୍କୃତିକ ସମ୍ବଳ କ’ଣ?
Answer: ମଣିଷ ନିଜର କୌଶଳ ଓ ପ୍ରଯୁକ୍ତି ଦ୍ୱାରା ପ୍ରାକୃତିକ ସମ୍ବଳକୁ ରୂପାନ୍ତର କରି ବା ବ୍ୟବହାରଯୋଗ୍ୟ କରି ସୃଷ୍ଟି କରୁଥିବା ସମ୍ବଳ।
5. ଜୈବ ଓ ଅଜୈବ ସମ୍ବଳର ତଫାତ ଦିଅ।
Answer: ଜୈବ ସମ୍ବଳ ଜୀବନ୍ତ ଉପାଦାନ ସହ ସମ୍ପର୍କିତ; ଅଜୈବ ସମ୍ବଳ ଅଜୀବ ବା ନିର୍ଜୀବ ପଦାର୍ଥ।
6. ନବୀକରଣଯୋଗ୍ୟ ସମ୍ବଳ କ’ଣ?
Answer: ଯେଉଁ ସମ୍ବଳକୁ ବିଭିନ୍ନ ପ୍ରାକୃତିକ/ଚକ୍ରୀୟ ପ୍ରକ୍ରିୟା ଦ୍ୱାରା ପୁନଃଭରଣ କରାଯାଇପାରେ ତାହା ନବୀକରଣଯୋଗ୍ୟ ସମ୍ବଳ।
7. ଅନବୀକରଣଯୋଗ୍ୟ ସମ୍ବଳ କ’ଣ?
Answer: ବ୍ୟବହାର ଓ ହ୍ରାସ ପରେ ଯାହାର ପୁନଃଭରଣ ସମ୍ଭବ ନୁହେଁ, ତାହା ଅନବୀକରଣଯୋଗ୍ୟ ସମ୍ବଳ।
8. ସମ୍ବଳ ସଂରକ୍ଷଣ କ’ଣ?
Answer: ସମ୍ବଳର ସଯତ୍ନ ବିନିଯୋଗ ଓ ନବୀକରଣ ପାଇଁ ଯଥେଷ୍ଟ ସମୟ ଦେବାକୁ ସମ୍ବଳ ସଂରକ୍ଷଣ କୁହାଯାଏ।

📝 3-Mark / Long Answer Practice

1. ସମ୍ବଳକୁ ବିଭିନ୍ନ ଆଧାରରେ କିପରି ବର୍ଗୀକରଣ କରାଯାଏ?
Model Answer: ପ୍ରକୃତି, ଉତ୍ପତ୍ତି, ବ୍ୟବହାର ଓ ସୁଲଭତା, ପରିମାଣ, ଭରଣ, ବଣ୍ଟନ, ବିକାଶସ୍ତର ଓ ମାଲିକାନା ଆଦି ଆଧାରରେ ସମ୍ବଳକୁ ବିଭକ୍ତ କରାଯାଏ। ଉଦାହରଣ ଭାବେ ପ୍ରାକୃତିକ/ସାଂସ୍କୃତିକ/ମାନବ, ଜୈବ/ଅଜୈବ, ନବୀକରଣଯୋଗ୍ୟ/ଅନବୀକରଣଯୋଗ୍ୟ ଓ ବ୍ୟକ୍ତିଗତ/ଗୋଷ୍ଠୀଗତ/ଜାତୀୟ/ଆନ୍ତର୍ଜାତୀୟ ସମ୍ବଳ ଉଲ୍ଲେଖ କରାଯାଇପାରେ।
2. ସମ୍ବଳର ଅତ୍ୟଧିକ ଓ ଅନୁଚିତ ବ୍ୟବହାର କିପରି ପରିବେଶକୁ ପ୍ରଭାବିତ କରେ?
Model Answer: ଅତ୍ୟଧିକ ଆହରଣରେ ସମ୍ବଳର ଭଣ୍ଡାର କମିଯାଏ। ବନନଷ୍ଟ, ମାଟିକ୍ଷୟ, ପ୍ରଦୂଷଣ, ଜଳବାୟୁ ପରିବର୍ତ୍ତନ, ଜୈବବିବିଧତା ହ୍ରାସ ଓ ବନ୍ୟଜନ୍ତୁ ପାଇଁ ସଙ୍କଟ ବଢ଼ିପାରେ।
3. ଧାରଣୀୟ ବିକାଶର ଗୁରୁତ୍ୱ ବ୍ୟାଖ୍ୟା କର।
Model Answer: ଏହା ବର୍ତ୍ତମାନର ଆବଶ୍ୟକତା ସହ ଭବିଷ୍ୟତ ପିଢ଼ିର ଅଧିକାରକୁ ସମନ୍ୱୟ କରେ। ସମ୍ବଳର ସଂରକ୍ଷଣ, ପରିବେଶର ସୁରକ୍ଷା ଓ ଜୈବବିବିଧତା ରକ୍ଷା ଏହାର ମୁଖ୍ୟ ଦିଗ।
4. ଭାରତର ସମ୍ବଳ ଯୋଜନାର ମୁଖ୍ୟ ପ୍ରକ୍ରିୟାଗୁଡ଼ିକ ଲେଖ।
Model Answer: ସମ୍ବଳର ଆବଶ୍ୟକତା ଓ ସ୍ଥାନ ଚିହ୍ନଟ, ମଜୁତ ଓ ବିକାଶସ୍ତର ଆକଳନ, ସମ୍ବଳ ଉତ୍ତୋଳନ ଓ ବ୍ୟବହାର ପାଇଁ ଯୋଜନା, ଯନ୍ତ୍ରପାତି/ପ୍ରଯୁକ୍ତି/ଦକ୍ଷତା/ବଜାର ବ୍ୟବସ୍ଥା ଏବଂ ଜାତୀୟ ବିକାଶ ଯୋଜନା ସହ ସମନ୍ୱୟ।

  2. ବିଦ୍ୟାଳୟରେ ବ୍ୟବହୃତ 5ଟି ସମ୍ବଳର ତାଲିକା ପ୍ରସ୍ତୁତ କର।
