ଅଧ୍ୟାୟ – ୨ : ଦ୍ୱିଘାତ ସମୀକରଣ

ଶ୍ରେଣୀ – X | ଗଣିତ

📖 Textbook Questions & Answers

ଏହି ପୃଷ୍ଠାରେ ଦ୍ୱିଘାତ ସମୀକରଣ ଅଧ୍ୟାୟର ପାଠ୍ୟପୁସ୍ତକ ଅଭ୍ୟାସର ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ ପ୍ରଶ୍ନଗୁଡ଼ିକର ସହଜ ଉତ୍ତର ଓ ସମାଧାନ ଦିଆଯାଇଛି।

ପ୍ରତ୍ୟେକ ପ୍ରଶ୍ନକୁ ପ୍ରଥମେ ନିଜେ ସମାଧାନ କରିବାକୁ ଚେଷ୍ଟା କର। ତା'ପରେ ଉତ୍ତର ଦେଖି ନିଜର ସମାଧାନ ଯାଞ୍ଚ କର।

📝 ଅନୁଶୀଳନୀ – ୨(a)

୧. ନିମ୍ନଲିଖିତ ଉକ୍ତିଗୁଡ଼ିକୁ ସଂଶୋଧନ କର।

(i) x² − 4x + 4 = 0 ର ମୂଳଦ୍ୱୟ ବାସ୍ତବ ଓ ଭିନ୍ନ ।
ଉତ୍ତର: D = b² − 4ac
= (−4)² − 4(1)(4)
= 16 − 16 = 0

ତେଣୁ ମୂଳଦ୍ୱୟ ବାସ୍ତବ ଓ ସମାନ।
(ii) x² − 5x + 6 = 0 ର ପ୍ରଭେଦକ 2 ।
ଉତ୍ତର: D = (−5)² − 4(1)(6)
= 25 − 24
= 1

ଅତଏବ ପ୍ରଭେଦକର ମାନ 1।
(iii) ax² + bx − c = 0 ର ମୂଳଦ୍ୱୟର ସମଷ୍ଟି c/a ।
ସଠିକ୍ ଉତ୍ତର:
ମୂଳଦ୍ୱୟର ସମଷ୍ଟି
α + β = −b/a
(iv) ax² + bx + c = 0 ର ମୂଳଦ୍ୱୟର ଗୁଣଫଳ b/a ।
ସଠିକ୍ ଉତ୍ତର:
αβ = c/a
(v) ମୂଳ 1 ଓ −1 ବିଶିଷ୍ଟ ଦ୍ୱିଘାତ ସମୀକରଣ x² + 1 = 0 ।
ଉତ୍ତର: ମୂଳଦ୍ୱୟ α = 1 ଓ β = −1

ସମୀକରଣ:
x² − (α + β)x + αβ = 0

= x² − (1 − 1)x − 1 = 0

∴ x² − 1 = 0
(vi) x² = 0 ର ମୂଳଦ୍ୱୟ ଭିନ୍ନ ।
ଉତ୍ତର: x² = 0
⇒ x = 0, 0

ତେଣୁ ମୂଳଦ୍ୱୟ ସମାନ।
(vii) 3x² − 2x − 1 = 0 ର ମୂଳଦ୍ୱୟର ସମଷ୍ଟି −3/2 ।
ଉତ୍ତର: a = 3, b = −2

α + β = −b/a
= −(−2)/3
= 2/3

ଅତଏବ ସଠିକ୍ ସମଷ୍ଟି 2/3।
(viii) 3x² − 2x − 1 = 0 ର ମୂଳଦ୍ୱୟର ଗୁଣଫଳ 1/3 ।
ଉତ୍ତର: αβ = c/a
= −1/3

∴ ସଠିକ୍ ଗୁଣଫଳ −1/3।

📝 ଅନୁଶୀଳନୀ – ୨(a)

୨. ସଂକ୍ଷିପ୍ତ ଉତ୍ତର

(i) ଗୋଟିଏ ଦ୍ୱିଘାତ ସମୀକରଣର ମୂଳଦ୍ୱୟ 3 ଓ −5 । ସମୀକରଣଟି ନିରୂପଣ କର।
α = 3, β = −5

ସମୀକରଣ:
x² − (α + β)x + αβ = 0

= x² − (3 − 5)x + (3)(−5) = 0

∴ x² + 2x − 15 = 0
(ii) mx² − 2x + (2m − 1) = 0 ର ମୂଳଦ୍ୱୟର ଗୁଣଫଳ 3 ହେଲେ m ର ମାନ ନିରୂପଣ କର।
ମୂଳଦ୍ୱୟର ଗୁଣଫଳ:
(2m − 1)/m = 3

⇒ 2m − 1 = 3m
⇒ m = −1
(iii) x² − px + 2 = 0 ର ଗୋଟିଏ ମୂଳ 2 ହେଲେ p ର ମାନ ନିରୂପଣ କର।
x = 2 ବସାଇଲେ:
4 − 2p + 2 = 0
6 − 2p = 0
∴ p = 3
(iv) 4x² − 2x + c = 0 ର ମୂଳଦ୍ୱୟ ବାସ୍ତବ ଓ ସମାନ ହେଲେ c ର ମାନ ନିରୂପଣ କର।
ବାସ୍ତବ ଓ ସମାନ ମୂଳ ପାଇଁ:
D = 0
(−2)² − 4(4)c = 0
4 − 16c = 0
∴ c = 1/4
(v) 5x² + 2x + k = 0 ର ଗୋଟିଏ ମୂଳ −2 ହେଲେ k ର ମାନ ନିରୂପଣ କର।
x = −2 ବସାଇଲେ:
5(−2)² + 2(−2) + k = 0
20 − 4 + k = 0
16 + k = 0
∴ k = −16
(vi) x² − kx + 6 = 0 ର ଗୋଟିଏ ମୂଳ 3 ହେଲେ k ର ମାନ ନିରୂପଣ କର।
x = 3 ବସାଇଲେ:
9 − 3k + 6 = 0
15 − 3k = 0
∴ k = 5
(vii) 2x² + kx + 3 = 0 ର ମୂଳଦ୍ୱୟ ବାସ୍ତବ ଓ ସମାନ ହେଲେ k ର ମାନ ନିରୂପଣ କର।
D = 0
k² − 4(2)(3) = 0
k² − 24 = 0
k² = 24
∴ k = ±2√6

🎯 ଅନୁଶୀଳନୀ – ୨(a) MCQ

୧. ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ କେଉଁଟି x ର ଦ୍ୱିଘାତ ସମୀକରଣ?
(a) x² − x − 12 = 0
(b) x² + 12 = 3
(c) x + 1 = x²
(d) x(x − 1)(x + 5) = 0

ଉତ୍ତର: ଦିଆଯାଇଥିବା ବିକଳ୍ପର ସାଧାରଣ ରୂପକୁ ଆଣି ଯାଞ୍ଚ କରିବା ଆବଶ୍ୟକ।
୨. 7x² − 9x + 2 = 0 ର ମୂଳଦ୍ୱୟର ସ୍ୱରୂପ କ'ଣ?
D = (−9)² − 4(7)(2)
= 81 − 56
= 25 > 0

ଉତ୍ତର: ବାସ୍ତବ ଓ ପରସ୍ପରଠାରୁ ପୃଥକ୍।
୩. −6 ଓ 8 ମୂଳ ବିଶିଷ୍ଟ ଦ୍ୱିଘାତ ସମୀକରଣ କେଉଁଟି?
ସମୀକରଣ:
(x + 6)(x − 8) = 0

ଉତ୍ତର: (x + 6)(x − 8) = 0
୪. 3x² + 2√5x − 5 = 0 ର ମୂଳଦ୍ୱୟ α ଓ β ହେଲେ αβ ର ମାନ କେତେ?
αβ = c/a
= −5/3

ଉତ୍ତର: −5/3
୫. ଯଦି ମୂଳଦ୍ୱୟର ସମଷ୍ଟି 4 ଓ ଗୁଣଫଳ 5/2, ତେବେ ସମୀକରଣଟି ନିରୂପଣ କର।
ସମୀକରଣ:
x² − 4x + 5/2 = 0

2 ଦ୍ୱାରା ଗୁଣ କଲେ:
2x² − 8x + 5 = 0

📝 ଅନୁଶୀଳନୀ – ୨(b)

ଦ୍ୱିଘାତ ସମୀକରଣ ଗଠନ ଓ ପ୍ରୟୋଗ

୧. ଗୋଟିଏ ସଂଖ୍ୟା ଓ ତାହାର ବ୍ୟତ୍କ୍ରମର ସମଷ୍ଟି 2। ସଂଖ୍ୟାଟି x ହେଲେ ଦ୍ୱିଘାତ ସମୀକରଣ ଗଠନ କର।
ସଂଖ୍ୟା = x
ବ୍ୟତ୍କ୍ରମ = 1/x

x + 1/x = 2
⇒ x² + 1 = 2x
∴ x² − 2x + 1 = 0
୨. ଦୁଇଟି କ୍ରମିକ ପୂର୍ଣ୍ଣସଂଖ୍ୟାର ଗୁଣଫଳ 20। ଦ୍ୱିଘାତ ସମୀକରଣ ଗଠନ କର।
ଗୋଟିଏ ସଂଖ୍ୟା = y
ଅନ୍ୟ ସଂଖ୍ୟା = y + 1

y(y + 1) = 20
⇒ y² + y − 20 = 0

∴ y² + y − 20 = 0
୩. ଦୁଇଟି ସଂଖ୍ୟାର ସମଷ୍ଟି 18 ଏବଂ ଗୁଣଫଳ 72 ହେଲେ, ଗୋଟିଏ ସଂଖ୍ୟାକୁ x ନେଇ ଦ୍ୱିଘାତ ସମୀକରଣ ଗଠନ କର।
ଅନ୍ୟ ସଂଖ୍ୟା = 18 − x

x(18 − x) = 72
18x − x² = 72
∴ x² − 18x + 72 = 0
୪. ଏକ ଧନାତ୍ମକ ସଂଖ୍ୟା ତାହାର ବର୍ଗମୂଳଠାରୁ 12 ଅଧିକ। ସଂଖ୍ୟାଟି ନିର୍ଣ୍ଣୟ କର।
ଧରାଯାଉ ସଂଖ୍ୟା = x²
ବର୍ଗମୂଳ = x

x² = x + 12
⇒ x² − x − 12 = 0
⇒ (x − 4)(x + 3) = 0
x = 4 ବା −3

ଧନାତ୍ମକ ମାନ:
x = 4
ସଂଖ୍ୟା = x² = 16

ଉତ୍ତର: 16
୫. 51କୁ ଦୁଇ ଭାଗ କଲେ ସେମାନଙ୍କର ଗୁଣଫଳ 378 ହୁଏ। ସଂଖ୍ୟାଦ୍ୱୟ ନିର୍ଣ୍ଣୟ କର।
ଗୋଟିଏ ଭାଗ = x
ଅନ୍ୟ ଭାଗ = 51 − x

x(51 − x) = 378
⇒ 51x − x² = 378
⇒ x² − 51x + 378 = 0

ଏହାକୁ ସମାଧାନ କରି ସଂଖ୍ୟାଦ୍ୱୟ ନିର୍ଣ୍ଣୟ କରାଯାଇପାରିବ।

📌 ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ ସୂତ୍ର

  • D = b² − 4ac
  • α + β = −b/a
  • αβ = c/a
  • x = (−b ± √(b² − 4ac))/2a
