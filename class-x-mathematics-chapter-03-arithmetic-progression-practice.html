📌 ଅଭ୍ୟାସ ପୂର୍ବରୁ ମନେ ରଖ

tₙ = a + (n−1)d
Sₙ = n/2 [2a + (n−1)d]
Sₙ = n/2(a+l)

a = ପ୍ରଥମ ପଦ, d = ସାଧାରଣ ଅନ୍ତର, n = ପଦ ସଂଖ୍ୟା, l = ଶେଷ ପଦ।

🟢 ବିଭାଗ – A : ମୌଳିକ ଅଭ୍ୟାସ

21. 7, 12, 17, 22, ... ଏକ A.P. କି? a ଓ d ନିର୍ଣ୍ଣୟ କର।
22. 25, 20, 15, 10, ... ର ସାଧାରଣ ଅନ୍ତର ନିର୍ଣ୍ଣୟ କର।
23. 3, 3, 3, 3, ... ଏହା କି A.P.? ହେଲେ d କେତେ?
24. A.P. 11, 15, 19, 23, ... ର 18ତମ ପଦ ନିର୍ଣ୍ଣୟ କର।
25. A.P. −5, −2, 1, 4, ... ର 25ତମ ପଦ ନିର୍ଣ୍ଣୟ କର।
26. ଗୋଟିଏ A.P. ର a=9 ଓ d=−2 ହେଲେ ତାହାର ପ୍ରଥମ 8ଟି ପଦ ଲେଖ।

🟡 ବିଭାଗ – B : n-ତମ ପଦ ଅଭ୍ୟାସ

37. 5, 9, 13, 17, ... ର 40ତମ ପଦ ନିର୍ଣ୍ଣୟ କର।
38. ଗୋଟିଏ A.P. ର 7ତମ ପଦ 20 ଏବଂ 13ତମ ପଦ 38। ପ୍ରଥମ ପଦ ଓ ସାଧାରଣ ଅନ୍ତର ନିର୍ଣ୍ଣୟ କର।
39. A.P. 4, 10, 16, 22, ... ର କେଉଁ ପଦ 100 ହେବ?
310. ଗୋଟିଏ A.P. ର 5ତମ ପଦ 17 ଓ 11ତମ ପଦ 35। 25ତମ ପଦ ନିର୍ଣ୍ଣୟ କର।
311. −12, −8, −4, 0, ... ର 31ତମ ପଦ ନିର୍ଣ୍ଣୟ କର।

🟠 ବିଭାଗ – C : ପ୍ରଥମ n ପଦର ଯୋଗଫଳ

312. 3+6+9+...+60 ର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।
313. 8+13+18+...+98 ର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।
314. ଗୋଟିଏ A.P. ର a=12, d=5 ହେଲେ ପ୍ରଥମ 20ଟି ପଦର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।
315. 50, 47, 44, ... ର ପ୍ରଥମ 15ଟି ପଦର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।
416. ଗୋଟିଏ A.P. ର ପ୍ରଥମ ପଦ 7 ଏବଂ 20ତମ ପଦ 64। ପ୍ରଥମ 20ଟି ପଦର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।
417. 15 ଠାରୁ 99 ପର୍ଯ୍ୟନ୍ତ 3 ର ଗୁଣିତକମାନଙ୍କର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।

🔵 ବିଭାଗ – D : ଯୋଗଫଳରୁ n ନିର୍ଣ୍ଣୟ

418. 5+8+11+... ର କେତୋଟି ପଦର ଯୋଗଫଳ 425 ହେବ?
419. 20+18+16+... ର ପ୍ରଥମ n ପଦର ଯୋଗଫଳ 90 ହେଲେ n ନିର୍ଣ୍ଣୟ କର।
420. 2+5+8+...+92 ରେ କେତୋଟି ପଦ ଅଛି ଏବଂ ସମୁଦାୟ ଯୋଗଫଳ କେତେ?
421. ଗୋଟିଏ A.P. ର ପ୍ରଥମ n ପଦର ଯୋଗଫଳ 3n²+2n। ଏହାର n-ତମ ପଦର ସୂତ୍ର ନିର୍ଣ୍ଣୟ କର।

🟣 ବିଭାଗ – E : ପ୍ରାକୃତିକ, ଯୁଗ୍ମ ଓ ବିଜୋଡ଼ ସଂଖ୍ୟା

322. 1+2+3+...+50 ର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।
323. ପ୍ରଥମ 30ଟି ବିଜୋଡ଼ ସଂଖ୍ୟାର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।
324. ପ୍ରଥମ 25ଟି ଯୁଗ୍ମ ସଂଖ୍ୟାର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।
425. 1²+2²+3²+...+20² ର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।
426. 1³+2³+3³+...+15³ ର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।

🔴 ବିଭାଗ – F : A.M. ଓ ମଧ୍ୟମ ପଦ

327. 18 ଓ 42 ମଧ୍ୟରେ ଗୋଟିଏ A.M. ନିର୍ଣ୍ଣୟ କର।
428. 8 ଓ 38 ମଧ୍ୟରେ ଚାରୋଟି A.M. ସ୍ଥାପନ କର।
329. ତିନୋଟି ସଂଖ୍ୟା A.P. ରେ ଅଛନ୍ତି। ପ୍ରଥମ ଓ ତୃତୀୟ ସଂଖ୍ୟାର ଯୋଗ 30 ଏବଂ ମଧ୍ୟମ ସଂଖ୍ୟା 10 ହେଲେ ସଂଖ୍ୟାଗୁଡ଼ିକ ନିର୍ଣ୍ଣୟ କର।
430. ତିନୋଟି ସଂଖ୍ୟା A.P. ରେ ଅଛି ଏବଂ ସେମାନଙ୍କର ଯୋଗ 27। ତୃତୀୟ ସଂଖ୍ୟା ପ୍ରଥମ ସଂଖ୍ୟାଠାରୁ 8 ଅଧିକ ହେଲେ ସଂଖ୍ୟାଗୁଡ଼ିକ ନିର୍ଣ୍ଣୟ କର।

🟤 ବିଭାଗ – G : ଚ୍ୟାଲେଞ୍ଜ ପ୍ରଶ୍ନ

531. ଗୋଟିଏ A.P. ର t₇=16 ଓ t₁₇=36। ଏହାର ପ୍ରଥମ 25ଟି ପଦର ଯୋଗଫଳ ନିର୍ଣ୍ଣୟ କର।
532. ପ୍ରମାଣ କର ଯେ, ଗୋଟିଏ A.P. ର ସମମିତ ପଦମାନଙ୍କର ଯୋଗ ତାହାର ମଧ୍ୟମ ପଦର ଦୁଇଗୁଣ ସମାନ।
533. ଯଦି a, b, c A.P. ରେ ଅଛନ୍ତି, ତେବେ ପ୍ରମାଣ କର: 2b=a+c।
534. ଗୋଟିଏ A.P. ର ପ୍ରଥମ n ପଦର ଯୋଗଫଳ Sₙ ଦିଆଥିଲେ tₙ=Sₙ−Sₙ₋₁ ବ୍ୟବହାର କରି n-ତମ ପଦ ନିର୍ଣ୍ଣୟ କରିବାର ସାଧାରଣ ପଦ୍ଧତି ଲେଖ।
535. ଏକ ଧାରାର ପ୍ରଥମ ପଦ ଓ ସାଧାରଣ ଅନ୍ତର ଦିଆଥିଲେ ଏହାର ଶେଷ ପଦ ଓ ପ୍ରଥମ n ପଦର ଯୋଗଫଳ ମଧ୍ୟରେ ସମ୍ପର୍କ ଦେଖାଅ।

🧠 ନିଜେ ଯାଞ୍ଚ କର

ଉତ୍ତର ଦେଖିବା ପୂର୍ବରୁ ପ୍ରତ୍ୟେକ ପ୍ରଶ୍ନରେ ନିଜେ a, d, n ଚିହ୍ନଟ କର। ପ୍ରଶ୍ନଟି n-ତମ ପଦ ସମ୍ପର୍କିତ କି ଯୋଗଫଳ ସମ୍ପର୍କିତ, ପ୍ରଥମେ ନିର୍ଣ୍ଣୟ କର।
ମନେ ରଖ: କେବଳ ଉତ୍ତର ଲେଖିବା ନୁହେଁ—ପଦକ୍ଷେପ ସହିତ ସମାଧାନ କର। ବିଶେଷକରି d ଋଣାତ୍ମକ ଥିବା ପ୍ରଶ୍ନରେ ଚିହ୍ନ ଯାଞ୍ଚ କର।
