🧮 5 Problems with Solution — 5 Marks Each

1. ଦୁଇଟି ରେଖା ପରସ୍ପରକୁ ଛେଦ କରିଛି। ଗୋଟିଏ କୋଣ 68°। ଅନ୍ୟ ତିନୋଟି କୋଣ ନିର୍ଣ୍ଣୟ କର।
ସମାଧାନ:
Vertically opposite angle = 68°। Linear pair ର ଯୋଗ 180° ଥିବାରୁ ପ୍ରତ୍ୟେକ adjacent angle = 180°−68° = 112°। ତେଣୁ ଚାରି କୋଣ: 68°, 112°, 68°, 112°।
ମାର୍କ: 5
2. AB ∥ CD ଏବଂ transversal ଦ୍ୱାରା ଗଠିତ ଗୋଟିଏ corresponding angle 115°। ସମ୍ପର୍କିତ alternate interior ଓ same-side interior angles ନିର୍ଣ୍ଣୟ କର।
ସମାଧାନ:
Parallel lines ରେ corresponding angles ସମାନ, ତେଣୁ corresponding = 115°। Alternate interior angle ମଧ୍ୟ 115°। Same-side interior angles supplementary, ତେଣୁ ଅନ୍ୟଟି = 180°−115° = 65°।
ମାର୍କ: 5
3. ଦୁଇ adjacent angles (3x+10)° ଓ (2x+20)° Linear Pair। x ଓ ଦୁଇ କୋଣ ନିର୍ଣ୍ଣୟ କର।
ସମାଧାନ:
Linear Pair ⇒ (3x+10)+(2x+20)=180 ⇒ 5x+30=180 ⇒ x=30। ପ୍ରଥମ କୋଣ =100°; ଦ୍ୱିତୀୟ =80°। ଯାଞ୍ଚ: 100°+80°=180°।
ମାର୍କ: 5
4. AB ∥ CD। Same-side interior angles (4x+5)° ଓ (2x+25)°। x ଓ କୋଣ ନିର୍ଣ୍ଣୟ କର।
ସମାଧାନ:
Same-side interior angles ର ଯୋଗ 180°। (4x+5)+(2x+25)=180 ⇒ 6x+30=180 ⇒ x=25। କୋଣଦ୍ୱୟ =105° ଓ 75°। ଯାଞ୍ଚ: 105°+75°=180°।
ମାର୍କ: 5
5. ∠AOC=(3x+15)° ଓ ∠BOD=(5x−25)° vertically opposite। x ଓ କୋଣ ନିର୍ଣ୍ଣୟ କର।
ସମାଧାନ:
Vertically opposite angles ସମାନ। 3x+15=5x−25 ⇒ 2x=40 ⇒ x=20। ∠AOC=75° ଓ ∠BOD=75°। ସେମାନଙ୍କ adjacent angles =180°−75°=105°।
ମାର୍କ: 5
