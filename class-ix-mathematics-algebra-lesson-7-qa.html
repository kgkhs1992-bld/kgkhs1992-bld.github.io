Part A — 5-Mark Questions & Answers

1. Statistics କ'ଣ? Data କ'ଣ?

ଉତ୍ତର:
Statisticsରେ data ସଂଗ୍ରହ, ବ୍ୟବସ୍ଥିତ କରିବା ଓ ପ୍ରଦର୍ଶନ କରିବାର ପ୍ରକ୍ରିୟା ଅଧ୍ୟୟନ କରାଯାଏ।
Data ହେଉଛି କୌଣସି ବିଷୟ ସମ୍ପର୍କିତ ସଂଗୃହୀତ facts କିମ୍ବା numerical values।
Data raw ଅବସ୍ଥାରେ ଥାଇପାରେ କିମ୍ବା tableରେ ବ୍ୟବସ୍ଥିତ ହୋଇପାରେ।
Statisticsରେ frequency, frequency distribution ଓ grouped data ପରି ଧାରଣା ବ୍ୟବହୃତ ହୁଏ।
ଏହା dataକୁ ସହଜରେ ବୁଝିବାରେ ସାହାଯ୍ୟ କରେ।

2. Primary data ଓ Secondary data ମଧ୍ୟରେ ପାର୍ଥକ୍ୟ ଲେଖ।

ଉତ୍ତର:
ନିଜେ ପ୍ରଥମେ ସଂଗ୍ରହ କରାଯାଇଥିବା dataକୁ Primary data କୁହାଯାଏ।
ଅନ୍ୟ ଉତ୍ସରୁ ପାଇଥିବା dataକୁ Secondary data କୁହାଯାଏ।
ଉଦାହରଣ: ନିଜେ 30 ଜଣ ଛାତ୍ରଙ୍କ marks ସଂଗ୍ରହ କଲେ ଏହା primary data।
ପୁସ୍ତକ ବା ପୂର୍ବରୁ ପ୍ରକାଶିତ reportରୁ marks/data ନେଲେ secondary data।
ଉଭୟ data statisticsରେ ବ୍ୟବହାର କରାଯାଇପାରେ।

3. Frequency distribution table କିପରି ତିଆରି କରାଯାଏ?

ଉତ୍ତର:
ପ୍ରଥମେ raw dataରେ ପ୍ରତ୍ୟେକ value କେତେଥର ଆସିଛି ଚିହ୍ନଟ କରାଯାଏ।
ପ୍ରତ୍ୟେକ value ପାଇଁ tally marks ଦିଆଯାଏ।
ତାପରେ tally marks ଗଣି frequency ଲେଖାଯାଏ।
ଶେଷରେ value/score ଓ frequencyକୁ tableରେ ପ୍ରଦର୍ଶନ କରାଯାଏ।
ଏହି tableକୁ frequency distribution table କୁହାଯାଏ।

4. Cumulative frequency ବୁଝାଅ।

ଉତ୍ତର:
Cumulative frequency ହେଉଛି frequencyଗୁଡ଼ିକୁ କ୍ରମେ ଯୋଗ କରି ପାଇଥିବା total।
ଉଦାହରଣ frequency 5, 8, 7 ହେଲେ ପ୍ରଥମ cumulative frequency=5।
ଦ୍ୱିତୀୟ =5+8=13।
ତୃତୀୟ =13+7=20।
ତେଣୁ cumulative frequency =5,13,20।

5. Grouped frequency distributionରେ class interval, mid-point ଓ class size ବୁଝାଅ।

ଉତ୍ତର:
ବହୁ dataକୁ class intervalରେ ବିଭକ୍ତ କରି frequency ଦେଖାଇଲେ grouped frequency distribution ମିଳେ।
10–20 ଏକ class intervalର ଉଦାହରଣ।
ଏଠାରେ lower limit=10 ଏବଂ upper limit=20।
Mid-point=(10+20)/2=15।
Exclusive class size=20−10=10; ଏହିପରି class interval dataକୁ ସୁବ୍ୟବସ୍ଥିତ କରେ।
