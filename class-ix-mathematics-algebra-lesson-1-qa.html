🧠 ଅଭ୍ୟାସ ପ୍ରଶ୍ନ ଓ ଉତ୍ତର

5 Long Questions × 5 Marks

Q1. 1. Set କ’ଣ? Set କୁ କେଉଁ କେଉଁ ପ୍ରଣାଳୀରେ ପ୍ରକାଶ କରାଯାଏ? ଉଦାହରଣ ସହ ବ୍ୟାଖ୍ୟା କର। (5 Marks)
ଉତ୍ତର: Set ହେଉଛି ସୁସ୍ପଷ୍ଟ ଭାବରେ ଚିହ୍ନଟ କରିହେବା elements ମାନଙ୍କର ସଂଗ୍ରହ। Set କୁ ମୁଖ୍ୟତଃ Roster/Tabular Method ଓ Set-builder Method ରେ ପ୍ରକାଶ କରାଯାଏ। Roster ପ୍ରଣାଳୀରେ elements କୁ { } ମଧ୍ୟରେ ସିଧାସଳଖ ଲେଖାଯାଏ, ଯଥା A={1,2,3,4,5}. Set-builder ପ୍ରଣାଳୀରେ elements ର ସାଧାରଣ ଗୁଣ/ଶର୍ତ୍ତ ଦିଆଯାଏ, ଯଥା A={x | x∈N, 1≤x≤5}.
Q2. 2. Finite set, Infinite set, Empty set ଏବଂ Subset କୁ ଉଦାହରଣ ସହ ବ୍ୟାଖ୍ୟା କର। (5 Marks)
ଉତ୍ତର: Finite set ରେ element ସଂଖ୍ୟା ସୀମିତ; ଯଥା {1,2,3}. Infinite set ରେ element ଅସୀମ; ଯଥା N={1,2,3,...}. Empty set ରେ କୌଣସି element ନଥାଏ; ଏହାକୁ ∅ ବା { } ଲେଖାଯାଏ। A ର ପ୍ରତ୍ୟେକ element B ରେ ଥିଲେ A, B ର subset ଏବଂ A⊆B।
Q3. 3. A={1,2,3,4} ଏବଂ B={3,4,5,6} ହେଲେ A∪B, A∩B, A-B ଏବଂ B-A ନିର୍ଣ୍ଣୟ କର। (5 Marks)
ଉତ୍ତର: A∪B={1,2,3,4,5,6}; A∩B={3,4}; A-B={1,2}; B-A={5,6}. Union ରେ ଦୁଇ Set ର ସମସ୍ତ distinct elements ନିଆଯାଏ; intersection ରେ common elements ନିଆଯାଏ। Difference A-B ଓ B-A ସାଧାରଣତଃ ସମାନ ନୁହେଁ।
Q4. 4. Union ଓ Intersection ର commutative, associative ଏବଂ distributive laws ଲେଖି ବ୍ୟାଖ୍ୟା କର। (5 Marks)
ଉତ୍ତର: Commutative: A∪B=B∪A ଏବଂ A∩B=B∩A. Associative: (A∪B)∪C=A∪(B∪C) ଏବଂ (A∩B)∩C=A∩(B∩C). Distributive: A∪(B∩C)=(A∪B)∩(A∪C) ଏବଂ A∩(B∪C)=(A∩B)∪(A∩C).
Q5. 5. Universal set ଓ Complement ବୁଝାଇ A′=E-A ସୂତ୍ରକୁ ଉଦାହରଣ ସହ ବ୍ୟାଖ୍ୟା କର। (5 Marks)
ଉତ୍ତର: ଆଲୋଚନାରେ ଥିବା ସମସ୍ତ relevant elements ର Set କୁ universal set E କୁହାଯାଏ। E ରେ ଥିବା କିନ୍ତୁ A ରେ ନଥିବା elements ହେଉଛି A ର complement। ତେଣୁ A′=E-A। ଉଦାହରଣ: E={1,2,3,4,5,6}, A={2,3,5} ହେଲେ A′={1,4,6}.
