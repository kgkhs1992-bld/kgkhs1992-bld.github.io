📝 ଅତିରିକ୍ତ ଅଭ୍ୟାସ

📌 ଛାତ୍ରଛାତ୍ରୀଙ୍କ ପାଇଁ ନିର୍ଦ୍ଦେଶ

ନିମ୍ନଲିଖିତ ପ୍ରଶ୍ନଗୁଡ଼ିକୁ ଖାତାରେ ନିଜେ ସମାଧାନ କରନ୍ତୁ। ପ୍ରତ୍ୟେକ ପ୍ରଶ୍ନରେ ଆବଶ୍ୟକ ପଦକ୍ଷେପ ଦେଖାନ୍ତୁ।

୧️⃣ ଦ୍ୱିଘାତ ସମୀକରଣ ଚିହ୍ନଟ କର

ପ୍ରଶ୍ନ ୧: ନିମ୍ନଲିଖିତ ସମୀକରଣଗୁଡ଼ିକ ମଧ୍ୟରୁ ଦ୍ୱିଘାତ ସମୀକରଣଗୁଡ଼ିକୁ ଚିହ୍ନଟ କର।

(କ) x² + 5x + 6 = 0
(ଖ) 3x + 7 = 0
(ଗ) 2x² − 7x + 3 = 0
(ଘ) x³ + 2x = 0
ପ୍ରଶ୍ନ ୨: ନିମ୍ନଲିଖିତ ସମୀକରଣକୁ ax² + bx + c = 0 ରୂପରେ ଲେଖ ଏବଂ a, b, c ର ମାନ ନିର୍ଣ୍ଣୟ କର।

3x² − 8x + 4 = 0

୨️⃣ ଉତ୍ପାଦକୀକରଣ ପଦ୍ଧତି

ପ୍ରଶ୍ନ ୩: ଉତ୍ପାଦକୀକରଣ ପଦ୍ଧତିରେ ସମାଧାନ କର।

x² + 7x + 12 = 0
ପ୍ରଶ୍ନ ୪: ଉତ୍ପାଦକୀକରଣ ପଦ୍ଧତିରେ ସମାଧାନ କର।

x² − 9x + 20 = 0
ପ୍ରଶ୍ନ ୫: ସମାଧାନ କର।

2x² − 7x + 3 = 0

୩️⃣ ଦ୍ୱିଘାତ ସୂତ୍ର ବ୍ୟବହାର କର

ପ୍ରଶ୍ନ ୬: ଦ୍ୱିଘାତ ସୂତ୍ର ବ୍ୟବହାର କରି ସମୀକରଣର ମୂଳ ନିର୍ଣ୍ଣୟ କର।

x² − 5x + 2 = 0
ପ୍ରଶ୍ନ ୭: ସମାଧାନ କର।

2x² + 3x − 2 = 0

୪️⃣ ବିଭେଦକ

ପ୍ରଶ୍ନ ୮: ନିମ୍ନଲିଖିତ ସମୀକରଣର ବିଭେଦକ D = b² − 4ac ନିର୍ଣ୍ଣୟ କର।

x² − 6x + 9 = 0
ପ୍ରଶ୍ନ ୯: ନିମ୍ନଲିଖିତ ସମୀକରଣର ମୂଳଗୁଡ଼ିକର ପ୍ରକୃତି ନିର୍ଣ୍ଣୟ କର।

2x² + 4x + 5 = 0
ପ୍ରଶ୍ନ ୧୦: ବିଭେଦକ ବ୍ୟବହାର କରି କୁହ, ସମୀକରଣର ଦୁଇଟି ମୂଳ ସମାନ କି ନୁହେଁ।

x² − 8x + 16 = 0

୫️⃣ ମୂଳମାନଙ୍କର ଯୋଗଫଳ ଓ ଗୁଣଫଳ

ପ୍ରଶ୍ନ ୧୧: ସମୀକରଣର ମୂଳଦ୍ୱୟର ଯୋଗଫଳ ଓ ଗୁଣଫଳ ନିର୍ଣ୍ଣୟ କର।

2x² − 7x + 3 = 0
ପ୍ରଶ୍ନ ୧୨: ଯଦି α ଓ β ହେଉଛି x² − 9x + 14 = 0 ର ମୂଳ, ତେବେ α + β ଏବଂ αβ ନିର୍ଣ୍ଣୟ କର।

୬️⃣ ମୂଳ ଦିଆଥିଲେ ସମୀକରଣ ଗଠନ

ପ୍ରଶ୍ନ ୧୩: ମୂଳଦ୍ୱୟ 2 ଓ 5 ହେଲେ ଦ୍ୱିଘାତ ସମୀକରଣ ଗଠନ କର।
ପ୍ରଶ୍ନ ୧୪: ମୂଳଦ୍ୱୟ −3 ଓ 4 ହେଲେ ଦ୍ୱିଘାତ ସମୀକରଣ ଗଠନ କର।
